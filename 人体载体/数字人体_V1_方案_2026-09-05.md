# 数字人体 V1 可行方案（3D · AI 生成）

> 2026-09-05 定稿方向：Web（Vue + Three.js）+ 直接 3D + 独立 Web 页先行；AI 接入=用户上传人脸/身高/体重/围度 → 自动生成 3D 人体；换装=点击即换。

## 一、总体架构

```
用户输入（人脸照片 + 身高/体重/腰围/罩杯/体型话术）
        │
        ▼
【A. AI 生成层】  （核心）
  ├─ 人脸照片 → 3D 头部（Ready Player Me API / FLAME 2023 Open 自托管）
  └─ 身材参数 → 身体（RPM 体型参数 / MakeHuman 参数映射 + LLM 只做体型标签分类→确定性参数表）
        │
        ▼
【B. 3D 视图层】  Vue + Three.js（WebGL2）
  ├─ 人体 glb 加载（可旋转/缩放）
  ├─ 部位点击（Raycaster 命中面 → 按骨骼分组映射 胸/肩/背/腹/臂/腿…）
  ├─ 换装层（服装 glb 槽位：上装/下装/鞋/发型/配饰，点击即换）
  └─ 健身内容弹层（86 条中文动作库按部位 id 关联，已备好）
        │
        ▼
【C. 数据层】  本地 JSON（部位注册表 + 动作库 + 衣柜）+ 后续接商业挂点
```

## 二、关键选型与理由

| 环节 | 选型 | 理由 | 许可 |
|---|---|---|---|
| 人脸→3D头 | **Ready Player Me（V1）** | 照片→完整 3D 头像+身体+换装一步到位，最快打通「上传出模型」；自带骨架（部位点击好做） | SaaS 条款（⚠️ 需核实商用；不行则 V1 先演示、生产换 FLAME 2023 Open 自托管） |
| 身体参数 | RPM 体型调整（V1）→ MakeHuman（V2） | V1 快；V2 用 MakeHuman 宏参数（身高/体重/围度公式）+ LLM 标签分类 | MakeHuman 软件 AGPL/输出模型 CC0（官方 FAQ 需核） |
| 渲染 | Three.js（WebGL2） | 移动端 WebView 可用（模拟器 WebGPU 不可用）；Vue 组合成熟 | MIT ✅ |
| 拾取 | Three.js Raycaster + 骨骼分组 | 自制 ~1-2 天，无现成库 | 自制 ✅ |
| 动作数据 | free-exercise-db 中文 86 条（已生成） | Unlicense 公有领域 | ✅ |
| 后处理 | Blender（减面 20-40k 三角/Draco 压缩） | 移动端性能 | GPL（工具，输出模型不传染） |

## 三、分阶段落地

### 阶段 1「看懂效果」（先让用户看到）
- 单页 demo：RPM 头像加载 → 人体可旋转 → **点部位出中文动作** → 简单换装（上装/下装切换）
- 范围：浏览器打开即可用；数据本地
- **产出**：`人体载体/demo/human3d.html`（Three.js + 内嵌 86 条动作）
- 前置：①RPM API key（免费注册开发者平台）；②部位→骨骼映射表
- 里程碑：**上传照片出模型 + 点胸出卧推 + 点击换 T 恤**

### 阶段 2「AI 参数化」（用户参数 → 人体）
- 身高/体重/腰围/罩杯输入表单 + 「微胖/梨形/匀称」话术
- LLM 只做体型标签抽取（不直接产数值）→ 确定性参数表 → RPM/MakeHuman
- 头像可换（照片重生成）

### 阶段 3「商业挂点」（你构想的生意面）
- 部位注册表升级为**区域挂点协议**：点头发→理发店、点衣服→电商商家、点胸→健身房
- 衣柜接入（用户资产）+ 商家注册（复用 MOV 注册能力哲学）
- 3D 服装库（MakeHuman 社区 / 商家上传）

## 四、合规红线（先查后做）

1. **DECA / PIFuHD 不可商用**（研究专用/CC BY-NC）——碰都别碰
2. **FLAME 旧版不可商用**，只用 2023 Open（CC-BY-4.0）
3. **Ready Player Me 商用条款**——V1 开工前必须核实（免费额度/付费/头像版权/App 内使用）
4. **MakeHuman 输出模型**商用——官方 FAQ 确认
5. 人脸数据 = 个人信息 → 隐私政策/数据删除/用户授权（MOV 已有隐私合规体系可挂）

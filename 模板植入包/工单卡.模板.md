# 工单库.模板（复制为 `工单库.md` 使用）

> 工单库 = **唯一真相源**（E1），只由设计师写。
> 卡格式：以下「单号/标题/优先级/状态」为必填段，其余按需。
> 状态词表：`已立卡 · 已派单 · 施工中 · 交付待验收 · 验收通过 · 回炉 · 已合 main · 已作废 · 已归档`（对机器闸 `card-phase-audit` 敏感，别自造词）。

---

## 单号（示例：<PREFIX>-001）

**标题**：一句话说清这个单做什么

**优先级**：P0/P1/P2/P3（定义见 README §五）
**分类**：M1~M8（主分类；选一个,标签见「分类」行之外任意）
**功能域**：<一级>/<二级>（主功能域——唯一必填；软件功能坐标，必须在 `审验员/功能树.json`）
**关联功能域**：<可选，逗号分隔 0~N>（关联但不属主的软件功能）
**状态**：已立卡
**卡点**：待派单——无 ｜ → 📋 派单文补后更新
**STD**：`验收标准冻结区/<单号>/STD-<单号>-v1.md`
**交付**：`程序员\交付报告\DELIVERY_<单号>_<日期>.md`

# 安卓中国体系建设模板（本方向接入）

> 本包 = **工单流转模板**（与 `安卓中国体系建设\` 主引擎同源，2026-09-08 统一植入）。
> 用前先看：`安卓中国体系建设\README.md`（全量规则/红线/角色）+ 本包使用方法。

## 〇、植入三步（本包=安装器，用完即删 · 2026-09-09 拍板）

1. **建**：新项目/新方向建文件夹，把本包整体复制进去
2. **铺**：按下方目录约定铺角色文件夹与规则模板——README 规则模板就位、`项目配置.模板.md` 复制为 `项目配置.md` 并填值（接入完成）、数据表模板复制为实例落项目数据区（如 运营中心\）
3. **删**：确认 `项目配置.md` 填好后，**删除项目内的本包目录**——安装器不留住户；模板唯一源永远在 works 仓库根这份，要改模板改这份


## 一、本方向接入三步

1. **复制** `项目配置.模板.md` → `项目配置.md`（填本方向值：项目名/主线/仓库/环境/前缀）
2. **复制** `工单库.模板.md` → `处理中心\工单库.md`（起第一张卡；卡格式=机器闸认的形态——2026-09-09 起账本落处理中心）
3. **开工**：设计师立单 → 派单（`派单.模板.md`）→ 程序员施工 → 交付报告（`交付报告.模板.md`）→ 验收 → 审验 → 合 main

## 二、编号前缀（本方向自定义）

| 建议 | 语义 | 启用 |
|---|---|---|
| `<PREFIX>-01` | 本方向第一张卡 | 接入时定（在 项目配置.md 声明）|

- 前缀=载体/方向（每个方向一套，**跨方向禁止混写**）
- 卡号全方向唯一递增；新线启用新前缀先在 `项目配置.md` 登记

## 三、机器闸（统一在 `安卓中国体系建设\审验员\`，单点维护）

| 工具 | 用途 | 跑法（在 `安卓中国体系建设\` 根）|
|---|---|---|
| `sync-orders.mjs --check` | 库解析+DEL 绑定审计 | `node 审验员/sync-orders.mjs --check` |
| `card-phase-audit.cjs` | 卡面 phase 与 git 断裂检查 | `node 审验员/card-phase-audit.cjs` |
| `orders-overview.mjs` | E4 看板投影 | `node 审验员/orders-overview.mjs` |
| `set-status.py` | 卡状态写入闸（唯一改法） | `python 审验员/set-status.py <单号> --phase merged --role designer` |
| `审验.py --manifest` | 交付 manifest 硬闸 | `python 审验员/审验.py --manifest --json` |

> 工具只读本方向 `处理中心\工单库.md`——各方向实例数据互不干扰；工具本体别复制，改工具只改 `安卓中国体系建设\审验员\`（单点模板更新）。

## 四、验收标准（STD）

- 每单 STD 用 `STD.模板.md` 起草 → `gen-std.py <单号> --freeze` 冻结（sha 写卡）
- 冻结后不改判据（改=升版+记录 diff）

## 数据表模板使用说明（2026-09-09 收编自 处理中心\模板\——模板单一源）

> 本包 = **模板唯一源**（流程模板 + 数据表模板两族）。实际数据文件（事件登记表/资产档案表/挂账登记表等）按项目接入时从本包复制生成到项目对应位置，**不随模板分发**（防跨项目串数据）。数据表实例落点：运营中心\（项目数据区，gitignore）——事件登记表/资产档案表；处理中心\——挂账登记表（工单流转机制数据）。

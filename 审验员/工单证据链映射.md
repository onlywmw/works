# 工单 ↔ 证据链 映射（审验员 · AI 抽查依据）

> 用途：第三方 AI 抽查时，按工单号查证据链位置（journal / 截图 / 命令），再审验证据链 + 相关性/合理性。
> 证据根：`验收员\证据数据\`

## 一、工单 → 证据链目录

| 工单 | 证据目录 | 证据链（journal/截图/命令） | 说明 |
|---|---|---|---|
| （暂无工单） | — | — | — |

## 二、AI 抽查用法

```bash
python 审验.py --ticket <工单号> --json    # 抽查某工单证据链 + 相关性合理性
python 审验.py --list                       # 列出有证据的工单
```

（审验脚本未随规则迁移，可按 `证据链规范.md` 自行实现）

## 三、抽查内容（AI 查什么）

### 证据链（journal 工具调用链 + 截图 + 命令）
- journal：工具调用链（时间/动作/结果）——是否真实 tool_call
- 截图：是否有关键界面证据（时间戳）
- 命令：是否有结果/产物输出

### 相关性 / 合理性（输出 problems）
| 检查 | 异常 |
|---|---|
| 证据链断裂 | journal 无工具调用（AI 口头说没真调） |
| 缺证据 | 无截图 / 无命令 |
| 时间不合理 | 截图早于工具调用（疑似伪造） |
| 失败标记 | 命令含 失败/不存在/FAILED |

### 结论
- ✅ 证据链完整，无异常
- ❌ 证据链有问题/疑似造假

## 四、注意
- 部分工单 journal 可能为 0——需结合命令输出判断（AI 不能只看 journal，要查命令/结果文件）
- 证据目录有多个时，审验员应合并查所有
- 抽查结论 → 参考 `工单表.xlsx` 该工单验收状态对照

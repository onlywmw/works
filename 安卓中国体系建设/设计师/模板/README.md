# 设计师（模板说明）

> 设计师 = 工单源头：出方案 → 拆工单 → 派单 → 合 main（唯一）。
> 模板仓库只有**通用模板**（`模板/`）与**工具**（知识库/前端设计）；项目实例（方案设计/派单/契约/设计预览）**不随模板分发**——接入后按需自建。

## 模板清单（`模板/`）

| 文件 | 用途 |
|---|---|
| `工单卡.模板.md` | 立卡模板（卡格式=机器闸认的形态） |
| `派单.模板.md` | 派单文本模板（写清范围/边界/接口/交付物） |
| `STD.模板.md` | 验收标准冻结模板（`gen-std.py` 生成后冻结） |

## 常用工具

- 知识库：`知识库/`（复用件/已知坑——项目接入后复制 `.模板` 建库）
- 看板前端：`前端设计/`（board 生成链，项目无关）
- 合约冻结：`审验员/gen-std.py <单号> --freeze`（写 STD + sha 回卡）

## 设计产出规范（红线）

- 方案/设计文档落 `方案设计/`（按项目建子目录）
- 设计预览落 `设计预览/`（demo 自包含，无外部依赖）
- 派单文本落 `派单/`（文件名 `<前缀>-xx_标题_派单_日期.md`）
- 设计评审：先给作者看 demo/截图 → 拍板 → 才入 STD 冻结

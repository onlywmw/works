## 一、数据契约（L1-7）
- **WorkbenchPins v2**：pin 只存 `{stableId,pinType,preset}`；序列化无 name/icon/kind/page/ui 冗余（断言测试「序列化只含三字段」）；上限 5 截断。
- **v1→v2 迁移幂等**：v1 `{id,name,icon,kind,page,ui}` → `{stableId=v1Id, pinType=BUILTIN/MCP_TOOL, preset=""}`（v1 的 id 即 stableId；page/name/icon 冗余丢弃）；`ui.getPins` 读取时前向迁移写回（幂等）。
- **单写点**：SharedPreferences `workbench_pins`（WorkbenchPins object + ui.getPins/ui.setPins + 卸载 hook + 管理弹层 onChanged，全部经 readPinList/writePinList 同一对函数）。
- **pin_type**：`BUILTIN`（内置 page 类：tasks/orders/vault/memory）/ `MCP_TOOL`（ext.* 工具 / 系统组裸名）。

## 二、注册表实读渲染（CapsuleResolver）
- resolve(stableId,pinType,preset,servers,schema)：name/icon/subtitle/状态从 `LocalOverview.build()` 实读（包改名 → 胶囊自动正确，无旧名残影）。
- 匹配：市场/内置包=`ext.<tag>.<tool>`（tag=包名 sanitize，与 McpMarket.discoverServer 同规则）；系统组（system-core）=裸名。
- 预设链：`pin.preset（用户填/生成）→ 仅 badge=内置 包兜底 presetFor（我方写预设）`；**市场包无用户预设 = 无预设** → 点击进轻量输入面板。
- 状态：OK / DISABLED（本地停用）/ UNREACHABLE（服务端下线）/ REMOVED（卸载/未知）。
- readOnlyHint：perm=free 或 desc/name 词法（只读/纯查询/查询/status/list/read）；本地工具 schema 直达门控（hasRequired）。

## 三、dock 三区 + 交互（MainActivity）
- 常驻（模型 chip + MCP 工具聚合，聚合可见 ⟺ 存在未钉可用工具）/ 钉选（≤5）/「＋」固定管理口（横滑不丢）。
- 点击分派表：BUILTIN→开页（workbench/orders/vault/memory 路由）/ MCP 有预设→回填 / MCP 无预设→轻量输入面板（包内工具列表→点选回填通用句式，不直调工具）。
- 长按菜单：直达执行（资格=有预设 ∧（readOnlyHint ∨ 无必填参）；否则禁用）/ 详情（类型/状态/预设）/ 取消钉选。
- 第三态：停用=变淡+toast 引导；卸载（市场 uninstall hook 清 ext 前缀 pin+释额）；服务端下线=变淡+「不可用」标+toast（pin 保留显示但 `countsTowardLimit=false` 不占新名额）。
- REMOVED 勾稽：renderPinChips 发现卸载/未知工具 → 清数据+释放名额（递归重绘）。

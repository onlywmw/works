## 二、验收锚证据

### A1-1 唯一目录源（双写归零）
- Vue 侧无第二份目录数据：生成器内断言 `Vue 中无 const COMPONENTS = [`、无 `id: 'UI-` 字面量 → 通过。
- Kotlin 侧无第二份业务数据：UiComponentCatalog.kt 全部业务字段由 JSON 渲染。
- 遗留的 `UI-*` 字面量（如 `c['UI-SETTINGS-ROW']`）为**运行时 profile 消费 key + 注释**，非目录表——已逐个核实。

### A1-2 改 schema → 重生成 → Kotlin+Vue 同步
- 「全等」判定=业务字段一致（id/name/kind/prefix/variants/defaultVariant/site/order/provider/semanticType），表示差异（Kotlin 类型定义/注释/import/排版）不算漂移。
- 生成物与手写源 `spec` 区 diff=0；逐条核对业务数据与 HEAD 一致。

### A1-3 手改生成物 → 断言红（亲杀）
- tamper 实测：手写污染写入生成文件 → 重生成覆盖，残留 0。生成器本身 schema 自洽断言（20 条 / 52 档 / order 连续 / default∈variants / kind==semanticType 小写 / site==id 段 / prefix=Resolver 对账）全部通过。

### A1-4 CI 防漂移
- `.github/workflows/upg70-catalog.yml` 已建：checkout → setup-node → `cd 前端设计/mov-vue && npm run gen-ui-catalog && git diff --exit-code` → setup-java 17 → `./gradlew :app:testDebugUnitTest`。合 main 后由 CI 实际执行；本地等价验证 = gen 后 `git diff` 对两个生成物为空（见下节测试记录）。

### A1-5 生成顺序与 order 一致
- `order` 1-20 连续 + id 唯一 + js 投影 `indexOf` 升序断言 → 通过（生成器禁按 id/name 重排，本项为生成器内部硬断言）。

### A2-1 SETTINGS 形态类已在 tokens.css、scoped 无残留
- `tokens.css` 全局规则 8 条：`.srow-card` `.srow-inset` `.stog-pill(+node)` `.stog-text(+node)` `.shead-accent(+title)`，`:deep()` 移除改后代选择器（`.stog-pill .van-switch__node` 等）。
- SettingsPage.vue scoped 内 `.srow|.stog|.shead-` 定义残留 = **0**（grep 实证）。
- 无其他组件定义同前缀形态类（已核实）；tokens.css 由 settings-main.js 全局加载，迁移安全。

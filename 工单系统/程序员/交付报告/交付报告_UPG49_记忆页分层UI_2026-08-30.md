## 三、功能面
- **分层**：已记住前置 + 待确认后置 + 分区标题 + 计数行（共 N 条 · 已记住 X · 待确认 Y）。
- **设为重要**：promote → UI diff（底层 ok 才更新；失败 toast 错误码；成功侧锚测试）。
- **置顶/取消置顶**：memorySetPinned（≤3 原子；PINNED_LIMIT 文案「置顶最多 3 条…」）；行内 📌 徽标 + 操作按钮文案置顶⇄取消置顶。
- **移除 + 5s 撤销**：确认弹窗（承诺文案）→ memoryRemove（tombstone）→ 底部撤销条（倒计时；`MemoryRows.undoExpired` 纯函数判定；旋转 onSaveInstanceState 恢复窗口；RESTORE_EXPIRED 文案）。
- **搜索**：客户端过滤（API 无文本搜索参数，如实申报）；**筛选**：已记住/待确认 chip（单选，同选=全部）。
- **详情**：点击摘要 → 只读字段（状态/首次/最近使用/引用次数）+ 溯源占位（底层暂无字段，不编造）。
- **异常**：加载失败 toast 错误码；门面未就绪兜底文案；空态引导「对话中让 MOV「记住…」」。

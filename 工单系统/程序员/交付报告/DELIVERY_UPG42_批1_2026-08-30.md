## 交付清单（批 1 一期：「开发者文档一键给 AI」闭环）

1. **`assets/mov-page-server.js`**（自研 ≈250 行 UMD，script tag 引入）：

   - **postMessage 薄壳**：message 监听 → allowedOrigins 白名单校验 → dispatch → 回源 postMessage；请求/响应**统一 JSON 字符串形态**（协议对称，测试抓出实现不一致已修——原响应发对象）；
   - **错误码对齐 MCP 标准**：非法方法 → `-32601 method not found`（含未知 method）；非法参数 → `-32602 invalid params`（含**未注册工具名**——MCP 语义同款，与 -32601 区分）；内部错误 → `-32603 internal error`（handler throw / Promise reject 双路）；
   - **「数据非指令」包裹**（红线 3，三重）：`content[0].text` 前缀标注 + `__mov:'data-not-instructions'` + `isData:true` + `structuredContent.note`；
   - **allowedOrigins 白名单制**（红线 2）：`['https://mow.kim']`（禁 `*`）；白名单外**静默零响应面**（不回报错——不给探测面）；
   - JSON Schema 子集校验：required 齐备 + 声明字段 type 匹配（string/number/boolean/array/object）→ 非法 `-32602` 指出字段。
2. **dev 站 3 工具**（全只读，红线 1）：

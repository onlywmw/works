# 外观定制引擎 · 设计 v2（MVP 收敛 · 大神评审后）

> 设计师 @2026-08-30 ｜ 承接 v1(方向对) ｜ 大神:收敛成"窄而完整"核心闭环 → v2 定 MVP 范围。

---

## 〇、一句话
**「外观」= 外观定制引擎(明暗 + 组件形态 + 板块展示 三维度)。v1 只做:两套预设方案(经典/极简)覆盖**核心组件与核心板块**(胶囊/输入框/卡片/工作台/主页dock/市场本地tab),预设整块切、不自由混搭,验证一键切换/持久化/性能——**窄而完整,不做宽而浅**。**

---

## 一、MVP 范围（v2 收敛,大神建议）

### 覆盖(第一梯队)· 核心
| 维度 | 覆盖 |
|---|---|
| **B 组件** | 胶囊 / 输入框(composer)/ 卡片 / 工作台模块卡 |
| **C 板块** | 工作台(布局 full|compact)/ 主页 dock(胶囊集 default|compact)/ 市场-本地 tab(卡片|列表) |

### 后置(第二/三梯队,本 v1 不做)
按钮/列表行/ tab / 弹层 / 开关 / 状态点 / 设置页 / 记忆页 / 侧边栏 等组件与板块。

---

## 二、只做预设,不自由混搭(防配置地狱)
- 用户只选**预设方案**(经典/极简),**不能自由混搭**组件/板块(每维度 A/B 组合会膨胀);
- 明暗是 A 维度**快捷覆盖**(跟随系统/浅/深)可单独选,但组件/板块随预设整块走。

---

## 三、板块展示:预设整块切(不做模块级自配)
- 工作台"显示什么/怎么排"= 预设整块切换(full|compact);**不做模块开关/排序/布局模板**(那接近低代码,留后续"高级自定义")。

---

## 四、配置 schema（v2 定,TS type）
```ts
type AppearanceProfile = {
  id: 'classic' | 'minimal'
  theme: 'system' | 'light' | 'dark'      // A 明暗(可单独覆盖)
  components: {                            // B 组件形态
    chip: 'pill' | 'rounded'
    input: 'soft' | 'outline'
    card: 'elevated' | 'flat'
  }
  sections: {                              // C 板块展示(整块预设)
    workbench: 'full' | 'compact'
    marketLocal: 'cards' | 'list'
    homeDock: 'default' | 'compact'
  }
}
```
- 数据驱动;后续扩展(加组件/板块/方案)清晰。

---

## 五、技术承载（v2 定,不引主题/布局库）
- **组件形态**:CSS 变量 + 根节点 `data-appearance`(或 class)切换(`html[data-appearance="minimal"]` 覆盖组件样式);
- **板块展示**:**纯配置对象**(TS/JSON)+ 条件渲染,组件订阅配置(切换只更新配置引用,不重新挂载/不布局抖动);
- tokens.css(明暗/基础形状,UPG-40):底层,不推翻。

---

## 六、外观项入口（v2 定,升级）
- 设置页「外观」入口 = **明暗快捷三选(跟随系统/浅/深) + 外观方案(经典/极简)选择**;
- 明暗三选作 A 维度快捷覆盖,方案选择切 B+C;不另起一套。

---

## 七、最小验证（v2 补,先原型）
- **先做一个可玩原型**:胶囊样式 A/B + 工作台布局 A/B(两维度)→ 验证一键切换的体验/性能,再扩到全量核心。

---

## 八、可访问性 / 动效
- 极简方案去描边/降对比 → **确认浅/深色下对比度达标(可访问性不丢)**;
- 一键切换允许**轻微过渡**,但不做全 App 大动画(性能/视觉噪音)。

---

## 九、验收测点(v2 收敛)
- **L1**:①两套方案(经典/极简)一键切换 → 核心组件(胶囊/输入框/卡片/工作台卡)随 `data-appearance` 变 ②核心板块(工作台 full|compact / 市场本地 cards|list / 主页dock default|compact)随配置变 ③预设整块切(无自由混搭)④持久化(重启保留)⑤明暗快捷三选(A 可单独覆盖)——侧 schema 断言。
- **L2 真机**:切"极简"→ 胶囊/输入框/工作台/市场本地/主页dock 同步变极简;截图前后对比;切回"经典"恢复;深浅色下极简对比度达标;切换无布局抖动;300 条无卡顿。
- **L3**:tokens+组件 config+板块 config 单源;与 UPG-40(颜色/明暗)/主页胶囊(组件)/设计规范(经典基准)不冲突;`data-appearance` + 配置对象驱动(不引库)。

---

## 十、结论
- v1 方向对(明暗+组件+板块三维度);v2 收敛 **MVP:两套预设(经典/极简)只覆盖核心组件/板块,预设整块切、不混搭、不做模块级自配;不引主题/布局库(数据驱动 data-appearance+配置对象);外观项=明暗三选+方案选择;先最小原型验证**;
- **窄而完整**;可作 MVP 设计基线,转实施。

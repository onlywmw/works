# MOV 安全体系 设计 v1（统一安全层 · 用户体验为先）

> 设计师 @2026-08-31 ｜ 状态：**待大神评审**（用户拍板：**安全体系独立成层、全局重构**，不能散在各模块；**以用户体验为先**、全面、细致，对标国内顶尖）
> 核心：安全**不该牺牲体验**——**无感、隐形、该守才守、透明可撤**。把加密/密钥/权限/敏感分级/门控/审计**领出来做成一套全局安全层**，资产、记忆、凭据、MCP、网络、审批**都接入这同一层**。
> 前置：这层定稿后，`我的资产` 等基于其上立项（挂账-我的资产-待安全体系前置）。

---

## 〇、一句话
**MOV 的安全 = 一套全局安全层**（密钥/权限/分级/门控/审计），**所有数据流和模块都走它**；且**以用户体验为先**——安全做到"用户感觉不到"（本机加密、自动防护、关键才确认、透明可查、可撤销），而不是"越安全越打扰"。

---

## 一、安全目标 + 威胁模型
**要防**：①数据泄露（凭据/记忆/资产明文外泄）②未授权访问（越权读/写）③MCP 恶意（外部工具越权/注入/写敏感）④对外泄密（上传/网络明文）⑤绕过审批（工具被自助放宽）⑥元数据/EXIF 泄露（GPS 等）。
**不防过度**：不为"绝对安全"牺牲流畅/功能/无感体验（这是体验优先的关键平衡）。

---

## 二、设计原则（体验优先 · 六条）
1. **无感默认**：本地加密、本机权限、自动防护——用户**零感知**，绝不弹给用户看技术安全项；
2. **关键才确认**：只有**高敏感/对外/不可逆**的操作才触发确认（审批弹窗·大白话），日常操作零打扰；
3. **透明可查**：用户能看"我的数据去了哪、谁访问过、用了什么"（隐私设置/数据足迹），但**不暴露技术细节**（密钥/算法/分级数字）；
4. **渐进不强迫**：默认安全档自动，用户可上调/下调；不因未配置高级安全而砍功能；
5. **可撤销**：危险/可逆操作带撤销（5s 撤销/二次确认），不"点了就没了"；
6. **安全不破坏功能**：安全是隐形护栏，不影响流畅/可用性/体验（这是国内顶尖的分水岭）。

---

## 三、统一安全架构（五层一套）
```
                      数据流（资产 / 记忆 / 凭据 / MCP / 网络 / 审批）
                                        │
        ┌───────────────┬───────────────┼───────────────┬───────────────┐
        ↓               ↓               ↓               ↓               ↓
   [KMS 密钥/加密]  [权限模型]      [敏感分级]      [门控 gate]     [审计 audit]
   KeyVault(AES-GCM) 主体×资源×操作   公开/内部/机密/绝密  MCP写/工具调/对外  谁·何时·对什么·可撤
   字段/文件/端到端    权限矩阵·默认拒   +字段级sensitive  统一gate决策      不可变日志·可查询
        └───────────────┴───────────────┼───────────────┴───────────────┘
                                        ↓
                              统一安全层（各模块接入·单一入口）
```
- **单一入口**：所有安全决策走一个 `SecurityGate`（不是各模块各自判断）→ 一致、可测、不漂移；
- **各模块接入**：资产 / 记忆 / 凭据 / MCP / 网络 / 审批——都调用这层，**不再各自实现安全**。

## 四、五层详解（细致）

### 4.1 KMS / 密钥与加密
- **KeyVault**（Keystore AES-256/GCM，不可导出）统一管理；**主密钥封装**子密钥（按用途分发：凭据密钥/资产密钥/会话密钥）；
- **加密策略**：字段级（敏感值单独加密）、文件级（资产文件）、端到端（云同步）——**不按"整类"一刀切**，敏感字段自动加密/脱敏；
- **密钥生命周期**：轮换（可配置）、崩溃/换机 → 密钥不可导出、密文不可解（优雅降级提示重录，不崩）；
- **设备内**：本机加密默认开启（零感知），用户无感。

### 4.2 权限模型（一套矩阵）
```
主体(user / 账号 / mcp:xxx / 系统) × 资源(asset / 记忆 / 凭据 / 工具 / 网络) × 操作(读/写/删/执行/分享)
```
- **默认拒绝**；**最少权限**；
- **MCP 权限**：细粒度（哪个 MCP 可读/可写/可执行哪些资源），非全有全无；credential **默拒 MCP 读写出**，仅用户**显式授权**单条才放行；
- **用户授权粒度**：逐条/按类/按次——用户可精确控制，不是"同意一堆"；
- **本机单用户**：首期 user 主体；未来多设备/账号 → 权限矩阵天然扩展。

### 4.3 敏感分级
| 级 | 例 | 加密 | 脱敏 | 展示 | 授权 |
|---|---|---|---|---|---|
| 公开 | 普通资产/无碍元数据 | 明文 | 否 | 正常 | — |
| 内部 | 一般记忆/内容 | 按需 | 否 | 正常 | 本机默认 |
| 机密 | 凭据值/身份/人像 | **必加密** | 脱敏字段 | 掩码/二次确认 | 显式授权 |
| 绝密 | 支付/密钥/生物 | 强加密(独立) | 强脱敏 | 强确认 | 单次显式 |
- **字段级 `sensitive`**：metaSchema 里标敏感字段（EXIF 的 GPS、凭据值）→ 自动脱敏/加密，不整类一刀切；

### 4.4 门控（gate）——统一决策
```
SecurityGate.evaluate(主体, 资源, 操作, 敏感级) → ALLOW / ASK(审批) / DENY / FREE
```
- **工具调用**：permissionTier(gate/ask/free) —— 问/免/拦（已有，迁入统一层）；
- **MCP 写入门控**：白名单 MCP + 敏感资源 → ASK / DENY；
- **对外(上传/网络)门控**：云/外部 → 端到端加密 + 最小化 + 用户知悉；
- **审批授权**：大白话弹窗（已定稿）——只在高敏感/对外/不可逆触发；
- 决策**可解释**（为什么问/为什么拦），不给用户黑盒拒绝。

### 4.5 审计 / 可撤销
- **不可变审计日志**（谁·何时·对什么·读了什么/写了什么·授权原由）——可追溯；
- **可撤销**：授权/写入可撤（用户撤销后不再生效）；危险操作带 5s 撤销；
- **可查询**：用户可在隐私设置看**数据足迹**（"哪些数据被谁用了"）——透明但不打扰；
- 审计与 Memory Timeline 呼应（记忆变迁账本）——统一"不可变留痕"。

## 五、用户体验设计（核心 · 体验为先）

### 5.0 审批弹窗（安全确认）——体验的核心 · 最直观触点
> **安全层对用户唯一的主动触碰就是审批弹窗**（其余全无感）。用户对"MOV 安全好不好"的判断几乎全来自这一次弹窗——它值得做到**极致**。对标已用户确认的 demo v4 视觉 + 大白话三原则。

**出现时机（该守才守，绝不日常弹）**：仅**高敏感 / 对外 / 不可逆 / 写类**操作触发；free 级直接放行，日常零弹窗。

**直觉结构（四块 · 秒懂）**：
```
① 发生了什么      📝 AI 想帮你保存这份会议纪要      ← 最大字·视觉主体·一句人话
② 具体对象        保存为 `会议纪要.md` / 发给张三"改到3点" ← 次级·参数人话化
③ 授权操作        [ 同意 ]   [ 拒绝 ]              ← 视觉中心·weight 最大
④ 辅助小字(灰)    30s 后自动取消 · 本次会记录到安全日志
                  ☐ 本次对话中,之后类似操作自动同意
```

**体验红线（审批弹窗）**：
- **秒懂**：一句话人话讲"要做什么/影响什么"，**零技术黑话**（不出现 `shell.exec`/`command=`）；
- **不吓人**：不恐慌文案（不"危险⚠️/警告"），讲"它想帮你做什么、会动到哪"——安抚式而非恐吓式；
- **直觉**：同意/拒绝一目了然，默认安全；不用想"点了会不会出事"；
- **给掌控**：拒绝=这次不做（**不降级**）；同意=放心（讲明白后果）；可"**本次 / 始终同类同意**"（少弹）；
- **轻量不打扰**：只一次；**30s 自动取消**（安全兜底）；同类合并（同类同意，不重复弹）；
- **优雅**：视觉对齐 demo v4（已用户确认）；动效 `--dur-base`；不突兀、不打断思绪；
- **可解释**：需要时能看"为什么问"（来源/触发的工具）——透明但不黑盒。

> **这一条是"安全体验"的定海神针**：其它安全都无感，唯有这次弹窗用户会认真看——它符合预期、不吓人、可掌控、不频繁，用户就对 MOV 的安全放心（并愿意信任 system 继续授权）。

---

> 安全**不打扰**是灵魂——用户几乎感觉不到安全，但数据被好好保护。

| 场景 | 体验 | 说明 |
|---|---|---|
| 本机数据/凭据 | **无感** | 自动加密，用户零感知不用管 |
| 日常 MCP/工具调用 | **无感** | free 级直接放行，不弹窗 |
| 敏感/对外/写操作 | **一键确认**（大白话） | 只在"该守"时弹一次，说明白（做什么/影响什么），同意/拒绝 |
| 拒绝 | 不降级 | 拒绝仅是这次不做，不影响功能 |
| 可逆操作（删/撤） | **5s 撤销** | 不留"点了就没了"的恐惧 |
| 数据足迹 | **可查不打扰** | 隐私设置里看，不主动弹 |
| 密钥/换机 | **优雅降级** | 换机提示"重新录入"，不崩不漏 |
| 危险动作 | **二次确认** | 删除/支付/高敏感 → 确认+可撤 |

**体验红线**：绝不为安全做这些——频繁弹窗打断、强制全高安全档、暴露技术安全数字、因安全砍功能、把简单操作变复杂。**安全做到"用户感觉不到但数据安全"才是顶尖**（对标微信/支付宝的"无感安全"）。

| **网络/上传** | 端到端加密 + 最小化 + 门控(对外) |
| **审批** | gate(ask/free) 迁入统一层 + 大白话弹窗 + 审计 |

## 七、用户可见（克制披露）
- 用户**只会看到**：必要时刻的一次确认（大白话）、隐私设置里的"数据足迹/数据管理"、危险操作的撤销；
- **不会看到**：密钥/算法/分级/权限矩阵等任何技术细节；不推送安全惊吓文案；
- 安全是**隐形护栏**，不是屏幕上的"安全设置大礼包"。

---

## 八、验收测点（安全 + 体验 · L1/L2/L3）
- **L1 安全契约**：①KeyVault(AES-GCM)不可导出、字段/文件加密 ②权限矩阵主体×资源×操作：默认拒、MCP 细粒度、credential 默拒 MCP ③敏感分级：机密必加密、字段级 sensitive 脱敏 ④SecurityGate 单一入口（变异：模块绕 gate→必红）⑤审计不可变、可查、可撤 ⑥端到端加密(云)。
- **L2 用户体验（核心）**：①本机数据无感（无任何弹窗/提示）②free 级 MCP/工具无感放行 ③敏感/对外 → **一次大白话确认**（说明白、同意/拒绝）④拒绝不降级 ⑤删除/危险 → 5s 撤销 ⑥数据足迹可查不打扰 ⑦无技术安全信息暴露 ⑧安全不破坏流畅/功能（用户操作路径不被安全打断）。
- **L3 统一接入**：资产/记忆/凭据/MCP/网络/审批 全走 SecurityGate（依赖检查/契约测试）；权限矩阵一致性；审计可追溯。

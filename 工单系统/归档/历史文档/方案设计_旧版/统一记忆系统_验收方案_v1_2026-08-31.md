## 〇、一句话验收基准
**验证 Memory OS 是否兑现 4 条铁律 + 3 处收口**（Event≠Memory / Current·History immutable / 记忆无限存储·知识有限暴露；删除复活屏蔽 / Timeline×Semantic 管辖 / 冻结接缝+参数版本化），并保证**碎片层+语义层"三层隔离、memory-api 零改"**。

---

## 一、定级（三层验收维度）
| 层 | 对象 | 判定 | 最低覆盖 |
|---|---|---|---|
| **L1** | 契约/纯逻辑（状态机/屏蔽/派生/不可变/预算/读写约束） | 单测 + 变异锚逐项 | 全项 + 变异锚全绿 |
| **L2** | 真机用户路径（碎片→候选→采纳→入池→Re-evaluate→◌→Archive；时间线只读；检索上下文） | 真机截图 + 行为证据 | 全部核心路径 |
| **L3** | 转可执行（隔离/依赖检查/只读约束/原子写入一致性/append-only） | 契约测试 + 依赖检查 | 架构约束项 |

## 二、验收测点（含证据判据 + 变异锚）

### A. 删除复活屏蔽（P0-1 · 结构保证，最高优先）
| # | 测点 | 证据（怎么验） | 变异锚（改回旧实现必红） |
|---|---|---|---|
| A1 | 删除记忆 ⇒ 记录 `blockedSourceHashes` | 断言删除后 Entity/屏蔽表含该 sourceHash | 删屏蔽记录 → 必红 |
| A2 | 候选生成/Pattern Detection **过滤 blockedSourceHash 派生** | 构造"删后重复同源行为"序列 ⇒ 该内容不再进候选/Semantic | 移除过滤 → 候选复活 → 必红 |
| A3 | 移除 IN_POOL 碎片 → 池内副本被挡派生 ⇒ 标 ARCHIVED/RE-EVALUATE | 移除后池内条目状态迁移 | 池内副本仍 ACTIVE → 必红 |
| A4 | purge 逃生口：人类触发可标记彻底抹除 | `purge(subject)` ⇒ 记录 + 结果数据打标（历史可标注不可改） | 无 purge 接口 → 必红 |

### B. Timeline 不可变 + 管辖（P0-2 / 铁律②）
| # | 测点 | 证据 | 变异锚 |
|---|---|---|---|
| B1 | Semantic 状态变更 ⇒ Timeline 必有**同事务 append**（原子一致） | Semantic 变、Timeline 必增；中断注入不半写 | 只改 Semantic 忘 append → 必红 |
| B2 | Timeline 仅 append；`UPDATE/DELETE/REWRITE` 无入口（连 dev 无 `delete/update`） | repo 无 `timeline.update/delete` 变体方法；只能 append | 暴露 update/delete → 必红 |
| B3 | **actor 审计**：AI 只 `PROPOSED`；`ACCEPTED/REJECTED/ARCHIVED` actor=user | 断言 ai-proposal 不能产出 ACCEPTED | ai-proposal 写 ACCEPTED → 必红 |
| B4 | Correction 追加不改旧条 | 判错 ⇒ append CORRECTION，旧条原样 | 就地改旧条 → 必红 |
| B5 | 碎片 promote/remove/pin **不** append Semantic Timeline（诚实声明，走 Event/碎片 journal 或后续 hook） | 现状：碎片层行为不产生 Semantic Timeline 条目 | 误 append → 必红（按当前声明） |

### C. 检索消费层（铁律③ 知识有限暴露）
| # | 测点 | 证据 | 变异锚 |
|---|---|---|---|
| C1 | **Retrieval 只读** | 检索路径只读存储、无写调用 | 检索写库 → 必红 |
| C2 | Router **默认 Core + Semantic**；intent→层（progress→Event/Episodic、historical→Timeline、personalization→Core+Semantic+Episodic） | 断言默认信道 + 各 intent 落层 | historical 走 Semantic → 必红 |
| C3 | **预算裁剪**（Core 全量 < 阈值；超阈值 → Index + Top-K；总额 Runtime 控） | 超预算上下文被裁 | 超预算注入 → 必红 |
| C4 | Compose **每段带来源**（层 + 溯源 id） | 上下文每块附 source 标签 | 缺来源 → 必红 |
| C5 | **Index / Core 为派生**（由 Semantic 元数据投影，非 LLM 重写） | 断言 Core 由 `type×importance×预算` 规则稳定选出条目原文拼接 | LLM 自由造短语写 Core → 必红 |
| C6 | TimLine/Event **不走 Index**（按时间/actor 直查） | Index 不含 Timeline/Event | Index 含 Timeline → 必红 |

### D. 生命周期 + 类型/冲突（表1/2/3 + 生命链）
| # | 测点 | 证据 | 变异锚 |
|---|---|---|---|
| D1 | 生命链每转移 = Semantic 变更 + Timeline 记账；含**死亡路径**（TOMBSTONE/移除、Archive≠删除） | 状态转移日志 | 漏记/无 Archive 出口 → 必红 |
| D2 | 冲突（同类型互斥）⇒ RE-EVALUATE 待人工；跨类型不冲突；Observed≠Inferred 只候选 | Conflict Matrix 逐断 | 冲突条目直接注入（不 RE-EVALUATE）→ 必红 |
| D3 | 跨层冲突（新事件/碎片 vs 池内条目）⇒ 池内条目 RE-EVALUATE | 构造跨层矛盾 | 跨层冲突被忽略 → 必红 |
| D4 | 人工确认检查点：AI 只提议、人裁决才动库 | 变异：AI 擅自改库→必红 | 已含 |
| D5 | `memoryType` 生命周期差异（STATE 快 / IDENTITY 极慢） | decay 按类型生效 | 一刀切衰减 → 必红 |
| D6 | freshness **运行时派生**（decayPolicy+lastVerifiedAt 现算，不存死）/ 不暴露 UI | 改 decayPolicy ⇒ freshness 变；UI 无 confidence/score | 存死值 / 暴露数字 → 必红 |

### E. 三层隔离（L3）
| # | 测点 | 证据 | 变异锚 |
|---|---|---|---|
| E1 | 碎片层（Episodic）/语义层（Semantic）隔离；`memory-api` 零改 | 改造只动 memoryPool/Semantic；依赖检查/契约测试 | 动 memory-api → 必红 |
| E2 | Semantic 对 AI 只读 | AI 无写 Semantic 路径 | AI 写库 → 必红 |
| E3 | Event Store append-only（只增不改） | 无 update/delete | 提供删除 → 必红 |
| E4 | Index/Core 派生一致性（Semantic 变 ⇒ 重投影一致） | 派生重建后差异 0 | 不同步 → 必红 |

## 三、真机取证（L2 · 用户可见路径）
用**真机截图 + 行为证据**逐条验证，记录落 `ACCEPTANCE_LOG`：
1. 看剧/听歌 → Event 记痕 → Episodic 出现「正在看黑镜」；
2. 重复偏好 → **候选 → 建议 → 用户采纳 → `关于我.md`**；
3. 旧偏好（长期未验）→ **◌ 待确认 → 点进「[是][不是]」→ 更新 / 保历史(ARCHIVED)**；
4. **记忆时间线只读页**：能看到「喜欢晴天→听A→变B」的变化（只读，无编辑入口）；
5. 对话「按我习惯拆项目」→ 上下文**很相关、很少、可解释来源**（Router 取 Core+Semantic+Episodic）；
6. 对话「去年我最喜欢什么」→ 走**历史信道**（Timeline），常规对话**不**带 Timeline；
7. 用户能分清「我的记忆 ↔ 记忆库」从属；▼ 界面无 `confidence/decay 天数` 数字；
8. **空库**：新用户/无记忆 → 行为零影响（无报错、不注入）。
> 判据：每项能出**截图/回放**佐证；模糊或"好像可以"不算过。

---

## 四、Token / Key / 隐私申报
- **隐私铁律级**：Event Store 为监控级数据——**本地/加密/可导出/可删/purge**；上真机验证不漏明文（`git grep sk-`/`key` 零命中）；
- **Token 成本**：候选/Core 一次性工具级；审预算裁剪（C3）后为常低（几 KB）；申报随单。

## 五、通过标准
- **L1**：A/B/C/D/E 全项通过 + **变异锚全绿**（改回旧实现/删判定 必红，防"看起来工作实状态没变"）；

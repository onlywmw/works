## 〇、一句话
主页输入框上方胶囊区 = **三区模型**:常驻区(模型chip + MCP工具聚合,不计上限)/ 钉选区(≤5 用户主动钉选能力)/ 管理区(末尾「＋」固定,就地管理)。内置能力与第三方 MCP 工具**都能单独钉成独立胶囊**;「MCP 工具」胶囊 = 未单独钉的工具聚合入口(空态隐藏)。

---

## 一、三区模型（v2 定案,解决"容量/占位"）

```
┌ 横滑 ──────────────────┐  ← 常驻区+钉选区 可横滑;「＋」固定不滚
│ 常驻区(不计上限): [模型chip] [MCP 工具]          │
│ 钉选区(≤5):       [订单] [🚄12306] [Obsidian]   │
│ 管理区(固定):     [＋]                           │
└───────────────────────┘
```
- **常驻区**：模型 chip（缩写）+ 「MCP 工具」聚合入口——**不计入用户钉选上限**;
- **钉选区**：最多 5 个用户主动钉选的能力（内置 + MCP 独立胶囊），默认**按添加时间倒序**（用户可拖动自定义）;
- **管理区**：末尾「＋」**固定**在可视区末尾（常驻/钉选可横滑，＋不滚，用户始终能找到管理口）。

---

## 二、MCP 工具聚合胶囊：空态与隐藏（v2 补）

- 「MCP 工具」胶囊 = **未单独钉的工具聚合入口**（保留,不可去掉——否则未钉工具不可达）;
- **空态隐藏**：当**所有** MCP 工具都被单独钉出 → 「MCP 工具」胶囊**隐藏**;在「＋」管理弹层保留「打开 MCP 工具列表」次级入口;
- 有未钉工具 → 胶囊自动恢复。

---

## 三、MCP 独立胶囊点击行为（v2 定案,二选一）

**默认 = 预设指令回填**(与内置钉选一致/低风险/用户二次确认)——理由:①与现有一致不学两套 ②直达触发副作用误触 ③回填后二次确认符合对话安全边界;
- **无预设指令的 MCP 工具** → 点击打开该工具**轻量输入面板**(不直接执行);
- 直达工具 = **长按**提供（二级操作,非默认）。


- **实时 dock 预览**(弹层内缩略显示 dock 当前样子);
- **空态**(某分组无项)/ **停用/卸载提示**(见下);
- 「打开 MCP 工具列表」次级入口(聚合空态时可达未钉工具)。

## 五、停用/卸载状态（v2 明确,两种分开）

| 状态 | dock 表现 | 点击 | 管理弹层 |
|---|---|---|---|
| **停用**(enabled=false) | 胶囊**变淡** | toast「该工具已停用，去本地 tab 启用」 | 标记"已停用" |
| **卸载**(工具删除) | 从 dock **直接移除** | — | 标记"已卸载"或从列表消失 |

> 统一规则:**停用 ≠ 卸载**——停用变淡可再启用;卸载移除,无残留。

## 一、C 端语言 vs API 语言（词表唯一）

| 内部模型(API) | C 端文案 | 说明 |
|---|---|---|
| DRAFT | **待确认** | 不说"草稿"（用户误解为"写一半没保存"） |
| ACTIVE | **已记住** | 不说"已固化/草稿已确认"（系统语言） |
| promote | **设为重要** | 不说"晋升"（黑话）；底层 `memoryPromote` 不变 |
| pinned | **置顶** | 不说"固定"；= 排序，与"重要(=生命周期)"区分 |
| tombstone(remove后) | 承诺"**移除后不再使用此条**" | 不承诺语义拦截相似内容（语义 tombstone 待定） |

> 术语唯一：用户可见中文 = 待确认 / 已记住 / 设为重要 / 置顶 / 移除；API 参数 = ACTIVE / DRAFT / promote / pinned / tombstone。**严禁黑话进 UI**；产品语言 ≠ API 语言。

## 三、操作集 ↔ 契约 API（P0-1 对齐表 · 无遗漏）

| UI 操作 | 契约 API | 底层 | 边界 |
|---|---|---|---|
| 展示 / 分页 / 分层 | `memoryList(filter,cursor,page=30)` | Store | facets 精确计数；ACTIVE `pinned DESC,lastUsedAt DESC` / DRAFT `pinned DESC,createdAt DESC` |
| 搜索（内容 + 标签） | `memoryList` + 命中过滤 / 高亮 | Store+预留FTS | 正则转义 |
| 设为重要 | `memoryPromote(id)` | Lifecycle | 失败回滚 / 与 judge 竞态 diff |
| 置顶 / 取消置顶 | `memorySetPinned(id,value)` | PinnedStore | 上限 3：**API 拒(PINNED_LIMIT) + UI 禁第 4 个** 双保险 |
| 移除 | `memoryRemove(id)` | tombstone **立即落库** | 5s 撤销=UI |
| 撤销 | `memoryRestore(id)` | previousStatus+Pinned | 恢复完整状态 |
| 详情 | `memoryGetDetail(id)` | Store | refCount 暂不展示(调试) |
| 标签 · 改 | `memorySetTags(id,tags)` | entity.tags | 规范化；人工标记 |
| 标签 · 全量(预留,M2) | `memoryListTags()` | entity | UI 先不做 |

> **契约清单与 UI 操作集一一对应，无"按钮无契约入口"**。追加契约 = 须在本表登记。

## 四、契约（吸收 v4 + 标签 v4.1）

### 4.1 状态机（幂等 / 冲突）
| 操作 \ 当前态 | DRAFT | ACTIVE | TOMBSTONE |
|---|---|---|---|
| promote(设为重要) | ok→ACTIVE | ok(幂等) | NOT_FOUND |
| remove(移除) | ok→tomb | ok→tomb | ok(幂等) |
| restore(撤销) | BAD_STATE | ok(幂等) | ok→回原态 / RESTORE_EXPIRED |
| setPinned(置顶) | ok | ok | NOT_FOUND |

- **restore 恢复完整状态（冻结①）**：tombstone 保存 `previousStatus + previousPinned`；restore 成功 → 恢复「被移除前完整状态 + UI 元数据」——原 `ACTIVE+pinned` 则回 `ACTIVE+pinned`；
- 错误码三分类：失败回滚（TIMEOUT/UNKNOWN/RESTORE_EXPIRED/BAD_STATE）｜ 冲突 diff（NOT_FOUND）｜ 业务拒绝（PINNED_LIMIT/SYNC_TOKEN_INVALID）。

### 4.2 统一 Envelope（冻结④）
`{ok, code, data, syncToken, seq}`；UI 只判 `ok/code`；成功=ok:true+code:OK。

### 4.3 API 表
（`memoryList / memoryGetDetail / memoryPromote / memoryRemove / memoryRestore / memorySetPinned / memoryChanges` 同 v4；新增标签）
- `memorySetTags(id, tags: List<String>)` → code OK / `BAD_TAG`；
- `memoryList` / `memoryGetDetail` 返回体 `ListItem`/`DetailData` 加 **`tags: List<String>`**；
- `memoryList(filter, tag, …)` 预留按 tag 过滤；`memoryListTags()` 返回全量 tag（M2）；
- `memoryGetDetail` 加 `tagsTouchedByUser`？（否——**内部字段不入 API**，见 §4.5）。

### 4.4 规则契约
- **pinned 归属（定案）**：pinned 持久化在 **memory-api 门面层独立 `PinnedStore`(pinned.json)**，core/MemoryLifecycle **零感知**；list 组装 join 排序；**不进 MemoryEntity / 记忆 DB**。三规则：①置顶条移除→清理释放名额 ②草稿晋升→保持置顶 ③上限 3 = **原子 check-and-set**（API 拒 PINNED_LIMIT + UI 禁第 4，双保险）；
- **tombstone（定案·冻结②）**：`remove` **立即生效**（tombstone 即刻落库，AI 立即不再用）；**5s 撤销只是 UI**（Snackbar→restore）；**不要**做成"5s 后才 tombstone"；只承诺"不再使用此条"；
- **连续移除两条**（新增定案）：撤销条**替换**——只保留最近一条可撤销，旧一条**立即生效不可撤销**。

### 4.5 标签契约（v4.1 · 人工不被覆盖可测）
- `MemoryEntity` + `tags: List<String>`（默认空）+ **内部 `tagsTouchedByUser: Boolean`（默认 false，不入 ListItem/API，仅内部护栏）**；
- **迁移**：旧实体缺 tags/tagsTouchedByUser → 默认 空/false，**不丢已有记忆**（向后兼容）；
- `memorySetTags(id,tags)`：**规范化**（trim / 去重 / 单条 ≤8 字 / 数量 ≤5）→ 写入 → `tagsTouchedByUser=true`；
- **AI 打标**：仅**晋升点单次**执行，且条件 `!tagsTouchedByUser && tags.isEmpty()`；落库前**重查该条件**（防竞态）；LLM 不可用/低置信 → tags 空，**零编造**；
- 效果：用户**清空**标签后 `tagsTouchedByUser=true` → AI 不再填回，**L1"人工不被 AI 重覆盖"有可测机制**。

## 五、异常路径
- **晋升**：失败/超时 → 回滚 + 提示；与自动 judge 竞态 → 底层为准 diff（不乐观写死）；防抖 loading 防重复；
- **移除**：tombstone 立即落库 → 5s 撤销条；restore 失败（RESTORE_EXPIRED）→ 提示"已超时不可撤销"；恢复回**原位**；
- **标签竞态**：人工清空 vs AI 打标任务 → `tagsTouchedByUser` 护栏 + 落库前重查；
- **搜索**：关键词正则转义（含 `<`/`(` 等）；命中标签但一级不显示 → 搜索态显示命中 tag pill；
- **自动晋升**（引用≥2 触发）：条目从待确认 "消失" → **数据驱动 diff**，刷新不丢滚动（300 条真机最易暴露）。

## 六、Sheet 形态（半屏 · 与设置页同形态）
- **容器**：`BottomSheetDialog`，`STATE_EXPANDED`，**70% 屏高**，顶部圆角 **16**（§三 容器16）+ clipToOutline；底色 `S0`（浅 #F3F4F7，暗色 S0_DARK 跟随 uiMode）；进场 `--dur-base 200ms --ease-decelerate`；
- **顶部**：手柄条 44×5 灰居中 + 标题「我的记忆」17/600 居中 + 计数副行 12px TEXT3；
- **搜索框**：圆角 8、高 40、s1 白底 + line 描边 + 左放大镜 icon；
- **一级**：分组并列（已记住 / 待确认），行 = content + 副题 + `›`，无卡片/状态点/标签（搜索态除外）；行高 ≥44（a11y）；间距 12/16（4 倍数）；
- **二级**：详情（可滚动）+ 标签区（灰底 pill + 增删，可滚动）+ 操作文字钮；
- **撤销条**：深色 `#2E333B` 圆角 8 上浮贴 safe-bottom（§十 安全区），白字 + 撤销钮；
- **行为变更**（明示）：①相较 v3/v4 的分段切换/卡片/状态点，回归极简（分组并列/扁平行/无状态点）②**撤销不跨旋转**：Sheet 为短生命周期弹层，旋转/关闭 = 视为**提前确认移除**（半屏语义收敛；若确要"旋转不失效"→ 撤销态需提到宿主 Activity/ViewModel 层，另作评估）。

## 七、标签（AI 自动打标 + 二级手动改）
- **定位**：与生命周期（已记住/待确认）、排序（置顶/重要）**正交的第三维度 = 发现**；**不占名额**（区别于置顶 ≤3）；AI 默认 1-2 个、克制（≤6 字）；
- **AI 打标**：晋升点**异步**、依 content 提炼、**禁凭空加**（UPG-06 确定性防编造）、LLM 不可用 → 空（零编造）；
- **人工改**：二级详情标签区增删改；**人工改不被 AI 重覆盖**（`tagsTouchedByUser`，§4.5）；
- **迁移**：旧实体无 tags → 渲染空，不丢数据；
- **隐私**：打标**跟随主对话同一 LLM 管道 / 授权口径**，不新增独立数据出口；
- **搜索**：命中标签（content+tags 匹配），一级搜索态显示命中 tag pill。

## 八、数据留口 + 埋点
- **留口**：`last_referenced` / `last_verified` + 状态（active→stale/superseded 复核留口）；晋升时文本级查重提示；「使用」回填对话（数据结构保留原文/时间/来源 + FTS/embedding 检索位）；
- **埋点**：晋升率 / 草稿平均停留 / 移除率（含撤销率）/ 搜索空搜率 / 置顶使用率 / 标签打标率——验证"分层 + 标签真有用"。

## 九、验收测点
### L1（契约 + 逻辑）
状态机逐格幂等；restore 恢复完整状态；置顶 ≤3（API 拒 + UI 禁第 4，无缺口）；置顶移除释额 / 草稿晋升保持置顶；tombstone **立即**（崩溃安全）；**契约清单 = UI 操作集，无遗漏**；错误码 → 文案映射；标签：①**正常 LLM → 打标非空且 ≤2、词来自 content** ②人工改不被 AI 重覆盖 ③**手动清空后 AI 不重填** ④旧实体渲染空（迁移） ⑤setTags 规范化（trim/去重/≤8字/≤5） ⑥搜索命中标签 ⑦**LLM 不可用 → 空标签零编造** ⑧`pinned` 独立 PinnedStore、不进 DB。**打标①⑦为两个独立场景，不混述**。

### L2（真机）
半屏 Sheet 70% / 下滑关闭 / 无控件堆叠；一级扫可读（无卡片/状态点/标签）；二级详情（含标签区）可滚动；撤销条（**Sheet 旋转 = 视为确认移除**，测点同步）；空态两种（整体 / 单 segment）；搜索命中标签显示 tag pill；暗色跟随；safe-bottom 贴底；300 条冷启动 **<2s（不含进场动画）**。

### L3（转可执行）
呈现层**只依赖 memory-api 门面**（依赖检查 / 契约测试，非口号）；`entity.tags` 单源 + `tagsTouchedByUser` 为内部护栏；`pinned` 独立 PinnedStore（不进 DB）；AI 打标与记忆主链**解耦**（fail 不影响记忆可用/调出）。

# 我的记忆 · 分层管理 设计 v1

> 设计师 @2026-08-30 ｜ 状态：**设计稿（用户拍板"记忆要分层管理"）**
> 演示：`设计预览\记忆分层管理_demo.html`
> 底层依据：UPG-05 记忆体系（已固化=晋升 / 草稿=draft / 移除=tombstone / 晋升阈值/14 天衰减已定）

---

## 〇、一句话

**把「我的记忆」从"平铺三行字+只能删"改成「分层管理」——按「已固化 / 草稿」分层分区呈现，每层有自己的管理动作（移除/固定/晋升），文案去技术术语，加搜索 + 视图切换。**

---

## 一、背景（现状问题, `MemoryPageActivity`）

当前记忆页是原生 LinearLayout 平铺：标题「记忆管理」+ 计数行 + 每条三行字（状态【已固化/草稿】·kind · 引用 N 次 / 摘要 / 时间·来源）+ 移除确认。问题：
1. **文案技术术语化**：`kind`/`引用 N 次` 普通用户看不懂；
2. **无分层分区**：已固化/草稿只靠【】+颜色区分，扫读难；
3. **无搜索/视图切换**：记忆多了（N 条）难找；
4. **功能单一**：只有「移除」，无固定/晋升等管理动作。

---

## 二、分层模型（基于 UPG-05 记忆体系）

| 层 | 语义 | 呈现 | 管理动作 |
|---|---|---|---|
| **已固化**（晋升） | 被反复使用/引用≥2，重要、长期 | 摘要 + 状态标 + 来源/时间；可置顶 | **固定/取消固定**、移除 |
| **草稿**（draft） | 刚让 AI 记的，待整理 | 摘要**默认折叠**（隐私心理设计落点） | **晋升**（→固化）、移除 |
| （可选扩展）**基因/偏好** | 从固化提取的行为特征 | — | 待定（本次不做） |

- 分层语义来自 UPG-05（draft→晋升→固化，tombstone 移除已定）；本设计只重**呈现层**（UI 分组/操作），不动记忆底层。

---

## 三、界面结构

```
我的记忆
🔍 搜索记忆…
[ 全部 | 已固化 | 草稿 ]        ← 视图切换(可筛)

📌 已固化  [重要·长期]   2 条
  🍎 对花生过敏，规划餐食要避开
     ★已固定 · 来自「健康饮食」对话
     [取消固定]  [移除]
  🏃 每周三晚上健身，周末晨跑

📝 草稿  [待整理]    3 条
  📌 下周要交季度报告…
     [晋升]  [移除]
```

## 四、操作集（去掉「复制」——记忆是查看/管理，非复制素材）

| 操作 | 层 | 说明 |
|---|---|---|
| **移除** | 两层 | 删除（tombstone 压制，隐私）——方案 UI 动词定"移除" |
| **固定 / 取消固定** | 已固化 | 常用记忆置顶 |
| **晋升** | 草稿 | 草稿→已固化（分层管理核心） |

> 待定：**「使用」**（把记忆回填到当前对话让 AI 用它）/ **「编辑」**（记错了改内容, 方案后续批）——是否加由用户/大神拍板。

## 五、文案规范（去技术术语）

- 状态：`已固化` / `草稿`（不用 kind）；
- 来源：`来自「XX」对话 · 3 天前`（不用 session 尾号 / 引用计数）；
- 避免 `引用 N 次` 等术语——用户只关心"这条是什么、什么时候、哪来的"。

## 六、验收测点

- **L1**：①已固化/草稿分层呈现（含各层标签/计数）②视图切换（全部/已固化/草稿）正确筛选 ③操作：移除走 tombstone（journal 落）、晋升（草稿→固化）、固定/取消固定 ④搜索可达 ⑤去技术术语文案（无 kind/引用次数字样）。
- **L2 真机**：多记忆（300 条种子）分层清晰可扫；移除即时消失 + 落 journal；晋升后从草稿位移到已固化；固定后置顶；冷启动 <2s 保持；截图存证。
- **L3**：与 UPG-05 记忆底层零冲突（呈现层只在 UI 分组/入口/操作，不动 MemoryLifecycle/聚合）。

## 七、待定 / 决策点

1. 「**使用**」动作——把记忆回填当前对话（AI 据此处理），要不要加？
2. 「**编辑**」——记错了改内容（方案后续批），本次是否纳入？
3. 是否加第三层「**基因/偏好**」（行为特征）作独立分组？
4. 入口：设置页「我的记忆」行（ui.openMemory）保持，标题「**我的记忆**」（当前为「记忆管理」，统一口径）。

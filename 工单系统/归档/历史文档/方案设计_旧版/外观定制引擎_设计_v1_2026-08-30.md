# 外观定制引擎 · 设计 v1（组件 / 板块级 一键切换）

> 设计师 @2026-08-30 ｜ 状态：待确认/评审 ｜ 依据：主仓库实码(UPG-40 换肤标准/tokens.css/设计规范) + 用户愿景
> 用户:「我要每个组件和 UI 板块都能变化——改胶囊样式、输入框样式、工作台展示什么,一键更改。」

---

## 〇、一句话
**「外观」不只是明暗,而是「外观定制引擎」:明暗主题 + 组件形态(胶囊/输入框/按钮/卡片)+ 板块展示(工作台/市场/本地 tab 显示什么、怎么排)三个维度,每维度若干预设方案,一键切换、全 App 即时生效、持久化。换皮肤=换它的明暗+组件形态;换"风格方案"=连带板块展示一起切。**

---

## 一、愿景拆解（用户要"每个组件和板块都能变,一键切换"）

| 维度 | 可变的 | 例子 |
|---|---|---|
| **A 明暗** | 浅/深(现有 tokens) | 跟随系统/浅/深 |
| **B 组件形态** | 胶囊/输入框/按钮/卡片/列表的**形状、尺度、密度** | 胶囊:全圆胶囊 vs 圆角方钮;输入框:大圆角 vs 小圆角/带底色;卡片:有描边 vs 无描边浮起;列表:分组 vs 纯分隔线 |
| **C 板块展示** | 各页面**显示什么内容、排什么布局** | 工作台:显示哪些模块卡(任务/记忆/能力)/排列;市场本地 tab:概览卡+分组 vs 纯列表;主页 dock:哪些胶囊/形态 |

**核心:一键切换 = 应用一套"外观方案"**(A+B+C 组合),覆盖全 App 对应组件/板块。

---

## 二、机制

### 1. 三层配置（单源,分层）
```
外观方案(AppearanceProfile)  ← 用户选的一套(如"经典"/"极简"/"功能全")
    ├─ 明暗:  (SYSTEM/LIGHT/DARK)            → tokens.css 浅/深
    ├─ 组件:  {胶囊:胶囊|方钮, 输入框:…, 卡片:…, 列表:…}   → 组件级 class/config
    └─ 板块:  {工作台:模块集+布局, 市场本地:形态, 主页dock:胶囊集} → 布局配置
```
- **tokens.css**(颜色/形状 token)→ 明暗 + 基础形状(已有 UPG-40);
- **组件 config**(胶囊/输入框/卡片/列表 的几何/密度)→ 组件模板切换;
- **板块 config**(工作台/市场/本地/主页 dock 的显示集与布局)→ 页面渲染。

### 2. 一键切换
- 用户选「外观方案」(预设套:经典/极简/功能全)→ 应用 A+B+C,即时生效(所到组件/板块全变);
- 持久化;重启保留;跟随系统(明暗)可单独覆盖。

### 3. 预设方案（MVP 建议两套起步）
| 方案 | 明暗 | 组件 | 板块 |
|---|---|---|---|
| **经典(默认)** | 跟随系统 | 现有胶囊/输入框/卡片 | 现有展示 |
| **极简** | 跟随系统 | 胶囊更紧凑/输入框更素/卡片去描边 | 工作台精简(只核心模块)/本地 tab 纯列表 |
| (扩展)功能全 | — | 信息密度高 | 工作台全模块/展示丰富 |

> MVP:先做「经典/极简」两套全量,一键切;后续按需求扩。

---

## 三、覆盖面（"每个组件和板块"）

- **组件**:胶囊(chips)、输入框(composer)、按钮、卡片、列表行、弹层、tab、开关、状态点……(设计规范 §五 的件,逐个对应 config);
- **板块**:工作台(Workbench)、市场(本地/商店)、市场对话(tool 气泡/审批弹窗)、侧边栏、设置页、记忆页、主页 dock——每板块的"显示集 + 布局"可配。

---

## 四、与既有体系衔接
- **UPG-40 换肤标准**(tokens.css 值段 + 候选皮肤):是"颜色/明暗"层——本引擎 B/C 在其上加深(组件/板块);
- **MOV 设计规范 §五**(组件规格/token):作"经典方案"基准;其它方案 = 组件/板块 config 重定义;
- **主页胶囊系统**(dock/管理):B(胶囊形态)与 C(主页 dock 展示)归入本引擎。

---

## 五、验收测点
- **L1**：①外观方案两套(经典/极简)②一键切换 → 全 App 组件(胶囊/输入框/卡片/列表)随 tokens/组件 config 变③板块(工作台/市场本地/主页dock)随板块 config 变④持久化(重启保留)⑤明暗仍可单独跟随系统。
- **L2 真机**：切"极简" → 全 App 胶囊/输入框/工作台同步变极简;截图对比;切回"经典"恢复;深浅仍正常;300 条无性能问题。
- **L3**：tokens+组件 config+板块 config 单源;与 UPG-40/主页胶囊/设计规范 不冲突(分层:颜色/形状 底层,组件/板块 config 上层)。

---

## 六、裁剪 / 待定
1. **MVP 范围**:先做「经典/极简」两套,还是先做**单维度组件切换**(如只胶囊样式 A/B)验证?
2. **组件粒度**:哪些组件优先(胶囊/输入框/卡片/工作台)?
3. **板块展示粒度**:工作台"显示什么"——模块是否可开关(用户自配),还是仅"预设方案"(整块切)?
4. 与「外观项(明暗三选)」关系:本引擎**取代/升级**外观项(明暗并入 A 维度),外观项入口 = 本引擎的明暗 + 方案切换?
5. 技术承载:tokens(css vars)已有;组件/板块 config 用 CSS class + 数据配置(还是引入主题/布局库)——需工程评估。

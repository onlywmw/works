## 〇、一句话

**把「AI 模型」做成一条统一通道：设置页三级(入口→列表→设置) ↔ ModelStore(唯一源) ↔ ModelRegistry ↔ 聊天页模型 chip(显示/切换) ↔ 请求(用当前模型自己的 key/baseUrl)。模型(含本地自部署、key)全在设置页管理，换模型/加本地 = 配置，零代码改动。**

### ① 一级 · 设置页入口（**完全合并，删独立 API Key 行**）
```
[⚙️] AI 模型        ›        ← 简约(无副题/无当前名)
```

### ② 二级 · 模型列表
```
[DeepSeek V4 Flash  ✓当前]   [⚡测试]  [开关·on]

──────────────────────────

```
- 行 = 模型名 + 当前✓ + **⚡快速测试**(加载态 + 错误详情:超时/401/404 提示排查) + **启用开关**(停用不可选为当前)；
- 点行 → 三级编辑；**不留供应商/接口小字**(简约)。

### ③ 三级 · 真正设置（编辑/添加两态）
```

显示名称   DeepSeek V4     (可选)      ← v3 新增(自动缩写替代)
模型 ID    deepseek-v4-flash

接口地址   https://api.deepseek.com    (本地= http://127.0.0.1:11434/v1 )
API Key   sk-****5f77  [👁 显示/隐藏]  [编辑]   ← 显示/隐藏切换
设为当前  [开关]
[保存]  [⚡快速测试]
删除该模型
```
- 添加态：标题"添加模型"空表单；编辑态：回填该模型；
- **本地自部署**：供应商选「本地自部署」→ 自动 `provider=local`，接口填本地(Ollama/LM Studio/vLLM)，key 可空。

## 四、关键机制（v3 吸收大神意见）

### A. API Key 归属模型 + 安全存储（大神 2）
- 每模型 `keyName` → **优先复用现有 `credential.vault`**(若基于 Android Keystore 加密)扩展为多 key；若 vault 仅简单 SharedPreferences → 升级 **EncryptedSharedPreferences**(androidx.security)，保留旧接口兼容；
- **迁移**：首次启动检测旧 DeepSeek key → 存在则**自动建默认 DeepSeek 模型(用旧 key)** + 删除旧存储标记；多 key(罕见)提供导入/手动迁移提示；
- key 脱敏展示(掩码 sk-****5f77)+ 显示/隐藏切换。

### B. 模型 chip 缩写（大神 3）
- `chipLabel(provider, modelId, modeName)` → `provider + 主版本(modelId)` + ` · modeName`；
- **提取主版本**：从 modelId 去 provider 前缀 + 日期/哈希后缀，留核心(`deepseek-v4-flash`→`V4 Flash`)；
- **本地无 provider**：`provider=local/空` → 用 label 简化(前 8 字符)或 `本地 · LLaMA3`；
- **三级「显示名称」可选字段**：为空才自动生成(用户可自定义)；
- **交互**：chip 点击弹气泡显示完整 label；长按进模型设置；
- 缩写**元数据驱动，换模型自动缩对，非硬编码**。

### C. 请求路由 / 适配层分发（大神 5）
- **独立 `AdapterFactory`**：`provider → AdapterClass` 映射，**默认 OpenAI 兼容适配器**；未来注册新适配器不影响现有；
- 本地识别：**用户前端选「本地自部署」→ 显式 `provider=local`**(不靠 URL 特征)；URL localhost 仅作辅助校验(测试时提示网络问题)。

### D. 本地自部署（大神 1）
- **统一 OpenAI 兼容适配器**(Ollama/LM Studio/vLLM/LocalAI 都有 `/v1/chat/completions`)；不引入各原生适配器；
- 加**轻量"兼容性探测"**：首次测试发最小请求，404/不兼容 → 提示检查服务配置。

## 五、打通点（消除"各搞各的"）

| 断点 | 打通 |
|---|---|
| key 走 credential.setKey(DeepSeek 专属) | key 归**每模型**(keyName→credential.vault/EncryptedPrefs)，模型管理里配 |
| 设置页无模型管理 UI | 三级(入口/列表/设置)，接 model.*；**完全合单「AI 模型」入口(删独立 API Key 行)** |
| ModelStore/Registry 可能不同步 | 改完立即 syncModelRegistry |
| 显示完整 label 无缩写 | chipLabel 元数据生成缩写(含兜底/显示名称) |
| 请求可能非当前模型 key/baseUrl | 请求读 current().baseUrl/keyName → AdapterFactory 分发 |

## 六、补充（大神 4 条,全采纳）

1. **模型切换快照**：切换当前模型时，进行中请求用**原模型快照**完成；新请求用新模型(请求上下文绑模型快照，防切换异常)。
2. **删除当前模型**：自动设**第一个启用模型为当前** + 提示。
3. **测试反馈**：`⚡快速测试` 显示加载态；失败给错误详情(超时/401/404)帮排查。
4. **ModelStore 性能**：内存缓存 + 修改异步写盘，防卡顿。(云同步加密为未来项,不在本期)

## 七、验收测点
- **L1**：①三级可导航 ②model.list=ModelStore 全量(当前✓/启用态) ③添加云/本地模型 → Store+Registry+请求可用 ④切换 setDefault → Registry+chip 变 ⑤key 归属模型(不同模型不同 key) ⑥chip 缩写随 provider+版本(DeepSeek V4/GPT-4o/Qwen2.5/本地 LLaMA3 自动缩对,非硬编码) ⑦本地自部署 provider=local 识别。
- **L2 真机**：设置页加本地自部署(Ollama 127.0.0.1:11434)→ chip 显示"LLaMA 3.2"→ 切换 → 本地对话成功；key 脱敏存储(shared_prefs 无明文)；旧 DeepSeek key 自动迁移为默认模型。
- **L3**：适配器按 current().provider 分发(去 DeepSeek 特判)；删除当前模型→自动设启用模型当前。

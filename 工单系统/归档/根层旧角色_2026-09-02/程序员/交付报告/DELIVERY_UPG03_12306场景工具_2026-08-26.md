## 二、实验结论（开发文档实战发现，重要）

1. **创作者文档协议三条自检全通**：健康检查 200 / tools/list 四字段 / tools/call 真实调用——文档协议本身可执行 ✅
2. **重大发现：12306 不能市场 server 化**——`scene-mcp` 部署到 mow.kim 后，12306 queryG 对**腾讯云数据中心 IP 返回 HTML 风控页**（实测 5/5 失败）；同款脚本在本地（家庭 IP）100% 成功。**结论**：12306 必须 **App 内置**（用户设备 IP，老版同款动线）→ 已按此交付内置版。挂账：`挂账-12306市场server化不可行`（处理中心）。
3. **Android 平台陷阱**：`java.net.http` 在当前配置下 Android 编译不通过 → 用 `HttpURLConnection`（老版同款）。

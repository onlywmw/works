# 输入内容 ↔ MCP 工具 联动机制 · 设计 v1

> 设计师 @2026-08-30 ｜ 状态：**待大神评审** ｜ 依据：主仓库实码溯源（2026-08-30）
> 承接：主页胶囊系统(工具可单独成胶囊)——本稿界定「用户输入如何触发/关联 MCP 工具」。

---

## 〇、一句话

**输入内容与 MCP 工具的联动 = 靠工具「description + inputSchema」喂给 LLM,让 AI 依据"用户输入 + 工具描述"做语义匹配选工具 → tool_calls 执行。工具 description 是联动纽带;胶囊/预设是"用户显式点名"的高确定性入口,AI 语义匹配是兜底。**

---

## 一、联动链路（已溯源）

```
用户输入(消息) ──┐
                  ├─→ LLM 语义判断 ──→ tool_calls(选工具) ──→ 执行 handler
工具注册表 ───────┘
(name/description/inputSchema = ToolSchema)
```
- `agentToolSchemas`(MainActivity:341)→ `toolsForStep = agentToolSchemas`(:2399/:4356)→ `DeepSeekAdapter.buildRequestBody`(:76-113)把 **工具定义(name + description + parameters/inputSchema)** 塞进请求给 LLM;
- LLM 依据「**用户输入内容 + 每个工具的 description/name/parameters**」→ 语义判断用哪个工具 → 输出 `tool_calls`;
- 工具描述来源 = `projectToolMeta`(:3698, UPG-01 三件套 desc/inputSchema/output,登记层单源)。

---

## 二、联动模型

### 1. 被动 · AI 语义匹配（主路径）
- 用户自然输入 → LLM 依工具 `description` 判断"这个输入要不要用这个工具、用哪个" → 调 tool_call;
- **工具 description**(如 12306 = "查车票/余票/站点")是 AI 识别的钥匙——**desc 越贴近用户语言,AI 越准**。

### 2. 主动 · 用户点名（胶囊 / 预设）
- 点「🚄 12306」胶囊 = **用户显式指定工具** + 预设指令("帮我查北京到上海的高铁")回填 → 明确引导 AI 用该工具;
- 胶囊 = 高确定性入口(绕过 LLM 模糊匹配);用于"用户确定要用某工具"的场景。

### 3. 参数联动
- `inputSchema(parameters)` 告诉 AI 工具要哪些字段;**AI 从输入提取填充**(如从"上海到北京,明天"提取 from/to/date);
- 无预设且参数复杂 → 轻量输入面板(用户手动补)。

---

## 三、核心 = 工具 description（联动地基）

| 维度 | 作用 | 风险 |
|---|---|---|
| **description(用途)** | AI 判断"什么输入→用我" | 太泛/术语化 → AI 匹配错/漏(该用 12306 却选别的) |
| **inputSchema(参数)** | AI 从输入提取填充 | 参数不明 → AI 传错参 |
| **output(返回)** | AI 判读结果 | 不明 → 结果误读 |

**⇒ 联动质量 ≈ 工具三件套(desc/inputSchema/output)的语义化程度**(UPG-01)。

---

## 四、隐含 / 风险
1. **工具 desc 不清晰** → AI 匹配错/漏(核心风险);
2. **胶囊与 AI 自动匹配冲突**：用户点某胶囊但 AI 又自动选别的工具 → 需明确优先级(胶囊点名 > AI 自由裁定?或预设指令强制限定工具);
3. **第三方 MCP 工具 desc 不可控**(作者写,可能不贴合中文用户) → 需二次润色或在注册时要求"适合什么输入"写法;
4. 工具多时,AI 选工具混淆(需工具描述足够区分)。

---

## 五、设计建议（待大神拍板）

1. **「适合什么输入」作为工具注册硬要求**：每个工具(尤其第三方 MCP)注册/上架时,除了 desc,必须写清「**用户说什么话会用我**」(触发示例)——喂给 AI 提升匹配,也暴露给用户理解"点它干嘛";
2. **工具详情/管理弹层暴露「适合什么输入」**：让用户知道"点这个胶囊/装这工具能干嘛"(UI 层复用 desc/触发示例);
3. **胶囊点名优先级**：点胶囊=预设指令回填 + 工具限定(该会话这个工具主用),AI 自动匹配让位——明确"用户点名 > AI 自由裁定";
4. **desc 语义化**：UPG-01 三件套的 desc,要求"**用用户语言、一句话讲清用途 + 常用触发说法**",防术语化;第三方 MCP desc 不合规 → 注册时可二次润色或标注。

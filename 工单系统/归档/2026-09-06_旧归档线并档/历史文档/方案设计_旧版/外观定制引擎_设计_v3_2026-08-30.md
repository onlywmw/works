## 〇、一句话
**本版只搭「外观引擎」的接口/框架:AppearanceProfile 数据结构 + `data-appearance` 切换机制 + 配置对象 + 外观项入口接线。极简模式的组件/板块具体外观替换：不做,留接口(schema/配置位/切换机制就绪,方案待后续填)。当前"经典"即现有外观(或仅框架)。**

---

## 一、交付范围（只留接口/框架）
1. **AppearanceProfile 数据结构**(schema,扩展点就绪):
```ts
type AppearanceProfile = {
  id: string                       // 'classic' | 'minimal'(+未来)
  theme: 'system' | 'light' | 'dark'   // A 明暗快捷
  components: { chip: 'pill'|'rounded', input: 'soft'|'outline', card: 'elevated'|'flat' }  // B 组件形态(留接口)
  sections: { workbench: 'full'|'compact', marketLocal: 'cards'|'list', homeDock: 'default'|'compact' } // C 板块展示(留接口)
}
```
2. **切换机制:**根节点 `data-appearance`(或 class)切换(CSS 变量 + `html[data-appearance="minimal"]` 覆盖组件样式);板块展示用**配置对象**条件渲染(数据驱动,不引主题/布局库);
3. **外观项入口**:设置页「外观」= **明暗快捷三选(跟随系统/浅/深)+ 外观方案位(经典/极简,极简留接口)**;
4. **持久化**:选中的 profile/theme 落盘,重启保留。

---

## 二、极简模式：留接口,不做具体替换
- **不做**:极简模式下组件(胶囊/输入框/卡片)与板块(工作台/市场本地/主页dock)的**具体样式/布局改动**;
- **用接口**:schema 的 `components.*`/`sections.*` 配置位 + `data-appearance="minimal"` 选择器**就绪**——后续填极简时会改 `data-appearance` 下对应样式 + 配置对象,引擎/入口/切换机制**不用动**;
- 当前:**只有"经典"**= 现有外观(默认),`minimal` 位为空(选了=仍经典/或未启用)。

- **L1**:①AppearanceProfile schema 定义(id/theme/components/sections)②`data-appearance` 切换机制(根节点选 class,组件可覆盖)③配置对象(板块)④外观项入口(明暗三选 + 方案位(经典/极简,极简可选=留接口))⑤持久化。

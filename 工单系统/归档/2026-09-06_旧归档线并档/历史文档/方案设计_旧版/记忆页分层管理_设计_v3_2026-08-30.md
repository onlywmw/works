## 一、异常路径 & 语义边界（v3 · 大神第①层·开发期必撞）

### 1. 晋升一致性/异常路径
- **失败回滚**：`memoryPromote` 失败/超时 → UI 回滚到草稿区 + 提示("晋升失败,请重试");验收补"晋升失败回滚"用例;
- **与自动 judge 竞态**：用户点晋升瞬间,该条可能已被自动晋升(引用≥2)或已移除——**以底层返回为准做 diff 更新,不做本地乐观写死**;
- **防重复提交**：晋升按钮点击即置 loading/防抖(连点只提交一次);
- **列表刷新策略**：自动晋升让条目"自己从草稿区消失"——**数据驱动 diff**,避免整页刷新丢滚动位置(300 条真机最易暴露)。

### 2. tombstone「再写入」语义（最优先确认）
- 文案承诺"移除后 AI 不再使用"——但用户下次再说同样内容,形成侧会写**新草稿**吗?若会,用户感知"移除没用";
- **需明确**:tombstone 挡"该条"还是"同/近似内容再写入";若底层不支持 → **弱化文案承诺**("移除后不再使用此条") 或 把"同内容拦截"列**底层待定项**;
- 业界状态维护式记忆(如"我刚搬家"自动覆盖旧住址)至少要求移除记录可被形成侧查询。

### 3. 固定 KEY 稳定性 / 生命周期
- SharedPreferences 存**稳定 ID**(非摘要 hash——未来"编辑"改内容 hash 即失效);有 stable ID 优先用 ID;
- 固定条被**移除/晋升时同步清理**固定集合(防"幽灵置顶");
- **固定上限 3~5 条**(全固定=没固定);
- "固定不跨设备"= 产品决策,写进文档(避免日后当 bug 报)。

### 4. 层内排序规则（v3 补,否则 L1 不可判定）
- 已固化内:按**最近引用倒序**(未固定部分),固定置顶在前;
- 草稿内:按**创建时间倒序**;
- 明确写入验收断言。

### 5. 草稿摘要来源 / 隐私动机校准
- 折叠前 40 字 = **生成式摘要**?还是原文截断?若原文截断,前 40 字可能就是敏感内容,"隐私心理"动机不成立;
- **二选一**:a) 摘要为**生成式**(隐私动机成立,推荐);b) 动机改写为"**降噪可扫**",隐私作附带收益。

## 二、数据模型留口（v3 · 大神第②层·低成本高回报,本次不做字段预留）

1. **已固化容量/陈旧度**：Entry 预留 `last_referenced` / `last_verified` + 状态(active→stale/superseded)——为后续"陈旧提示/复核"留口("每周三健身"会过时,"花生过敏"不会,长期混排必出问题);
2. **重复/冲突**：两条相近草稿各自晋升 → 已固化重复;至少**晋升时文本级查重提示**;语义去重列底层待定;
3. **为「使用」预留**：数据结构保留**原文/时间/来源结构化字段 + 可检索位(FTS/embedding)**——"记忆回填对话"是价值最高项,数据结构先留,独立需求不返工;
4. **最小埋点**：晋升率 / 草稿平均停留 / 移除率(含撤销率) / 搜索空搜率 / 固定使用率——验证"分层管理真有用"的唯一手段,上线即需。

## 三、文案 / 实现微调（v3 · 大神第③层）

- **「晋升」术语**：C 端内部黑话(直译 promote);与"固定"并存有理解成本。可选「设为重要/长期保留」;或保留 + 首次晋升一次性轻提示"晋升后长期保留,AI 优先使用";
- 搜索高亮：**关键词正则转义 + HTML 注入**(关键词含 `<`/`(` 等特殊字符);
- 5s 撤销 Snackbar：**页面重建(旋转/配置变化)不失效**;撤销恢复回**原位**(否则用户找不到);
- L2「晋升→移位」**视口策略**：跟随该条跳已固化区 vs 保持原位——**定一个**(建议跟随该条到已固化区顶部)。

## 四、界面结构 / 操作集（同 v2,微调后）

```
我的记忆
共 12 条 · 已固化 4 · 草稿 8
🔍 搜索记忆…(命中高亮 · 草稿命中自动展开 · 正则转义)
[ 已固化 | 草稿 ](筛选;默认全部=已固化前置+草稿在后)

📌 已固化 4 条(最近引用倒序,固定置顶)
  [固定/取消固定] [移除]
📝 草稿 8 条(创建倒序)
  [晋升→设为重要] [移除]
  (某层空态:暂无草稿,让 MOV 记住点什么吧)
```
操作:移除(5s 撤销)/ 固定(≤5·稳定ID·移除/晋升时清理)/ 晋升(调 memoryPromote,失败回滚,loading 防抖)。标题「我的记忆」。

## 五、验收测点（v3 增补）

- **L1 增**：晋升失败回滚;晋升与自动 judge 竞态幂等无副作用;固定条移除后置顶集合清理;高亮特殊字符;层内排序断言(已固化最近引用倒序/草稿创建倒序)。
- **L2 增**：撤销恢复原位;配置变化(旋转)下撤销不失效;自动晋升发生时 **diff 刷新不丢滚动位置**;300 条种子可扫。
- **L3 转可执行**：呈现层**只 import 记忆 API 门面(memoryPromote/memoryRemove 等)**,不触 MemoryLifecycle 内部实现;固定存储不进记忆数据库——用**依赖检查/代码审查清单**落地(非口号,否则 L3 无法验收)。

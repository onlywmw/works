## 〇、一句话
把「审批模式」升级为**「安全」中心**：二级页顶部**安全等级 / 体验等级**两栏并存（S/A/B），下面列全部安全设置项；用户调某项 → 两栏**实时反映权衡**；**资金 / 凭据 / 绝密 = 硬边界，恒定最严**（体验再 S，安全至少 B、资金恒守）。

## 一、二级页结构
```
设置 →「安全」›   （原「审批模式」行升级为「安全」）

‹ 安全
┌────────────────────────────────────────────┐
│ 安全等级  S·A·B     │   体验等级  S·A·B      │  ← 两栏并排（当前档高亮）
├────────────────────────────────────────────┤
│ 🔒 本机数据已加密保护 · 无异常                 │  ← 安全状态一屏（零操作·一眼放心）
│ 审批模式                        [open / ask]  │
│ 敏感操作确认                    [按次 / 每次]  │
│ 第三方 MCP 权限                 [读自由/写询问/写拦截]│
│ 自动记住偏好（同类确认收敛）       [开 / 关]      │
│ 数据足迹 / 审计记录              [开 / 关]      │
│ 敏感字段展示                    [掩码 / 明文]   │
│ 云同步 / 对外                   [本机 / 加密云]  │
│ ────────────────────────────────────────── │
│ 硬边界（恒定保护 · 不可调）                    │
│ 🔒 凭据保护       已保护                      │
│ 🔒 资金 / 支付保护  已保护                    │
└────────────────────────────────────────────┘
```
- 顶部**两栏等级**是灵魂（用户一眼看清天平在哪端）；
- **安全状态**一屏（已加密）零操作；
- 硬边界项**灰显"已保护"**（不可调），明确"这些始终守"。

## 二、安全设置项清单（用户可选 · 统计）

| # | 项 | 档位 | 对安全 | 对体验 |
|---|---|---|---|---|
| 1 | **审批模式** | open / ask | 写类全放=低 · 每次确认=高 | 放行=高 · 确认=低 |
| 2 | **敏感操作确认** | 按次 / 每次 | 每次=高 | 按次=高 |
| 3 | **第三方 MCP 权限** | 读自由 / 写询问 / 写拦截 | 拦=高 | 自由=高 |
| 4 | **自动记住偏好**（同类确认收敛） | 开 / 关 | 开=略低 | 开=高 |
| 5 | **数据足迹 / 审计记录** | 开 / 关 | 记录=高 | 关=少"被记录感" |
| 6 | **敏感字段展示** | 掩码 / 明文 | 掩码=高 | 明文=高 |
| 7 | **云同步 / 对外** | 本机 / 加密云 | 本机=高 | 云=多端便捷高 |

> 覆盖安全体系核心（审批/敏感/MCP/个性化/审计/展示/外发），且都**对安全+体验有明确方向**——调档即动天平。

---

## 三、等级映射（聚合 · 两栏独立）

- 每项档位 → 对**安全分** + 对**体验分**（如 严档=安全↑、松档=体验↑）；
- **安全等级** = 各项安全分聚合（越谨严 → 越高 S/A/B）；**体验等级** = 各项体验分聚合（越打扰 → 越低）；
- **两栏独立计算**（不是简单反向）：有些项两全（本机加密=安全↑体验不变；记住偏好=体验↑安全不变），所以两栏可能同时高/不同步；
- 档位高亮当前 S/A/B，用户可以**点档位看预览**（选更严 → 安全升/体验降）。

---

## 四、System Hard Boundary（硬边界 · 恒定最严）

- **凭据 / 资金 / 支付 / 绝密**：**恒定最严，不随用户体验等级放开**——即使体验 S，这些仍最严；
- 效果：**安全等级有下限（至少 B）**、资金恒守——**体验 S ≠ 安全裸奔**（呼应安全体 v2.1 System Hard Boundary）；
- UI：硬边界项**灰显"🔒 已保护"**（不可调），明确告知"这些始终守"；等级计算时硬边界项恒定计入安全（拉高安全下限）。

---

## 五、与体验优化呼应
- **安全状态一屏**（零操作一眼放心）、**审批一次秒懂**、**记住偏好越用越顺**——都进安全中心；
- 顶部**两栏等级**让用户直观"我现在天平在哪端"——**体验优先但有度**（体验开，但资金/凭据恒守）。

---

## 六、验收测点
- **L1**：①顶部两栏（安全/体验等级）随设置**实时变** ②每项档位→等级映射正确（变异：档位算错→必红）③硬边界项**不可调/恒最严**（变异：资金可放开→必红）④**安全等级下限 B**（体验 S 时安全仍≥B，变异：可到≤A→必红）⑤两栏独立（非纯反向）。
- **L2 真机**：设"最严"→ 安全 S / 体验 B；设"最放开"（资金仍守）→ 体验 S / 安全 B / 资金恒严；调某项 → 两栏实时变；硬边界"🔒 已保护"灰显不可调。
- **L3**：等级聚合规则契约测试；硬边界不因体验等级放开（依赖检查）。

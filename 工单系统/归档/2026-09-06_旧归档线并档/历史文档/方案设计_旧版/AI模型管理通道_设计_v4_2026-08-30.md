## 二、通道架构 + 会话级绑定（v4 新增）

```
设置页三级(入口/列表/设置)  ↕ model.*  ModelStore(唯一源) →sync→ ModelRegistry
                                                    │ current()→label/缩写+modeName
聊天页 chip(显示/切换) + 会话级模型绑定(会话.modelId, 新消息沿用)
                                                    │ 请求读 current()/会话.modelId 的 baseUrl/keyName
                                                    ▼
                                              AdapterFactory(provider→Adapter, 默认OpenAI兼容)
```

**会话级模型绑定（v4 定案，落地单 4）**：会话实体记录 `modelId`；新消息默认沿用该会话绑定模型；若该模型已删/停用 → 进入会话提示选择替代模型。避免「切到本地模型后打开历史会话,当前模型语义歧义」。

## 四、关键机制（v4 吸收大神两轮）

### A. Key 安全存储（**v4 改动**）
- **弃 EncryptedSharedPreferences**(androidx.security:security-crypto 已被官方弃用/存在加密缺陷)；
- 改用 **Android Keystore 生成 AES 密钥 + 自实现 AES-GCM 加密**，密文存 SharedPreferences/DataStore，**明文只在内存**；`keyName → vault` **契约不变**(单2 对外接口照旧，只换底层实现)；
- **Keystore 跨设备**：密钥不可迁移，Android Auto Backup 默认备份 prefs/files → 备份恢复密文解不开。**需在 backup rules 排除加密数据**，或 UI 说明「换机需重新录入 key」。

### B. 明文 HTTP 网络权限（**v4 新增 · 隐形断点**）
- Android 9+ 默认**禁止明文 HTTP**(含 `http://127.0.0.1:11434`)→ 需 `network_security_config` 对 `127.0.0.1`/`localhost`/局域网 IP 段显式放行 `cleartextTrafficPermitted`，否则真机 Ollama 直接连失败；
- 模拟器访问宿主机用 `10.0.2.2`(非 127.0.0.1，验收文档备注)；
- 真机连电脑 Ollama 需服务端 `OLLAMA_HOST=0.0.0.0` → 测试失败错误详情给出提示。

### C. 模型 chip 缩写（同 v3）
`chipLabel(provider,modelId,modeName)` → `provider+主版本`；去前缀/日期哈希后缀留核心；本地无 provider→label 简化(`本地·LLaMA3`)；三级「显示名称」可选(空才自动)；chip 点气泡显完整 label + **气泡内放「管理模型」入口**(替代长按,发现性更好)；元数据驱动，换模型自动缩对。

### D. 请求路由 / 适配器（同 v3）
`AdapterFactory`(provider→AdapterClass，默认 OpenAI 兼容)；本地=用户选「本地自部署」→provider=local(不靠 URL)；统一 OpenAI 兼容适配器(Ollama/LM Studio/vLLM/LocalAI) + 轻量兼容性探测(404/不兼容→提示检查)；去 DeepSeek 特判。

## 五、数据可靠性（v4 新增）

1. **原子写盘**：`model_store.json` 用「临时文件+rename」，防进程被杀文件截断(异步丢失最后一次修改可接受，文件损坏不可接受)；
2. **迁移版本化**：`model_store.json` 加 `version` 字段 + migration flag 标记完成 → 幂等(二次启动不重复建默认模型)；
3. **空态兜底**：删除当前模型→回退第一个启用模型；**若无任何启用模型 → 聊天页禁用输入 + 引导跳设置页添加**（必现路径）。

## 六、⚡测试体验（v4 新增）

## 九、验收测点

- **L1**：①三级可导航 ②model.list=ModelStore 全量(当前✓/启用态) ③加云/本地模型→Store+Registry+请求可用 ④切换 setDefault→Registry+chip 变 ⑤key 归属模型 ⑥chip 缩写随 provider+版本(自动缩对,非硬编码) ⑦本地 provider=local 识别。
- **L2 真机**：加本地自部署(Ollama 127.0.0.1:11434)→chip 显"LLaMA 3.2"→切换→本地对话成功；**明文 HTTP 放行真机连通(非 10.0.2.2)**；key 脱敏存储(shared_prefs 无明文)；旧 DeepSeek key 自动迁移默认模型。
- **L3**：AdapterFactory 分发(去 DeepSeek 特判)；删除当前→自动设启用模型当前；**无启用模型→禁输入+引导**。
- **补充(大神)**：①model_store.json 并发/中断后完整性 ②迁移幂等(二次启动不重复建默认) ③无可用模型空态路径。

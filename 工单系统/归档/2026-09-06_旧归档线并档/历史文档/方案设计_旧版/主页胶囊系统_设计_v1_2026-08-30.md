# 主页胶囊系统 · 设计 v1（胶囊可自由钉选 + 第三方 MCP 工具独立胶囊）

> 设计师 @2026-08-30 ｜ 状态：**待大神评审** ｜ 演示：`设计预览\主页胶囊管理_demo.html`
> 前置：本日已把底部 dock 整理（模型 chip 缩写 / 四胶囊统一 110×34 胶囊居中 / 去竖线 / 钉选短标 / 去健康点）——本稿在其上做**管理 + 扩展**。

---

## 〇、一句话

**主页输入框上方胶囊区 = 用户可自定义的「常用能力快捷」。内置能力(订单/信息/记忆)与第三方 MCP 工具都能**单独钉成独立胶囊**直接上主页;主页胶囊区末尾「＋」= 就地管理(哪些显示 / 排序 / 上限 5)。「MCP 工具」胶囊 = 没被单独钉的工具聚合入口。**

---

## 一、背景（问题）

1. **第三方 MCP 工具不能单独成胶囊**：现在所有 MCP 工具都折在「MCP 工具」胶囊里,点击展开气泡才能看/用;用户想常用的某个 MCP 工具(如 12306 查票)**直接一个胶囊**就能用,不必每次进「MCP 工具」翻;
2. **管理口与展示脱节**：控制"哪些胶囊上主页"(钉选)目前在**市场-本地 tab**——用户在主页看到胶囊,却要去本地 tab 增删,绕;
3. 模型 chip(缩写)已就绪;胶囊区用了"模型chip / MCP工具 / 内置钉选(订单·信息)"混排,**缺统一管理 + MCP 独立胶囊**。

---

## 二、目标

1. **任何能力都可单独钉成独立胶囊**：内置(订单/信息/记忆)+ **第三方 MCP 工具**(12306/Obsidian/浏览器自动化…)——MCP 工具可"提起"为独立胶囊,不必折在「MCP 工具」里;
2. **主页就地管理**：胶囊区末尾「＋」→「主页胶囊管理」弹层(哪些显示 / 排序 / 上限 5),直连 `workbench_pins` 单写点;
3. 「MCP 工具」胶囊 = 未单独钉的工具聚合入口(点开仍是气列表,但被单独钉的不在里面重复)。

---

## 三、设计

### 1. 主页 dock 胶囊区
```
[Deepseek V4] [MCP 工具] [订单] [信息] [🚄 12306] [＋]
```
- 模型 chip(缩写) / 「MCP 工具」(未单独钉的聚合) / 内置钉选(订单·信息) / **第三方 MCP 独立胶囊(🚄 12306)** / **＋管理**;
- 胶囊统一 110×34 胶囊、文字居中、无健康点、无竖线(已定)。

### 2. 「＋」→ 主页胶囊管理（就地弹层）
```
主页胶囊管理 · 上限5 · 可排序
【内置能力】订单✓ 信息✓ 记忆☐
【MCP 工具 · 单独钉成胶囊】
   12306 ✓   Obsidian笔记 ✓   浏览器自动化☐
   更多MCP工具(仍折在「MCP工具」胶囊)☐
```
- 每个能力(内置 + 第三方 MCP)**单独勾选 → 是否独立胶囊**上主页;
- 勾的 → dock 出现独立胶囊;没勾的 MCP 工具仍折在「MCP 工具」胶囊;
- **排序**(拖动)/ **上限 5** / 停用态变淡。

### 3. 数据（复用 + 扩展）
- `workbench_pins`(单写点,已有,上限 5)——扩展支持 **MCP 工具钉选**(pin 可指向 MCP 工具 id,name/tool 标识);
- 钉选条目:内置(订单/信息/记忆,page 类)+ MCP 工具(id/name/tool)——dock 渲染时按类型(内置跳页 / MCP 工具预设指令回填或直达工具)。

### 4. 边界
- 「MCP 工具」胶囊 = 未单独钉的工具聚合(不显示已被独立钉的,防重复);
- 独立胶囊点击:内置 → 跳对应页;MCP 工具 → 预设指令回填输入框(与现有钉选一致)或直达;
- 已钉 MCP 工具被停用/卸载 → 胶囊变淡(引导去本地 tab 启用)或移除。

---

## 四、关联
- **模型 chip**(AI 模型管理通道·单3 缩写)已落地;
- `workbench_pins` 单写点(UPG-23)复用,不新建平行体系;
- 与「AI 模型管理」「记忆页」并列——都是"能力快捷/入口"层,本稿统一胶囊呈现 + 管理。

## 五、验收测点
- **L1**：①可勾选内置 + 第三方 MCP 工具为独立胶囊(勾→dock 出现,不勾→仍在 MCP 工具折叠)②上限 5(PINNED_LIMIT)③排序(拖动,dock 顺序同步)④MCP 工具独立胶囊点击→预设指令回填/直达⑤「MCP 工具」胶囊不含已独立钉的(防重复)⑥模型 chip 缩写仍正确。
- **L2 真机**：主页 dock 加 MCP 独立胶囊(12306)→ 点击直接预设回填/用;「＋」管理就地增删、order 同步;停用 MCP 独立胶囊变淡引导;300 条无性能问题、滚动流畅。
- **L3**：`workbench_pins` 单写点(不新建平行体系);模型/内存/胶囊各层不互相污染;与本地 tab 钉选区一致性。

## 四、关键机制（v2 定案）

### 1. 「晋升」= 调底层真实接口（大神最关键）
- **溯源确认**：`MemoryLifecycle.memoryPromote(draft, kind)`(MemoryLifecycle.kt:41) 已存在 = **手动晋升 API**；
- 晋升按钮 → 调 `memoryPromote(draft, kind)` → **真实落 `_memory_promoted`**（草稿→已固化），非 UI 假状态；
- 与自动 `judge`(引用≥2 晋升，幂等，已晋升跳过)并存——**手动晋升是补充入口**（用户主动整理），不冲突；
- 若底层 memoryPromote 对外未接线 UI，需加一个 memory.promote 桥(轻量)——待底层确认接线态。

### 2. 固定（置顶）= 独立 UI 状态，不污染底层
- 存本地 SharedPreferences（`memory_fixed` 集合 / 或 UI 状态表），**不进 MemoryLifecycle、不影响生命周期**；
- 只是排序置顶偏好，与记忆晋升/衰减正交。

### 3. 草稿折叠交互
- 折叠态 = **摘要前 40 字 + 「…展开」**；点击 → 整条展开（显示全文 + 来源/时间）；再点收起；
- 全部草稿默认折叠（隐私心理），长尾不分批（避免一刀切）。

### 4. 筛选标签（非"全部"混排）
- 「已固化」「草稿」两个标签 = **筛选**（选哪层只显哪层）；默认**全部** = 已固化在前 + 草稿在后（两分区，非按时间混排）；
- 顶部标签选中态清晰。

### 5. 搜索
- 匹配：摘要 + 来源 + 状态；**当前列表过滤** + 命中关键词高亮；草稿命中 → **自动展开该条**；
- 结果就地呈现（不跳新页）。

### 6. 移除（tombstone 软删）
- 确认文案：「**移除后 AI 将不再使用此记忆**」（不只"移除"ambiguous）；
- 提供 **5 秒撤销**（Snackbar：移除 → 撤销恢复）；超时 tombstone 落库；
- tombstone 数据保留（本次不做"已移除记忆"查看入口，说明：软删可恢复尾，硬清理后续）。

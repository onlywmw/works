设计说明（UPG-23 v2）

新主页小按钮 = 钉选的出口：钉选的工具包以方形图标钮显示在主页输入框上方 chips 排（模型 / MCP 工具两个固定 chip 之后，分隔线隔开），带健康小圆点。点按 = 快捷调用（插入预设指令到输入框）。钉选从此有了用户可感知的回报。
新MCP 工具 chip 气泡 = 总览的轻量投影：列已启用分组 + 工具数 + 健康点；停用的包灰显。数据与本地 tab 同源。
1本地 tab = 本机能力总览：概览卡（工具数/来源/钉选占用+健康一句话）→ 钉选槽 → 三层分组（内置/市场/系统）→ 工具级下钻带权限标记（免审批/需确认，与 McpToolScheduler 名单同源）。
2联动是同一个状态：右边停用 → 左边气泡灰显、钉选钮健康点变；右边钉选/取消 → 左边小按钮增减。 demo 里两部手机共享一份数据，正式实现也是（market.status + ui.getPins 单一数据源，L6 红线）。
3未定的点：①主页小按钮槽位与钉选 5 上限共用还是独立；②小按钮点按行为=插入指令 还是 直接调工具；③Obsidian 未授权 SAF 的引导行；④系统基础能力只展示不可关。

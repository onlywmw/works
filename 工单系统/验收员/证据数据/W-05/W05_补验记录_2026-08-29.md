## 新发现缺陷（阻塞「五卡渲染」实证）
**事件五子类页面在生产不可达：点击任意子类链接均跳回总览。**
- 实测：真实点击 `#sidebar a[href="#/events-备案"]`（Input 管线）→ `location.hash` 由 `` 变 `#/overview`，H1=总览；证件/审核/事务/运营同样全跳 `#/overview`（五连测）。
- 对照：ASCII key 子类（app-tickets 工单流转）点击正常渲染。
- 机理坐实（只读 eval）：
  - DOM 属性 `getAttribute('href')` = `#/events-备案`（原始中文）
  - 浏览器 URL 解析后 `new URL(a.href).hash` = `#/events-%E5%A4%87%E6%A1%88`（百分号编码，URL 标准行为）
  - 生产 app.js `route()`：`location.hash.replace(...)` 得编码串 → `findSection` 与 json 原始中文 key `events-备案` 不等 → 命中 `!s` 分支重置 `#/overview`（缺 `decodeURIComponent` 或 key 应 ASCII 化）
- 影响面：侧栏五子类链接、总览「事件」维度卡（href=#/events-备案）、本周焦点 E-01 行（href=#/events-备案）三个入口全部失效 → **五张事件卡（标题/状态/截止日期）无法在真实页面实证**。
- 旁证：omnibox 直贴 `mow.kim/#/events-备案` 与预编码 `mow.kim/#/events-%E5%A4%87%E6%A1%88` 均跳回总览（用户可复现路径）。

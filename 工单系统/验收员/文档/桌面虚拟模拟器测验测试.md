# 桌面虚拟模拟器测验测试（验收员标准方法）

> 生效日期：2026-08-26 ｜ 依据：`项目配置.md` 三、验收环境（MOV 真机 = 桌面虚拟模拟器 `emulator-5556`）
> 本文件定义**桌面虚拟模拟器**作为 MOV 验收的主要「真机等价环境」的标准测试方法。
> 实体平板为补充环境（涉及相机实拍/传感器真值/蓝牙/WiFi 设备实测时启用，另有注明）。

---

## 一、环境与启动

| 项 | 值 |
|---|---|
| AVD | `MOV_Test`（备用 `Medium_Phone_GA`） |
| 设备 | `emulator-5556`（5554 为备用/并行） |
| 启动 | `emulator -avd MOV_Test`（SDK 8.0+；已启动则跳过） |
| 确认在线 | `adb devices` 出现 `emulator-5556  device` |

## 二、标准测试动作（验收员必用）

```bash
ADB="adb -s emulator-5556"
# ① 安装（断言输出含 Success）
$ADB install -r <apk-path>

# ② 启动（断言 topResumedActivity = com.mov.android/.MainActivity）
$ADB shell am start -n com.mov.android/.MainActivity
$ADB shell dumpsys activity activities | grep topResumedActivity

# ③ 截图（用 exec-out；模拟器多 display 时 screencap 直接 -p 会报 usage）
$ADB exec-out screencap -p > 证据_<场景>.png

# ④ UI 树（uiautomator dump → python 读，绕开 GBK 终端）
$ADB shell uiautomator dump /sdcard/u.xml && $ADB shell cat /sdcard/u.xml > u.xml
python -c "import io,re; s=io.open('u.xml',encoding='utf-8',errors='replace').read(); print([m.group(1) for m in re.finditer(r'text=\"([^\"]{1,60})\"',s) if m.group(1).strip()])"

# ⑤ 输入（tap/文本/回车；input text 只支持 ASCII——中文用英文参数或输入链脚本）
$ADB shell input tap 540 2270
$ADB shell input text "query%strain..."   # %s = 空格
$ADB shell input keyevent 66              # Enter

# ⑥ 日志（App 侧证据）
$ADB shell logcat -d | grep -iE "SceneTools|Mov|Tool|journal" | tail -30
```

## 三、工具验证与范围

- **适用**：UI/交互、工具调用、市场/房间/审批/抽屉、WebView 页面、OCR、日历/通知/定时（系统模拟可用）等
- **可用模拟**：相机（模拟器虚拟摄像头场景图）、地理位置（`geo fix` 注入）、传感器（部分虚拟）
- **需要实体平板补充**：摄像头实拍画面、真实传感器读数（陀螺/加速度）、蓝牙/WiFi 设备发现、短信/电话、真实定位

## 四、证据规范（沿用 README 红线）

- ✅ 标准：**可重跑命令 + 截图/journal 可见「目标达成」**
- 证据命名：`<场景>_<时间戳>.png`（如 `tools_scene_trainQuery_20260826_1530.png`）
- 落点：`验收员\证据数据\<YYYY-MM-DD>\<工单号>\`（一单一个文件夹 + README 总结）
- 结论登记：验收员列 `✅已真机`（附证据目录名）→ 审验员按 `审验员\工单证据链映射.md` 抽查

## 五、已踩坑（防再犯）

| 坑 | 解决 |
|---|---|
| `screencap -p` 报 usage | 用 `exec-out screencap -p > 文件`（不要 `shell -p /sdcard/...`） |
| 中文 grep/打印乱码（GBK） | 输出写文件用 python `encoding='utf-8'` 读，不在终端 print 中文 |
| `adb input text` 不支持中文 | 参数用英文/ASCII 直达（AI 可理解英文指令），或走 UI 输入链脚本 |
| 消息发出后 AI 无回复 | 先查模型 API key/网络（挂账-模拟器AI未回复），模型通后补 L3 journal 证据，不得标 ✅ |
| UI dump 找不到文本节点 | `uiautomator dump` 后再 `cat`；WebView 内容可能不在 XML，用截图+OCR 交叉验证 |

## 六、与实体设备分工

| 场景 | 首选 |
|---|---|
| 日常单/UI 单/工具单/市场单 | 桌面虚拟模拟器（快、可重跑、证据稳定） |
| 相机实拍/传感器/蓝牙/真实定位/短信电话 | 实体平板（专门注明「实体设备补充」） |
| 纯后端/无 UI（命令/协议/服务） | 不要求模拟器——按「真机验收标准与方式方法」§四 命令/journal/产物验证 |

# 处理中心（模板说明）

> 本目录 = 处理中心的运行数据；**模板仓库只有 `模板/`（空白模板）**——实际数据文件（事件登记表/资产档案表/挂账登记表/验收标准冻结区/验证产物/问题区…）按项目接入时从 `模板/` 复制生成，**不随模板仓库分发**（避免跨项目串数据）。

## 目录职责（接入后生成）

| 目录/文件 | 用途 | 谁写 |
|---|---|---|
| `挂账登记表.md` | 挂账池（发现未进工单的待办） | 任何人登记，设计师转单 |
| `事件登记表.md` | 运营/合规/资产事务留痕 | 设计师 |
| `资产档案表.md` | 证书/密钥/商标/域名/账号档案 | 设计师 |
| `验收标准冻结区/<单号>/` | 每单验收标准（STD 冻结件） | 设计师冻结 |
| `验证产物/` | E4 看板投影（自动生成） | 机器 |
| `问题区/` | 审验/验收发现问题记录 | 各角色 |

## 模板清单（`模板/`）

- `挂账登记表.模板.md`
- `事件登记表.模板.md`
- `资产档案表.模板.md`

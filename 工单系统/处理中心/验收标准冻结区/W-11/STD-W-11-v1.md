## 冻结区（不可改 · 只读）

### 验收定级

| 定级 | 本单验收方式 | 验收要点 |
|---|---|---|
| L1 低 | 单测层 | 无 env 拒启各案（SMS_MODE 未设/TOKEN_SECRET 未设/real 缺 SMS_* 列明缺哪个）、token 过期 401、IP 限流触发、body 超限 413 |
| L2 中 | 生产灰度实证 | 测试端口起新进程过登录全流程（真手机号发码→登录→/me→set-password）；旧 token（修复前签发）过期后 401（如选旧 token 宽限须报告说明口径） |
| L3 高 | 三端回归（2026-09-05 口径更正） | **mov-ai.cn 商家入驻/登录 + mow.kim 后台管理登录 + App 登录**；服务重启窗口 ≤30 秒且提前告知用户 |

### 变异锚

| 锚点 | 变异动作 | 期望 |
|---|---|---|
| token 过期锚 | 删掉 parseToken 的时间戳过期校验 | 「过期 token → 401」用例必红（亲杀） |
| fail-loud 锚 | 恢复 `SMS_MODE \|\| "dev"` 默认值 | 「未显式设置 → 拒绝启动」用例必红 |
| 后门锚 | 复活 DEV_FIXED_CODE 固定验证码分支 | 「dev 固定码不得直通」用例必红 |

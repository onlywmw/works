## content_sha256 生成方法（本段仅供校验 · 不属于冻结区）

填完「冻结区」后，对本文件运行（Windows bash 下将 `python` 换成实际解释器）：

```bash
python -c "import hashlib,sys; t=open(sys.argv[1],encoding='utf-8').read(); s=t.split('## 冻结区',1)[1].split('## 追加说明区',1)[0]; print(hashlib.sha256(s.encode()).hexdigest())" "STD-<工单号>-v<n>.md"
```

把输出的 64 位 hex 回填到头部 `content_sha256`。

> 校验：验收 / 审验 / 合 main 抽查时重跑同命令比对；不一致 = 标准被改，阻断并走修订。

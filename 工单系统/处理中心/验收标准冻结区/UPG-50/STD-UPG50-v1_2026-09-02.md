## 一、范围（第一阶段 · 打样跑通）

- 输入框组件 **3 形态**（classic 经典/capsule 胶囊/underline 下划线）× 明暗 × 状态矩阵
- **组件库选择页**（Appearance Selection View）：列表（每行=组件名+形态横铺）+ 选中即替换 + ✓/● 语义 + 明暗跟随全局 + 最近使用标记
- 持久化（AppearanceProfile）+ 覆盖真删 + UI 直调范围说明

## 二、L1 机器判据（JVM/静态 · 自动）

| 编号 | 判据 | 通过标准 |
|---|---|---|
| L1-1 | 形态解析 | Resolver 对 `input.capsule` 等形态 ID 解析到对应 DOM/class 形态（纯函数单测） |
| L1-2 | 覆盖真删 | 选回 default → profile 中该组件条目**彻底删除**（断言无残留键） |
| L1-3 | 持久化 | AppearanceProfile 写读一致（重启后保持） |
| L1-4 | 状态矩阵 | 3 形态×明暗×6 状态全声明（断言规格表+渲染无崩溃） |
| L1-5 | 明暗跟随 | 切主题 → 选择页+组件同步（无独立状态残留） |
| L1-6 | 唯一真相 | 页面无本地独立 selected（读取=AppearanceProfile —— grep 断言无 selected 本地态） |
| L1-7 | 变体语义 | u50 选择写入 appearanceProfile.components（不写 impl 层） |
| L1-8 | UI 编号建库 | 首批 20 条编号唯一+范式合规（`UI-<部位>-<组件>`）+每条四字段齐（component_id/semantic_type/名称/provider）——机器校验（基准=UI组件编号库_v1） |
| L1-9 | 编号-部位隔离 | UI-CHAT-INPUT 切换不影响 UI-SETTINGS-INPUT 等（单部位打样——非本部位编号零被引用断言） |
| L1-10 | 排版 Token 标准先行 | 契约新增 文本缩放/字族/字重 三个语义名（MOV设计规范 v2.1 §九，文本缩放=小/标准/大三档；字族=默认/品牌/等宽；字重=常规/中粗）；**消费侧只用语义名**（grep 断言无写死字号/字族——设计红线延续）；「设置-外观三档偏好 UI」=**并行小单，不在本单范围** |

## 三、L2 真机判据（装机）

| 编号 | 判据 | 通过标准 |
|---|---|---|

| L2-2 | 选中即替换（单实例） | 点 capsule → **UI-CHAT-INPUT 即时变胶囊**（点击前后截图对照）；**其他输入框**（UI-SETTINGS-INPUT 等）截图对比零变化——与 L1-9 对齐 |

## 一、定位

登录页是用户打开 App 的**第一张脸**：一半是功能（30 秒内完成登录），一半是品牌（让人觉得「这个产品很高级、可信」）。设计原则：**一个视觉焦点、零装饰噪音、所有元素都有用**。

## 二、页面结构（自上而下五区，一屏放完不滚动）

│   （品牌光晕背景）         │
│                         │
│      ② 登录方式切换       │  ← Tab：验证码登录 ｜ 密码登录
│                         │
│      ③ 表单区            │

│   [验证码____] [获取验证码]│  ← 密码 tab 时换成密码框
│                         │

### ① 品牌区（本页灵魂，「更重品牌」落在这里）

- **背景**：暖白 `#FAFAF9` 基底 + 一层**品牌光晕**——品牌蓝 `#3B6EEB` 8-10% 透明度的径向渐变，从顶部 1/3 处散开，边缘完全消隐（不是色块、不是卡片，是"光"）；可加一道极细的琥珀 `#D97706` 6% 辅光晕增加层次。禁止：图片背景、视频背景、粒子动效；
- **Logo**：居中，约 72-88dp，不要外框/底色块；
- **品牌名「MOV」**：Inter 600，32-36sp，近黑 `#1A1A1A`，字距 -0.02em；
- **品牌主张**：一句话，14sp，`#6B6B6B`。文案占位建议：「让 AI 成为你的日常」（正式文案等品牌线出，前端留好位）；

### ② 登录方式切换

- 文字 Tab：「验证码登录」「密码登录」，选中态 16sp/600/近黑 + 下方 2px 品牌蓝短划线（24dp 宽，居中），未选中 `#9CA3AF`；
- 切换无动画或 150ms 淡换，禁止滑动切换手势（会和输入误触）。

### ③ 表单区

- 输入框：高 56dp，圆角 16dp，暖灰底 `#F4F3F1` + 1px `#E5E5E5` 边；**聚焦态**：边框变品牌蓝 1px，无发光阴影；
- 手机号框：`+86` 前缀固定位（`#6B6B6B`）+ 数字键盘唤出；
- 验证码框 + 「获取验证码」按钮：文字按钮，品牌蓝；点击后进入 **60s 倒计时**（「59s 后重发」，`#9CA3AF` 不可点）；
- 密码框：右侧眼睛图标切换明文；
- **主按钮「登录」**：高 52dp，全宽，圆角 26dp（pill），近黑 `#1A1A1A` 实心 + 白字 16sp/600；未填完/未勾协议 = 40% 透明度禁用态；点击后按钮内转 loading 圈（不跳页面级 loading）；
- **错误反馈**：inline 红字 12sp `#DC2626` 显示在对应输入框下方（如「验证码错误」），输入框边框变红；禁止用 toast 一闪而过。

### ④ 第三方预留

- 分隔线：细线 `#E5E5E5` + 中间「其他登录方式」11sp `#9CA3AF`；
- 微信图标：圆形 44dp，**置灰 40% 透明度**（明确表示"将来有"），点击反馈 = inline 提示「微信登录即将上线」。

### ⑤ 协议区

- 勾选框 + 「已阅读并同意《用户协议》《隐私政策》」12sp `#6B6B6B`，协议名品牌蓝可点；
- **默认不勾选**，未勾点击登录 = 勾选框轻晃一下 + inline 提示（不弹窗）。

| 项 | 值 |

| 页面左右边距 | 28dp |

| 字体 | Inter 全家桶；中文回落系统默认（思源/PingFang 随系统） |

## 四、Android 适配要点

- 沉浸式状态栏（图标深色）；底部手势条区域留白，协议区距底 ≥16dp + 安全区；
- **键盘弹起**：整页上移而不是遮挡——品牌区可压缩（Logo 缩小至 48dp，主张文案隐藏），表单区永远完整可见；
- 深色系统模式下本页**保持浅色**（一期不做暗色，与全站一致）；
- 后端接口现成：`POST /account/send-code`、`POST /account/login`（验证码）、`POST /account/login-password`（密码）——对接即可，无新后端。

## 五、文案清单（前端直接用）

- Tab：验证码登录 / 密码登录
- 输入占位：「请输入手机号」/「请输入验证码」/「请输入密码」
- 按钮：登录 / 获取验证码 / 「{n}s 后重发」
- 错误：手机号格式不正确 / 验证码错误或已过期 / 密码错误 / 请先勾选协议
- 微信位：其他登录方式 / 微信登录即将上线
- 品牌主张：占位「让 AI 成为你的日常」（待品牌线定稿）

## 六、不做清单（前端不要擅自加）

- ❌ 轮播图/视频背景/Lottie 动效背景；
- ❌ 独立注册页（验证码登录即自动注册）；
- ❌ 一排第三方登录图标（只预留微信一位）；
- ❌ 「忘记密码」一期不做（密码 tab 错误三次提示语留出位置即可，找回流程后续单）；
- ❌ 游客模式/跳过登录。

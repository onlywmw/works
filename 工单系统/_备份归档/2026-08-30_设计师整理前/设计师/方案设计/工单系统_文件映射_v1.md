## 三、视图映射（树节点 = 数据表的视图）

| 树节点 | 类型 | 视图定义 |
|---|---|---|
| overview 总览 | leaf | 跨表聚合：focus = upg_tickets ∪ dim_* ∪ events 中「在制」按 prio+updated Top5；计数卡 = 各表 status 分组计数 |
| app-tickets 工单流转 | pipeline | upg_tickets 按 status 分组的分组视图（步进器） |
| app-backlog 挂账与问题 | pipeline | backlog 按 status 分组（⏳红点冒泡） |
| app-accept 验收记录 | timeline | accept_events 按 date 倒序 |
| market-*/brand-*/marketing-*/infra-* | pipeline / archive | dim_* 子表原样；档案型子表（brand-tm、infra-servers、marketing-cal）用 archive 卡片型 |
| archive 归档 | leaf | 跨表筛选视图：status=已完成 的全部记录，按 updated 倒序 |

## 四、同步规则

1. **单向只读**：文件 → sync-workbench.mjs → workbench.json → 前端；任何反向写禁止；
2. **先表后库**：登记纪律不变（xlsx 先行，md 同步），sync 只信 xlsx 的列状态，md 作详情源；
3. **触发时机**：登记动作后手动 `node sync-workbench.mjs --deploy`；合并 main 后必须跑一次（规则 18）；
4. **红点口径**：⏳/阻塞/打回/临期 → 红点冒泡到一级维度；
5. **脱敏**：手机号中间四位、口令、密钥不入 json（源头禁写 + sync 打码双保险）。

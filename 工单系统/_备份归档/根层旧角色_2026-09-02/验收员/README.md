# 验收员（README）

> **验收证据的唯一落点**。验收员验证（原查验员+真机测验员合并）验收全部交付（代码层+真机层）→ 证据落数据区 → 结论落 ACCEPTANCE_LOG（`0027-mov\docs\ACCEPTANCE_LOG.md`）。

## 证据链入口（倒查用）
- 每工单的证据链索引随验收产物落在 `证据数据\<YYYY-MM-DD>\` 对应日期目录
- 审验员抽查依据见 `审验员\工单证据链映射.md`

## 真机验收标准（红线 + 证据规范）
- ✅ = 截图/journal/命令**可重跑 + 可见目标达成**（非口头计划/机制触发/代码层）
- ⚠️ = 端到端未验 / ❌ = 失败误标 / 🔴 = 缺证据
- 无 UI/后端工单用命令/journal/产物/状态机验证（见 `文档\真机验收标准与方式方法.md` §四）

## 角色合并说明
- 原「查验员 + 真机测验员」合并为单一「验收员」——代码层（变异/全量/契约）+ 真机层（装机/截图/journal）一套验收
- 工单表验收员列是唯一验收列；历史查验员目录归档在旧流转中心

## 与审验员衔接
- 验收员验收（标 ✅）后 → **审验员 AI 审验证据链**（`审验员\审验.py` 查 journal/截图/命令 对账）
- 审验发现问题 → 登记 `处理中心\问题区` → 设计师处理（打回/补证）
- 验收员标 ✅ 须附可查证实物（审验可复现）；**不信自报信实物**

## 四、间距与尺寸阶梯（4 的倍数优先）

- **间距档**：4 / 8 / 12 / 16 / 24（页面边距 16，卡片内边距 12-14，行间距 8，图标间距 4-6）。原生现存 21 档 dp 逐批归并；**一切 padding 必走 dp2px，禁裸 px**（SettingsSheet:143/164、MainActivity:408/4450/4910/5078 等 8 处在案）。
- **行高**：列表行（van-cell）默认 44+；**含右值的行右值单行 ellipsize 不得折行**（AI 模型行「快速对话）」折行瑕疵在案）；**房间列表行高固定、时间列固定宽不换行**（「19:5\n7」折行瑕疵在案）。
- **顶栏**：统一 46px（van-nav-bar 默认）——自有 `.topbar` 56px（tokens.css:152）待并轨，差 10px 属瑕疵。
- **基础件**：icon-btn/头像 40px、tag 高 22px（tokens.css:120-133 在案，沿用）。

## 五、组件规格（定形态，逐项是验收点）

1. **按钮**：主按钮=primary 底+on-primary 字+圆角 12+高 44；次按钮=s1 底+line 边+text 字；文字按钮=primary-text 无框；危险按钮=danger（**退出登录用 danger 文字钮，不放页面底部孤立位**——进账号卡）。
2. **chip**（聊天页 chips 排）：高 30、全圆角、s1 底+line 边、12px 字；**文案不带 ▾ 三角**（用户拍板去除，UPG-25 ①；可点性由气泡交互承担，不靠指示符）；钉选小按钮=34×34 圆角 10（UPG-23 规格）。
   - **命名规则（v1 补，2026-08-30）**：chip 一律用**短显示名**——①模型 chip 显示短名（`DeepSeek`），完整名 `DeepSeek V4 Flash（快速对话）` 作悬浮/长按详情；②工具/功能 chip 短名 ≤4 字，超限按 §排版规则截断；③禁止完整长名占满 chip（防 `DeepSeek V4 Flash（快速对话）` 这类超长名）。
   - **排版规则（v1 补，2026-08-30）**：chip **宽度自适应内容**（不再固定 118dp，去掉硬截断）；长度超 `--chip-max-w`（容器 40%）→ 统一 `…` 收尾 + 悬浮显示完整名；**禁裸 CSS ellipsis 硬截到单字符**（防 `我的能力`→`我`、`DeepSeek V4 Flash…`→`DeepSeek V...` 残缺）；中文截断保证**语义前缀保留**（`我的能…` 而非孤字 `我`）。
   - **胶囊展开规范（v1 补，2026-08-30）**：
     - **形态**：点击胶囊 → **气泡浮层**（锚定胶囊，胶囊上方展开）——圆角 14、白/浅底、描边、阴影（对齐 §五.4 气泡弹层）；宽度锚内容、不超容器；
     - **层级**：一级气泡（列表行）→ 可选二级下钻（标题「‹」返回）；**最多两级**（不无限下钻）；
     - **行元素**：左=名称（+免 key 标 / 状态点）+ 可选副文字；右=chevron / 开关 / radio；**状态点三态**（同 §五.6 四色：绿正常=ok / 红不可达=danger / 灰停用=neutral）；
     - **交互**：点外部关闭；返回箭头；点项=执行（切换/打开/回填）；**空态=引导文案**（「去 XX」「暂无…」）；
     - **气泡字数规定（v1 补，2026-08-30）**——主行/副行各限字数，防 `DeepSeek V4 Flash Vision(多…` / `deepseek-v4-flash-vision-exp` 这类超长失控：
       - **主行（二级·名称）**：≤16 字（短显示名）；超长 → `…` 省略（保留语义前缀）+ 完整名放 profile/detail；模型主行 = 模型短名（`DeepSeek V4`），**模式后缀 `(快速对话)` 不入主行**（作右侧小标签/免 key）；
       - **副行（三级·详情）**：两段 ≤ 一行（如 `provider · 模型简称`）；**技术 id/model id 超长**（`deepseek-v4-flash-vision-exp`）→ **中段省略**（`deepseek-v4-flash-…`）或显示「厂商 · 版本」（`deepseek · V4 Flash`）；`当前`/`免key`/`✓` = **右尾缀小标签**（不占主副行字）；
       - **行数**：主行 1 行、副行 1 行（ellipsis）；**禁**技术 id 全量平铺副行、禁超行数。
     - **展开分类**：
       · 模型 chip / 「MCP 工具」/ MCP 独立胶囊 → **展开气泡**（层级/下钻按内容）;
       · 内置钉选（page 类：订单/信息/记忆）→ **跳页**（不展开）;
       · MCP 独立胶囊点击默认 → **预设指令回填**（低风险/二次确认）;
       · 「＋」管理 → 底部 sheet（另行规范，非胶囊展开）;
     - **禁**：胶囊展开不用全屏 popup/新建页；不无限下钻；跳页仅限 page 类钉选。
3. **卡片/分组**：van-cell-group inset，圆角 14，s1 底，line 分隔。
4. **弹层/sheet**：底部 sheet 顶圆角 16、底色 s0；气泡弹层圆角 14、阴影 0 8 28 rgba(0,0,0,.12)。
5. **开关**：van-switch 默认尺寸，on=primary。
6. **状态点**：7px 圆，ok绿/warn橙/danger红/灰=s3；全 App 同一套。
7. **tab**：下划线式（当前=2.5px primary 短杠），文字 13px。
8. **toast**：深色半透明底 `rgba(26,26,26,.88)`、圆角 8、11px 白字、底部居中。
9. **空态**：text3 文案 + primary 文字按钮引导（「暂无项目，去市场看看」范式）。
10. **时间戳**：10px、text3、等宽数字、**固定宽不换行**。

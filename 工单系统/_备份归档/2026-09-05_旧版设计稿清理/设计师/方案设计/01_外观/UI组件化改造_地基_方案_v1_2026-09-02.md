## 2 病根（本地盘点证据）

1. **组件目录双份手写**：`UiComponentCatalog.kt`（Kotlin，20 条+52 档）与 `AppearanceApp.vue`（Vue，COMPONENTS 数组）不同构、人肉同步——无单一 JSON schema 源。
2. **形态类定义分散**：tokens.css（12 族）/ SettingsPage.vue scoped（SETTINGS 族）/ VaultPage、ModelPage、ChatPage 等**完全写死**未接入编号体系。
3. **无组件运行时**：`<prefix>-<variant>` 只是 class 字符串约定，无注册/context/provider——「可插拔替换」停留在设计稿。
4. **10 页面入口割裂**：每页独立 html + 重复 WebViewAssetLoader/Bridge/主题注入（BizSheet/SettingsSheet/VaultSheet/ModelSheet/AssetsSheet 各一份），无统一页面宿主。
5. **规范与实现漂移**：`MOV设计规范_v2_2026-08-30.md` 记 `--primary:#0E7C5B`（深绿），tokens.css 实际 `#23272F`（灰黑）；暗色 s0-s3、Motion/z/elevation/inset token 规范有、代码无。

## 3 改造范围（地基）

### A1 目录单一数据源（本单核心）
- 建 `前端设计/mov-vue/src/catalog/ui-components.schema.json`（或 .json）：
  `id / name / kind / prefix / variants[{id,label,state}] / defaultVariant / site / order / provider / semanticType`
- 生成脚本（node，`scripts/gen-ui-catalog.mjs`）输出：
  1. `UiComponentCatalog.kt`（CatalogEntry/ComponentVariant/ComponentSpec + 20 编号常量 + components 列表）
  2. `AppearanceApp.vue` 的 `COMPONENTS` 数组段
  3. 断言：Kotlin 与 Vue 生成物与 schema 全等（防手改漂移）
- Kotlin 侧 source 改为生成物；Vue 侧 import 生成物；**双写归零**。

### A2 形态类归层 + 规范对齐
- SETTINGS 族形态类从 SettingsPage.vue scoped 迁入 tokens.css 形态层（与现有 12 族同层）。
- 规范对齐：`--primary` 等以实物定标或改实物（按用户裁决）；补 Motion/z/elevation/inset token 落库或从规范删除。
- 产出：`tools/ui-catalog-audit.mjs`（盘点未接入页面清单作为后续收编目录）。

### A3 统一页面宿主（B 阶段，可拆单）
- 10 入口收敛：共享 PageHost（WebView + WebViewAssetLoader + PagesBridge + applyPageTheme 注入）。
- 拆分决策放 A2 验收后。

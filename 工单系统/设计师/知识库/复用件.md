# 复用件表（回答「什么东西已验证可直接复用？」）

> 收录条件：**已验证可复用**，8 字段齐。字段更严，防变垃圾仓库。
> 出单前必查本库（派单文本填「已查坑位库/复用件库」字段），命中 → 施工范围直接引用。

## 字段说明（每行 8 字段必填）

```
component_id / 版本 / 适用范围 / 最后验证时间 / 关联工单 / 验证状态 / 使用次数 / 已知限制
```

- **component_id**：稳定标识（`工具-<名>` / `脚本-<名>` / `组件-<名>`），改名即新条目
- **验证状态**：`已验证可复用` / `验证中` / `已过时`（过时标「已过时」，不删，保留历史）
- **使用次数**：记录实际复用次数，推动「用起来」而非堆库

## 复用前必做

1. 核对「适用范围」是否覆盖本单场景（不覆盖 → 不强行复用）
2. 读「已知限制」，规避或补足
3. 使用后在「使用次数」+1，并记录本次验证结果（最后验证时间更新）
4. 复用中发现新坑 → 沉淀进 `已知坑.md`（半自动沉淀，见 `README.md` §三）

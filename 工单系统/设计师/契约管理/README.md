## 这个目录是什么

所有**已定稿设计契约**的单一入口：清单 / 指针 / 状态 / 管理规则。

- **主文档**：`契约总览与索引_v1_2026-09-01.md`（12 条契约台账：CT-01 Token → CT-12 模型）
- **原则**：源文档在 `..\方案设计\` 各分区（00_令牌与组件 / 01_外观 / …）；本目录**只做指针管理，不复制正文**（防双源漂移）
- **状态列 = 契约当前权威版本**；版本升级/评审采纳/打回重修 → 更新总览表 + 关联工单卡（工单库）

## 管理规则（详情见总览 §三）

1. 源文档唯一权威，本目录不复制
2. 定稿升版 = 新文件带版本号（旧版留溯源）
3. 重大变更 → 状态列+工单卡双更新
4. 标「工程契约」需 ≥1 轮外部评审（大神 9.x）采纳
5. 跨契约引用用指针，不复制

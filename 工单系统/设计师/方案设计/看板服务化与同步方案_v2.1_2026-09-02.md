## 一、最终模型（大神收敛版）

```
                  工单库.md（单写点·设计师）
                     │
                     ▼
            ┌────────────────────┐
            │  board-server      │
            │  signature check   │ ← mtime+size（P1）
            │  regen lock        │ ← 并发锁（P0-1）
            │  generate          │
            │  stability check   │ ← 生成后二次签名（P1）
            │  atomic publish    │ ← tmp→rename（P0-2）
            └─────────┬──────────┘
                      ▼
               board.html（只此文件可服务）
                      ▼
                   Browser
```

外围双层自愈（P0-3）：
```
Launcher（双击 bat → run.mjs）: health → 活着直接开 / 死了拉起 → 重试 → 打开
Startup ps1（守护循环）: 服务异常退出 → 5s 自动拉起（不在 server 内自 spawn——防进程风暴）
```

## 三、故障与降级（v2.1 更新）

| 场景 | 行为 |
|---|---|
| 库/表变化 | 请求时 regen（锁+稳定校验+原子发布）→ 下次刷新最新 |
| 服务死（开机失败/被关） | 双击 bat → run.mjs health 探测 → 拉起 → 打开；守护 ps1 循环兜底 |
| regen 失败 | 500 诚实报错（不 staleness） |
| 端口占 | BOARD_PORT 改；启动报错退出（守护循环重试） |
| 生成期间输入变化 | 丢弃本次→重生成（≤3） |
| 并发请求 | 锁单例——只有 1 个 regen，其余等 |

## TL;DR

看板从「文件+双击」升级为**本地 HTTP 服务**（`http://localhost:8787`，仅本机可访问）：
**浏览器点刷新 = 服务端检查工单库/表是否变化 → 变化则实时重新生成 → 返回最新**。同步机制仍为 v1.1（严格单写点 + git 串行 + 表可重建）。

**自查发现的漏洞/风险（请大神重点看 §六）**：端口占用、服务崩溃降级、写竞态、多机开放需显式、无鉴权（本机 only）。

---

## 一、架构

```
工单库.md（唯一真相·设计师单写点）
   ↓ 变化检测（mtime 快照）
board-server.mjs（本地·127.0.0.1:8787）
   ├─ GET /        → 变化? → regen() → 返回最新 html（Cache-Control: no-store）
   │                 (没变 → 直接返回当前 html)
   ├─ GET /health  → JSON 探针（ok/mtime/htmlMtime）
   └─ regen()      → 审验员/orders-overview.mjs（投影+断言）→ board-build.mjs（模板渲染）
浏览器（http://localhost:8787）——点刷新=立即最新；页面自带 60s 自动重载（双保险）
```

## 二、服务层设计

| 项 | 值 | 理由 |
|---|---|---|
| 端口 | 8787（`BOARD_PORT` 可改） | 避开常用端口 |
| 绑定 | **127.0.0.1 默认**（`BOARD_BIND=0.0.0.0` 才开放） | 工单信息不对内网默认暴露 |
| 鉴权 | 无（本机 only） | 绑定环回=只有本机进程可连 |
| 生成 | 变化才 regen（mtime 快照比对） | 刷新不浪费 |
| 缓存 | `Cache-Control: no-store` | 防浏览器缓存旧版 |
| 启动 | 开机自启（Startup ps1）+ 双击 bat 兜底 | 双入口 |
| 依赖 | node 内置 http/fs/child_process（零 npm） | 无新依赖 |

## 三、故障与降级

| 场景 | 行为 | 用户看到 |
|---|---|---|
| 库/表变化 | 请求时 regen（~1s） | 下次刷新=最新 |
| 服务没起（开机自启失败/被关） | bat 双击=打开 URL → 连接被拒 | 解决：重新双击 bat（启动服务+打开）——**bat 已含启动逻辑** |
| regen 失败（mjs 报错） | 返回 500 + 错误文本 | 看板不显示旧数据——诚实 fail（不staleness） |
| 端口被占（8787 被其他程序） | listen 报错退出 | 设 BOARD_PORT=8788 重启 |
| 与本机其他生成进程（bat 手动）同时写 html | 最后写赢（竞态低——低频） | 内容=其一（同源数据，无实质差异） |

## 四、多机延伸（阶段 2 雏形·默认关闭）

```
显式开放：BOARD_BIND=0.0.0.0 启动 → 局域网其他机器浏览器访问 http://<本机IP>:8787
防火墙：需放行 8787 入站（Windows 默认拦——需用户手动开）
```

**注意**：开放=无鉴权（只读看板——工单标题/状态/卡点含内部信息——**默认不开**；真要开建议先把「敏感性」与「便利性」权衡——**由用户拍板**）。

## 五、与同步方案 v1.1 的一致性

- 服务=**只读投影**（不写库/表——与 E4 契约一致）
- 单写点不变（设计师仍唯一写库人）
- 表重建 SOP 不变（冲突=先 md 后表）
- 服务不新增写面（regen 只写生成物目录）

## 六、漏洞自查表（请大神重点评审）

| # | 风险 | 现状 | 我的判断 |
|---|---|---|---|
| V1 | **端口 8787 被恶意本机进程占用**（恶意监听/DNS rebinding） | 本机内网工具——本地进程=已在本机有权限 | 可接受（本机进程权限已含读取工单）——不防 |
| V2 | **regenerate 命令注入**（regen 用 execFile 固定路径——无 shell 拼接） | 固定参数 | ✅ 无注入面（execFile 不经过 shell） |
| V3 | **路径遍历**（req.url 拼文件？） | server 只 serve 固定 html（url 白名单 `/`、`/health`） | ✅ 无遍历 |
| V4 | **大请求/DoS** | 单机环回——只有本机 | 可接受 |
| V5 | **工单信息泄露**（若开放 0.0.0.0） | 默认 127.0.0.1；开放需显式 env+防火墙 | ✅ 默认安全；开放=用户拍板 |
| V6 | **服务崩溃=看板冻结**（html 停在旧） | 无 self-heal | **待定**：要不要自动重启（如看板.bat 每次先 health 检查→死则拉起）？——请大神定 |
| V7 | **html 内嵌数据体量**（58 卡全量=128KB） | 本地无碍 | 多机开放时可接受 |
| V8 | **生成与提交竞态**（agent 撞上 regen 写 html） | 低频 | 可接受（生成物非真相） |
| V9 | **mtime 快照粒度**（2s 内两次变化） | 变化即 regen（无去抖） | 可接受（regen 幂等）——要不要加去抖？ |

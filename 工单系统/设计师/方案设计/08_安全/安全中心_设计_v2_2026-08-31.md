> 设计师 @2026-08-31 ｜ 状态：**评审通过·有条件冻结**（大神 8.6：方向对；最大修正 = **S/A/B 是"结果仪表盘"，不是"控制器"**；改 6 点后进 UI + UPG 拆解）

## 二、安全策略清单（分组 · v2 重排）

### 操作保护
| 项 | 档位 | 说明 |
|---|---|---|
| 审批模式 | 每次询问 / 自动放行（写类） | 写类操作是否确认 |
| 敏感操作确认 | 高风险询问 / 按次 | 读隐私/位置/凭据类确认 |
| **第三方工具访问**（=MCP，用户话） | 读取自动允许 / 修改前询问 / 敏感始终询问 | 底层 MCP，用户不感知 MCP 词 |
| 自动记住安全偏好 | 开 / 关 | 同类确认自动收敛（越用越顺） |

### 数据保护
| 项 | 档位 | 说明 |
|---|---|---|
| **数据足迹** | **查看 ›**（非开/关） | **审计=系统基础能力，不可整体关闭**；用户只看"我能看到哪些足迹" |
| 敏感信息显示 | **始终隐藏 / 查看时显示**（30s） | 不用"掩码/明文"（大白话；"明文"太像安全开关） |
| **数据同步** | 本机 / 加密同步 | **≠ 对外分享**（两个独立安全边界） |

> **对外分享** 从同步拆出：单独维度（每次询问）——**加密云 ≠ 自动允许对外**。

## 三、等级 = 结果仪表盘（v2 关键修正）
```
用户调整具体策略（操作/数据）
        ↓
安全策略变化 → 系统计算
        ↓
安全等级 / 体验等级（结果 · 显示）
```
- **用户不直接选 S/A/B**（等级是**结果**，不是**控制器**——避免"我选 S 系统到底做了什么？"的困惑）；
- **等级 = 策略聚合结果**：`max(用户策略计算, SystemHardBoundary 最低安全等级)`；UI 显示「**最低安全保护：B**」；
- 两栏**独立**（安全≠体验≠简单反向；本机加密/记住偏好=两全）；
- **⚠️ 体验等级是双刃剑（评审 P3）**：两栏并排 + 用户对字母的本能最大化（"两个都想 S"）→ 可能**反向激励优化体验（=降安全）**。对策：①摘要用**打扰频次**锚定（"少打扰"而非"体验得分"——已做）②**体验等级 = 打扰度映射**（高=少打扰），不是独立可追逐的"得分"③**硬边界兜底**（全放开也恒守资金/凭据/绝密/安全控制）④L2 用户路径测试"等级展示不诱发全放开"（见 §六）。

---

## 四、硬边界（类别 · 含安全控制）
**SYSTEM_HARD_BOUNDARY**：
```
Credential（凭据） / Financial（资金·支付） / Secret（绝密） / Identity（身份） / SecurityControl（安全控制）
```
- **安全控制本身也是硬边界**：`approval.setMode` / `permission.approve·deny` / `KeyVault` / `SecurityGate`——**不可被用户体验设置间接绕掉**；
- 硬边界项 UI「🔒 已保护」灰显不可调；
- 等级兜底：**max(用户策略, 硬边界最低安全等级)** → 正常显示「最低安全保护：B」（不说死"永远≥B"，用 max 表达，为未来企业/合规/儿童策略留口）。

---

## 五、体验优化呼应
- 等级是**结果** + **策略摘要**（用户不困惑"我到底改了什么"）；
- 审计=系统基础能力（数据足迹=**查看›**，不整体关——权限/审批/凭据访问/外发/安全撤销恒留痕）；
- 敏感=始终隐藏/查看时显示；第三方=用户话"工具访问"；同步≠对外——**大白话、不吓人、有度（硬边界恒守）**。

## 六、验收测点（v2）
- **L1**：①等级=结果（用户**不能直接选 S/A/B**；改策略→算等级→显示——变异：直接调等级→必红）②策略摘要（"当前：严格保护·少打扰"在——变异：无摘要→必红）③分组（操作/数据）④**硬边界含安全控制**（变异：approval.setMode 可被体验设置绕→必红）⑤**审计系统基础不可关**（变异：数据足迹可 OFF→必红）⑥敏感=始终隐藏/查看时显示（变异：明文→必红）⑦**同步≠对外**（变异：加密云=自动对外→必红）⑧等级计算 max(用户,硬边界)（「最低安全保护：B」显示）⑨**体验等级=打扰度语义**（显示"少打扰"而非"体验得分"；变异：等级展示鼓励"追体验得分/优化体验"→必红）。
- **L2 真机**：设"最严"→安全 S/体验 B；"最放开"（资金/凭据/安全控制仍守）→体验 S/安全 B/硬边界灰显；调策略→两栏+摘要实时变；数据足迹=查看入口（不可关）；敏感"查看时显示 30s"；第三方工具访问（无 MCP 黑话）；**⑨用户路径测试**：等级展示**不诱发"全放开"操作**（用户正常路径不该因看到两栏就一键全放开；新用户默认档不过度打扰、不激进降安全）**⑩默认档**（新用户 onboarding 首日：日常写入/敏感操作询问频率**合理**、默认=平衡档——变异：默认过严→首日高频打扰→必红）。
- **L3**：等级聚合契约测试；硬边界=max 兜底；审计强制留痕；同步/对外独立防线（依赖检查）。

## 七、评审更新（v2 全吸收）
大神 8.6：**6 点全部落地**——①等级=结果仪表盘（非控制器）②策略摘要 ③7 项分组（操作/数据）④审计=系统基础能力（不可整体关）⑤敏感=始终隐藏/查看时显示 ⑥同步/对外拆两维。**另吸收**：硬边界扩 5 类别 + **安全控制硬边界**（approval.setMode/KeyVault/SecurityGate 不可被体验绕）；等级=max(用户,硬边界)（「最低安全保护：B」，为企业策略留口）；第三方 MCP→**第三方工具访问**（用户话）；**不再增加安全设置**。

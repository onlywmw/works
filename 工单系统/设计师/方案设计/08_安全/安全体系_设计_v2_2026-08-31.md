> 设计师 @2026-08-31 ｜ 状态：**v2.1 最终冻结候选**（大神 9.0 终评：方向收敛；补 **4 个 P0** + **4 个 P1** 锁死；**不再扩体系，只把边界钉死**）

## 〇、一句话
**所有安全决策经过 SecurityGate 单一入口**：`subject × resource × operation × data × destination` → classify → policy → risk → decision → **DecisionToken** → Executor.verify → execute。MCP 走 Gatekeeper（Normalize → Tool Capability → Schema → Resource → Classify → Tier → Policy → Gate）。**授权与执行绑定**（TOCTOU）、**安全撤销可中止运行中任务**、**用户策略在系统安全边界内优先**、**数据流安全**（谁→访问什么 + 数据从哪→到哪）。**边界钉死，不再加层。**

---

## 一、威胁模型（+ TOCTOU / 数据流 / 批量）
防：数据泄露 / 越权 / **TOCTOU（检查与执行不同刻）** / MCP 恶意(动态工具·别名·包装·参数注入) / **批量低危攻击（单次FREE×高频）** / 对外泄密（**含数据流：机密→外部**）/ 绕过审批 / 元数据泄露 / **索引泄露语义（FTS 泄密）**。/ 不防过度：不为绝对安全牺牲流畅/功能/知情。

## 二、设计原则（体验优先 · 六条）
1. **不打扰 + 知情**：零操作、一句"数据已本机加密"；换机优雅降级；
2. **关键才确认**：高敏/对外/不可逆 → 大白话一次；
3. **透明可查**：数据足迹可查，不暴露技术细节；
4. **渐进**：默认自动，可上调；**用户可收紧，但不可突破系统安全边界**（System Hard Boundary）；
5. **可撤销（两类）**：体验型 5s / 安全型立即（**含中止运行中任务**）；
6. **安全不破坏功能**：加密字段可用（等值检索/受限搜索），FTS 分级防泄露。

## 三、架构（Security Control Plane · v2.1 升级）
```
                    ┌──────────────────────┐
                    │    Policy Manager    │  System / Default / User / Session
                    │  (Hard Boundary先)    │  (用户可收紧·不可破系统边界)
                    └──────────┬───────────┘
                               ↓
┌─────────────────────────────────────────────────┐
│                 SecurityGate                    │
│  Subject × Resource × Operation × Data × Dest   │  ← 含数据流(来源/分类/去向/目的)
│  classify → policy → risk(含聚合) → decision    │
│              ALLOW / ASK / DENY                 │
└────────────────────────┬────────────────────────┘
                         │  DecisionToken{decision,subject,resource,operation,
                         │    dataClass,dest,purpose,policyVersion,expiresAt,scope,authorizationId}
                         ↓
┌─────────────────────────────────────────────────┐
│                 Executor.verify(token)          │  ← 执行前验 token(未过期/资源未变/授权仍有效)
│                       execute                   │          防 TOCTOU
└───────────────────────┬─────────────────────────┘
                         ↑
                  MCP Gatekeeper ← Untrusted MCP
                  (Normalize→ToolCapability→Schema→Resource→Classify→Tier→Policy→Gate)
       KMS / Permission / Audit 为 SecurityGate 的下层组件
```
- **SecurityGate 单一入口**；**DecisionToken**（授权决策→执行绑定，防 TOCTOU——P0-01）；
- **Data Flow Policy**（数据从哪→到哪→经过→落哪——P0-04）；
- **Executor.verify**（执行前重验，防"刚检查过可执行"）。

## 四、层详解

### 4.1 KMS / 加密（+ 评审纠正：确定性加密限等值 · FTS 分级收紧）
- KeyVault(AES-GCM 不可导出) + 主密钥封装；字段/文件/端到端；密钥轮换；换机优雅降级；
- **确定性加密**：**只用于受限等值检索**（`WHERE enc=enc("标签")`），**不作为通用排序/范围查询方案**（评审纠正：排序/范围需 order-preserving 或脱敏派生——P1 单列）；随机化加密：最强、不可搜索（凭据值）；
- 解密缓存：会话级（防频繁弹窗）；
- **FTS 分级（评审收紧 · 防索引泄露语义）**：
  | 分类 | FTS |
  |---|---|
  | 普通数据 | 明文 FTS |
  | 内部 | 去标识索引 |
  | 机密 | 受限搜索 / 精确搜索 |
  | **绝密** | **默认不进全局 FTS**（防"主数据加密了、索引泄露语义"） |
- **加密字段正式清单**（P1-7）：字段 → 敏感级 → 加密方式 → 可搜索 → 进 FTS——逐字段表（不删，作为 P1 补）。

### 4.2 权限 + MCP Gatekeeper（+ Tool Capability Identity · P1-6）
- 权限矩阵：主体(user/账号/`mcp:xxx`/系统)×资源×操作；默认拒·最少权限；credential 默拒 MCP；
- **MCP Gatekeeper**（v2.1 完整管线，**Tool Identity 不可信**——第三方 server/tool 元数据是未可信输入）：
  ```
  Untrusted MCP → Normalize → Resolve Tool Identity → Validate Schema
      → Resolve Resource → Sensitive Classification → PermissionTier → Policy → SecurityGate
      → DecisionToken → Executor.verify → execute
  ```
  - **tool name ≠ permission identity**：不能 `if(tool==="credential.get")`；解析为内部可信 **ToolCapability / ResourceCapability / OperationCapability**（防工具改名/别名/动态/第三方包装绕权限——P1-6）；
  - 拦截点双向；参数粒度字段级；白名单(server/tool/tool+参数模式)；性能轻量判定(不解LLM·缓存<1ms)；
- **参数校验**（UPG-46 四类阻断）+ **风险分级 L0-L3**。

### 4.3 敏感分级
公开/内部/机密/绝密 + 字段级 sensitive；机密必加密、绝密独立强加密；掩码/二次确认；元数据脱敏。

### 4.4 门控 + Policy Manager（+ System Hard Boundary · P0-03）
- `SecurityGate.evaluate → ALLOW/ASK/DENY`；工具 permissionTier、MCP 写入、对外、审批（大白话）；决策可解释；
- **Policy Manager（分层）**：
  ```
  System Hard Boundary → Default Policy → User Policy → Session Policy
  ```
  - **用户可收紧，但不可突破系统安全边界**（例：系统 credential=DENY，用户不能改成 ALLOW，只能更严）——**是"用户策略在系统允许的安全边界内优先"，不是"用户无限覆盖"**（评审 P0-03）；
  - **Data Flow Policy（P0-04）**：SecurityGate 增加 **data×destination** 维度：
    ```
    数据流: SOURCE → DESTINATION, CLASSIFICATION, PURPOSE
    Confidential + 外部(MCP/网络) + 写作 → ASK
    Secret + 外部 → DENY
    ```
    ——"对外端到端+最小化"落到工程层；
  - 策略加载/合并/覆盖/冲突/版本化/审计（谁改了什么策略·为什么）。

### 4.5 审计 / 可撤销（+ 撤销运行中任务 · P0-02 · 审计完整性 · P1-8）
- 不可变审计（谁/何时/对什么/读·写/授权原由）；数据足迹可查（透明不打扰）；
- **撤销两类**：体验型(删除/移动) 5s 撤；**安全型立即**，且**工程定义到运行中任务**（P0-02）：
  ```
  未来调用 → 立即 DENY
  正在执行 → cancellation/abort 立即终止
  无法中止 → 撤销立即生效 + 停止后续数据发送 + 标记任务 revoked + 记录审计
  ```
- **审计完整性（P1-8）**：不只 append-only——明确 **hash chain / integrity check**（防本地库被改，"不可变"非仅"UI 无删除钮"）。

## 四·现网安全机制（MOV 已有 · 详细整合）

### 4.6 设置 · 审批模式（approvalMode）
- **设置入口**：「审批模式」行（设置页），点切 `ask`（默认权限·写类每次确认）/ `open`（全放·高危子集仍确认）；桥 `approval.getMode` / `approval.setMode`；
- **模式语义**：`DEFAULT_PERMISSION(ask)` = 只读放行 + 写类弹窗确认；`FULL_ACCESS(open)` = 全放，**高危子集仍确认**；
- **策略持久化**：`recordApprovalPolicy` 落盘 + `restoreApprovalPolicy` 重启可恢复（策略可回溯、生效即权威）；
- **审批弹窗**（大白话四块 §5.0）：读=放行 / 写类·敏感=确认；同意/拒绝；同类同意；30s 自动取消；记录到安全日志；
- **防绕过**：`approval.setMode` 收编进 `uiOnlyMcpTools`（AI/MCP 不可自助切 never 绕过写类 ASK——UPG-02 M3-R2）；`permission.approve/deny` 亦 UI-only。

### 4.7 工具/权限安全（PermissionGuard · gate/ask/free）
- **permissionTier(tool) → free/ask/gate**（单源访问器；前端只消费 tier 字符串，名单不出类——防镜像 BP 前科）：`systemBaselineDeny`→gate／`sensitiveTools`→gate/ask／`writeTools`→ask／`harmlessTools`→free；
- **无害级特判**：`harmlessAutoAllow` + `file.write` 工作区路径校验 + private 凭据写除外；`obsidian.file.write` 精确匹配防误捕（UPG-28）；
- **高风险**：`isHighRisk`（shell.exec/凭据路径/越界 `..`/反斜杠/绝对路径 → 实质级 ask）；
- **UI-only 白名单**（`uiOnlyTools`）：`permission.set_mode/approve/deny/presentation.set_mode/vault.peek`——仅 UI 可调，不暴露 AI/MCP（防自助提权/绕过审批）。

### 4.8 第三方 MCP 安全防范（详细）
- **接入审查**：`McpExtDiscovery` `Result.meta` 结构校验（`type==object && properties is map` 才透传，非法整条回落）——防非法外部 schema 污染 AI 面；
- **三态回落**（`mountExtTools`）：外部元数据 → 登记层 → 外部模板串；两套不混（宿主「MOV 工具:」语义）——防注入空 schema；
- **白名单归级**：第三方 MCP 工具按 `permissionTier` 归级（读=free/写=ask/敏感=gate）；
- **参数校验**（UPG-46 四类阻断：缺失必填/类型不符/越界路径/危险取值）；
- **风险分级 L0-L3**（L0 无害→L3 高危双重确认）；
- **UI 隔离**：第三方 MCP 不可调 UI-only 工具（set_mode/approve/deny/vault.peek）——防提权；
- **凭据隔离**：第三方 MCP 不接触 KeyVault 明文（vault 凭据仅 UI 填充、精确到条目授权读取）；
- **审计**：第三方 MCP 调用走 `journal`（tool/call + tool/result）。

### 4.9 验收审计标准（安全 · 详细）
- **审批审计**：审批决策（同意/拒绝/同类同意/30s 自动取消）落审计；`recordApprovalPolicy` 持久化可回溯；
- **工具调用审计**：`journal`（tool/call 参数摘要 + tool/result）每次调用留痕；
- **不可变**：audit 只追加（+ v2.1 补 hash chain/integrity）；
- **验收测点（变异锚）**：①敏感工具误入 harmless→必红 ②绕 guard 直接执行→必红 ③uiOnly 工具可被 AI/MCP 调（set_mode 提权）→必红 ④approval.setMode 不在 uiOnly→必红 ⑤obsidian.file.write 误捕/漏→必红 ⑥参数校验缺失→必红。

## 五、用户体验设计（核心 · 体验为先）

### 5.0 审批弹窗（定海神针 · 最直观触点）
（四块秒懂 / 大白话三原则 / 不吓人·直觉·给掌控·轻量(30s+同类合并)·优雅(demo v4)·可解释）——保留；**DecisionToken 对体验**：检查(授权)在后台毫秒级生成 token、执行绑定，**用户体感"无感放行/一次确认"，无额外等待**。

**审批触发清单 v0.1（+ Risk Aggregation · P1-5 补充）**：
| 操作 | 审批 |
|---|---|
| MCP 读普通资产 | 否 |
| MCP 读凭据值/记忆敏感段 | 是 |
| 写类工具 | 是 |
| 删除资产(有回收站·**单个普通**) | 否 |
| 永久删除 / 清空回收站 | 是 |
| **删除大量资产 / 敏感资产 / 唯一副本 / 安全凭据** | **是**（Risk Aggregation：单次低危×高频/批量/敏感级 = 高危） |
| 上传外部 / 分享外部 | 是 |
| 支付/扣费 | 是 |

### 5.1 加密知情 + 5.2 体验红线
（一句"已本机加密"、换机提示；不暴露密钥/算法/分级；不打扰、关键才确认、拒绝不降级、可撤(两类)、数据足迹可查、FTS 分级不破坏搜索）——保留。

---

### 5.3 安全体验优化（用户视角 · 8 场景 + 验收）
**目标**（呼应"体验优先"）：**该守才守（0 打扰）· 守得舒服（1 次秒懂）· 可控（可撤/不降级/透明）· 不吓人（人话）**。后台复杂、用户界面极简。

| # | 场景 | 体验优化 | 验收（变异锚=必红） |
|---|---|---|---|
| 1 | 平时·零打扰 | 本机自动加密 / 无害调用静默，无弹窗无提示 | free 级任何弹窗/提示 → 红 |
| 2 | 该守才·一次秒懂 | 写类/敏感/对外 → 一次大白话（一句它要做什么/影响什么 + 同意/拒绝 2 键 + **同类记住** + 30s 自动取消） | 技术黑话 / 多次确认 / 无同类合并 → 红 |
| 3 | 拒绝·不降级 | 拒绝=这次不做，功能照常 + 一句"好的这次不执行" | 拒绝后功能减 → 红 |
| 4 | 误触·5s可撤 / 吊销立即 | 可逆删除/移动 5s 撤；安全吊销/授权终止**立即** | 安全吊销也 5s 缓冲 → 红 |
| 5 | 换机/异常·人话 | 换机"部分数据需重录"；异常给**人话+可操作建议**（"某密码可能泄露，建议修改"），不技术码/不恐慌 | 抛技术码 / 恐慌文案 → 红 |
| 6 | 安全状态一屏 | 隐私设置一眼"已本机加密保护"+ 数据足迹可查；**绝不主动弹安全通知** | 主动弹安全通知 → 红 |
| 7 | 越用越顺 | 高频安全确认**自动记住偏好**（同类收敛、确认越来越少；敏感/高危仍每次确认） | 重复确认不收敛 → 红 |
| 8 | 决策毫秒级 | 安全检查**后台毫秒级**（DecisionToken 生成/验证），不阻塞主流程 | 安全检查阻塞 → 红 |

**验收分级**：L1（上表变异锚全红）；**L2 真机**：8 场景走查（平时零打扰 / 一次秒懂 / 拒绝不降级 / 5s可撤·吊销立即 / 换机人话 / 安全状态一屏 / 越用越顺 / 毫秒不阻塞——截图/回放）；**L3**：体验规则（无感/人话/可撤/不降级/不主动打扰）契约测试 + 依赖检查（不因安全破坏功能/流畅）。

## 六、各模块接入
凭据(机密+默拒MCP+精确授权+独立密钥) ｜ 记忆(Timeline+分级+门控+FTS分级) ｜ 资产(基于本层) ｜ MCP(Gatekeeper+Capability+白名单+审计) ｜ 网络(数据流门控+端到端+最小化) ｜ 审批(gate+大白话+审计)。

## 七、用户可见（克制）
只看到：必要一次确认(大白话)、隐私设置数据足迹、撤销、一句加密知情；不看到：密钥/算法/分级/权限矩阵/DataFlow/DecisionToken；不推送安全惊吓。

## 八、验收（安全契约 + 体验 + 统一接入 · 含 4 P0 变异锚）
- **L1**：①KeyVault 不可导出/字段文件/端到端加密(含 **FTS 分级**：绝密不进全局 FTS→变异:绝密进FTS=必红) ②权限矩阵默认拒/credential 默拒 ③**DecisionToken**：SecurityGate→token→Executor.verify（变异:执行不验 token/resource 已变仍执行=必红——TOCTOU） ④**Gatekeeper Tool Capability**（变异:tool别名/包装绕权限=必红；绕 gatekeeper 读凭据=必红） ⑤**System Hard Boundary**（变异:用户策略突破系统边界 credential→ALLOW=必红） ⑥**Data Flow**（变异:Secret+外部=ALLOW=必红） ⑦两类撤销+**运行中任务撤销**（变异:撤销仍继续发送=必红） ⑧Risk Aggregation（变异:批量删除 FREE=必红） ⑨审计 hash chain（变异:改审计日志不红=必红） ⑩加密字段可用性。
- **L2 体验**：零操作+知情；free 无感；敏感/对外/不可逆→一次大白话(按触发清单+聚合)；拒绝不降级；删除5s撤/授权吊销立即(含中止)；数据足迹可查；无技术暴露；FTS 分级不破坏搜索。
- **L3**：全模块走 SecurityGate+Gatekeeper(依赖检查/契约测试)；权限矩阵一致；策略版本化/分层；审计可追溯+完整性。

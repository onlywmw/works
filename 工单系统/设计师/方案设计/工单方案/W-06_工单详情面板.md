## 一、背景

工作台现状：点开工单只能看到一行状态——方案、验收标准、红线、交接段全看不到（"样子货"另一半根因）。详情其实都在源文件里：`工单库.md` 每单一节（标题/背景/验收标准/红线/派单交接段/追加项/定夺），`设计师\方案设计\` 每维一卡。本单把详情结构化进 json，前端加详情抽屉。

## 二、施工范围

1. **sync 解析工单库.md**：按 `# UPG-NN` 节切分，节内按 `##` 小节结构化（标题/背景/验收标准/红线/派单交接段/追加项/定夺，原样保留 markdown 文本）→ 每条工单记录加 `detail` 字段；
2. **sync 关联方案卡**：按命名约定 `设计师\方案设计\<ID>_*.md` glob 匹配（如 W-05_*、S-04_*），命中则 dims/基建事件记录加 `designDoc` 字段（全文 inline）；
3. **前端详情抽屉**：点击工单/事件/挂账卡片 → 右侧滑出抽屉（60% 宽，Esc/点遮罩关闭），分节渲染 detail（markdown 转 HTML **必须转义防 XSS**，不引重型 md 库，手写最小渲染器：标题/列表/表格/粗体/代码）；
4. **挂账/验收记录**同待遇：backlog 的 detail 列、accept_events 的 summary 进抽屉。

## 三、验收标准

- **L1**：构建绿 + verify 断言：UPG-13 的 detail 含「追加项 #8」「追加项 #9」节（变异：删工单库一节 → 必红）；W-05 记录 designDoc 非空；XSS 用例（详情含 `<script>` → 渲染为纯文本）；
- **L2**（真实浏览器截图入 ACCEPTANCE_LOG）：点开 UPG-13 → 抽屉分节展示方案/验收/红线/追加项；点开 W-05 → 方案卡全文可见；375px 移动端抽屉可用；
- **L3**：工单库.md 改一行 → sync --deploy → 抽屉可见变化 → 还原（规则 18）。

## 四、红线

- 只读：抽屉纯展示，零编辑入口；
- XSS 红线：markdown 渲染必须先转义再标记，禁止 innerHTML 直插源文本；
- 脱敏：detail 过 sync 打码管线（手机号/口令规则同现有）；
- 不改现有树/卡片结构，只加抽屉；
- Token/KV 申报「无影响」。

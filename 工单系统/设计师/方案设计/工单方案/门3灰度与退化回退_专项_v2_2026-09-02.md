## 〇、总纲（一句话）

## 一、统计口径（五件事之①——去重）

### 1.1 坏调用定义（不要相加）

```text
bad_call = isError OR fabricate_hit        —— 按 call_id 去重
一次调用最多贡献 1 次坏调用（两事件同次调用 ≠ 2 次失败）
```

### 1.2 核心指标

```text
degradation_rate = bad_calls / eligible_calls
```

**分别保存**（供后续定位）：`error_count` / `fabricate_count` / `bad_call_count`——不合并成一个 `failure_count`（分清「执行失败」vs「参数编造」）。

### 1.3 最小样本量（五件事之②——防冷启动误杀）

```text
触发条件 = eligible_calls >= MIN_CALLS(20)
         AND degradation_rate >= DEGRADE_THRESHOLD(30%)
```

- **30% 是 MVP 安全止损阈值，不是统计学证明的正确阈值**（文档显式声明）
- 无历史 baseline 时不假装知道真实阈值

### 1.4 紧急熔断（快速保险）

```text
普通路径：N≥20 且 bad_rate≥30% → shadow
紧急路径：连续 3 次 bad_call → 立即 shadow
```

## 二、聚合单位（五件事之③——技能级）

- **会话 = 观察窗口，不是最终归属单位**
- 每个 signal 必须绑定 `skill_id + call_id`：

```text
Session → Call → Skill ID → Skill-specific counters
```

- 回退对象 = **候选 Skill 本身**（不是 Session）
- 多技能同会话：`call_id=C123, skill_id=S456, isError=true → 只计入 S456`
- **若 guard 事件无 skill_id/call_id → 该事件不能作为技能级自动回退信号**（「有事件 ≠ 有可靠归属」——不是零新埋点就万事大吉）

---

## 三、状态机（五件事之④——自动降级/人工恢复分离）

```text
PROPOSED → SHADOW →（N 个有效观察）→ CANARY → STABLE
                                          ↓ 退化
                                       DEGRADED → SHADOW
                                                   ↓ 人工诊断/修复
                                         人工批准 → CANARY（恢复谨慎化）
```

- **回 shadow：自动**——shadow 是安全态，等人工确认=把自动防线变回人工防线
- **重入 canary：人工确认**——「降级自动化，恢复谨慎化」
- 禁止非法跳转（如 SHADOW→STABLE 绕过 canary）

### Ledger 事件语义（分开记录）

| 事件 | 含义 |
|---|---|
| `DEGRADED` | 检测器判断候选技能发生退化（可能失败在准备阶段） |
| `ROLLED_BACK` | 系统**实际完成** canary→shadow 切换（状态写入成功） |

两者可能不同时成立（检测到了但写失败/并发冲突）——**审计必须能区分**。

## 四、V1 信号边界（五件事之⑤——不扩）

| 类别 | 信号 | 动作 |
|---|---|---|
| **自动回退** | `isError` · `fabricate_hit` | 计数→去重→聚合→阈值→自动 shadow |
| **观察不判定** | steps · latency · retry · tool switching · route length | 只进诊断/观察，不回退（任务复杂度变化≠技能退化） |

---

## 五、依赖与前提（3 个先决契约）

1. **Signal Schema 稳定**：`skill_id / call_id / event_id / timestamp` 四字段必须存在——否则无法可靠归属+幂等
2. **Persistent Counter Store**：持久化位置/并发更新语义/幂等 key/崩溃恢复——四要素齐
3. **Gate State Machine**：正式状态（PROPOSED/SHADOW/CANARY/STABLE/DEGRADED）+ 非法跳转拒绝

## 一、算法情况

### （一）算法流程

用户输入（文本）→ ①客户端对话编排（上下文组装、记忆与画像注入、系统提示词定型）→ ②内容安全前置过滤 → ③第三方已备案大语言模型 API 生成（DeepSeek / GLM / Kimi，HTTPS 加密传输）→ ④工具调用编排（可选节点：模型输出经权限分级与安装审批机制调用本地工具，工具结果回注模型继续生成）→ ⑤生成内容后置过滤 + 防凭空声称校验 → ⑥客户端展示（AI 生成内容显著标识）。

（提交时建议把上述六节点画成流程图，每节点粒度不大于单个模型或策略。）

### （二）算法数据

**对话输入类输入数据**：用户输入的文本（中文为主，可含英文），非生物识别信息；可含用户主动提供的图片（拍照 OCR 场景，图片在设备端本地识别为文本后进入对话）。

**对话回复类输出数据**：模型生成的文本（中文为主），经安全过滤后展示；无文件输出，纯界面文本。

**工具调用类中间数据**：本地工具（文件读写、浏览器访问、任务计划等）的执行参数与结果文本，仅在设备端与当次对话上下文内使用。

**训练数据**：无。本算法不自行训练模型，不涉及训练数据采集与使用。

**语种/模态**：输入文本（中文为主）、输出文本（中文为主）；无跨模态生成。

### （三）算法模型

**第三方大语言模型（外购技术服务）**：DeepSeek（深度求索）、GLM（智谱 AI）、Kimi（月之暗面）等，均为已完成国家备案的大语言模型；模型类型为 Transformer 架构生成式语言模型；版本与更新由第三方运营方管理，我方接入时核验其备案状态并持续跟踪。模型评价指标与效果以第三方公示为准。

**自有规则型节点**：对话编排器（上下文窗口管理、记忆注入规则）、内容安全过滤器（规则匹配）、防凭空声称校验器（规则型事实校验）、工具调用权限分级与审批器（规则引擎）。均为基于规则的人工定义方法，无统计学习成分。

**预处理方法**：输入文本的上下文截断（预算口径管理）、敏感信息（凭据类）受控注入（信息库明文只直填页面、不进入模型上下文）。

**后处理方法**：生成文本安全过滤、防幻觉校验提示、AI 生成标识附加。

### （四）干预策略

**内容安全前置/后置过滤**（自动）：目标——拦截违法违规与不良信息的输入与输出；生效时间——全时段；影响范围——全部对话请求与回复；依据——《网络信息内容生态治理规定》等；策略来源——人工制定的规则库，持续更新；预计失效时间——长期有效，随法规与风险态势更新。

**工具调用权限分级与安装审批**（自动+人工）：目标——防止越权工具调用与恶意能力安装；生效时间——全时段；影响范围——全部工具调用；规则——读取凭据/支付/身份类敏感能力默认拒绝，第三方能力先审后发（人工审核上架）。

**防凭空声称校验**（自动）：目标——降低模型幻觉对用户的误导；对"声称已完成但无实际工具调用"的输出进行校验与提示。

## 二、服务提供情况

**服务方式**：通过 MOV AI App（Android）向社会公众提供智能对话服务；用户触发式实时调用，无批量处理。

**服务对象**：社会公众（C 端用户），不面向 14 周岁以下儿童。

**数据形态与共享**：对话内容经 HTTPS 传输至第三方已备案大模型 API 用于生成回复，不向第三方提供用户手机号等账号信息；无其他对外数据共享。算法中间结果（工具调用记录等）仅存储于用户设备本地，不与其他服务共享。

**算法更新频率**：自有编排层随应用版本更新；第三方模型版本由其运营方更新，我方跟踪其备案状态。

## 三、风险研判

**（一）算法滥用**：存在用户通过精心构造的输入诱导模型生成违法违规、不良信息内容的风险（如涉政有害、淫秽色情、虚假信息等）。影响分析：MOV 为闭域对话应用（内容仅对话双方可见，无公开传播渠道），滥用影响限于单用户会话范围；已通过前置过滤、后置过滤、第三方模型自身安全能力三层拦截，残余风险低。

**（二）算法漏洞**：第三方大模型存在固有输出不可控性（幻觉、偏见、不当内容）；自有编排层可能存在上下文污染。影响分析：幻觉可能导致用户获得错误信息；已通过防凭空声称校验、AI 生成标识（明示"内容由 AI 生成，请注意甄别重要信息"）缓解；不涉及金融、医疗等高风险决策场景，风险可控。

**（三）算法恶意利用**：存在提示词注入攻击（诱导模型忽略安全指令）、越权工具调用（诱导模型执行敏感操作）的风险。影响分析：越权调用可能影响用户设备端文件与数据；已通过工具权限分级（敏感能力默认拒绝）、安装审批、调用审批文案明示三重机制防控，残余风险低。

**（四）其他风险**：对话内容可能含用户个人信息，传输至第三方模型存在泄露风险；已通过最小化传输（不含账号信息）、加密传输、信息库凭据不进模型上下文等措施防控。

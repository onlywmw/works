# MOV Splash · 品牌短动画设计 v1
**出单人**：设计师 ｜ **日期**：2026-09-04 ｜ **状态**：✅ 设计定稿（用户拍板「透明 logo 下面 MOV AI，动画=字母运动，怎么动由设计师设计」）→ 交付设计师落地
**背景**：用户反馈登录后冷启动出现「系统默认 App 图标 splash（带边框）」观感差 → 品牌化定制 → 用户拍板结构：**透明竖眼 logo + 下方 MOV AI 字母，动画效果=字母运动**。

```

               ◤ ◢ ◣          ← ① 竖眼 logo（透明底，标准品牌图 MOV_BRAND_LOGO_V1）
                ◈ ◈ ◈
               ◥ ◣ ◤        （尺寸：~96dp × 104dp，居中偏上 40%）

         ─────────────────
           M   O   V   A   I      ← ② 字标（字母，动画主体）
         ─────────────────
```

| 元素 | 规范 |
|---|---|
| 背景 | `mov_bg`（品牌主色，与全局主题一致） |
| ① Logo | `MOV_BRAND_LOGO_V1_2026-08-26.png`（**透明底**，无边框无底板），高约 96dp |
| ② 字标 | **MOV AI**（一个词位：M O V 空格 A I），字间距 0.22em，字号 ~22sp，字重 600，颜色 `mov_on_bg`（浅色/品牌反白），字族=系统默认（不用第三方字体，降本） |

## 二、动画设计（字母运动 · 三部曲，总时长 ≈1.3s）

### 2.1 级联入场（0→0.55s）——「从眼睛里走出来」
| 字母 | 延迟 | 动作 |
|---|---|---|
| M | 0.00s | y +18dp → 0 · alpha 0→1 · ease-out |
| O | 0.08s | 同上（递延） |
| V | 0.16s | 同上 |
| A | 0.24s | 同上 |
| I | 0.32s | 同上 |

- 每个字母：`translationY 18dp→0` + `alpha 0→1`，`ease-out（cubic ~450ms 单字母）`
- 方向=**自下而上浮入**（从 logo 底部「升起」，形成「竖眼注视→字母显形」的叙事）
- 字母间 80ms staggar（视觉节奏 12.5fps 级差）

### 2.2 一次呼吸 (0.55→1.05s) ——「活着的字标」
- 全部字母到位后，**错相位微浮**：每字母 `y` 正弦 ±1.5dp，相位差 = i×0.45rad（邻居错开，非同步点头）
- 振幅 1.5dp（克制，不打扰）；只做 **1 个周期**（Splash 短，不做持续呼吸）
- 呼吸结束回到 y=0

### 2.3 过渡淡出 (1.05→1.3s) ——「融进主界面」
- 字标+logo 整体 `alpha 1→0.55` + `scale 1→0.98`（轻微后退感）
- 结束后跳转（PrivacyGate/登录/主页按登录态），无硬切

### 兜底（重要）
- **字母级联失败/低端机卡顿**：整体直接 alpha 淡入（0.2s）→ 保证「一定有品牌画面」
- **Reduce Motion 系统设置**：跳过 2.1/2.2（直接静态显示+淡出）

## 三、实现方案（给设计师的落地指引）

| 项 | 建议 |
|---|---|
| 载体 | **自定义 `SplashActivity`**（LAUNCHER）——系统级 Android 12 splash 只支持单图标位，装不下「logo+字标」复合结构；自定义 Activity 接管品牌画面（结构自由） |
| Android 12+ 系统 splash 衔接 | 保留已提交的 `values-v31` 主题定制（品牌底+竖眼）作为**前奏**（系统 splash 瞬时 → 自定义画面无缝接力，同背景色=无闪变） |
| 动画实现 | **原生 ValueAnimator/ViewPropertyAnimator**（不引 Lottie/第三方——零依赖、与换肤 token 兼容）；每字母一个 Text 或整行拆字符控件 |
| 跳转 | 1.3s 后 → 现有决策链（PrivacyGate → Login → Main，按登录态）；`finish()` 自身 |
| 兼容 | minSdk 现状；v31 系统 splash 属性仅在 12+ 生效（低版本直接自定义 Activity 画面） |
| 主题 | 背景用 `@color/mov_bg`（换肤 token 联动，不写死色值——UPG-40 契约） |

## 四、验收判据（供设计师自查/验收员复核）

1. 冷启动（杀进程重开）首屏=**透明竖眼 + MOV AI**，无「系统默认图标带边框」出现
2. 字母级联方向正确（M→I 依次自下浮入），肉眼可见错位逐步（非同时出现）
3. 呼吸只做 1 轮，振幅克制；淡出无闪烁
4. 总时长 1.2-1.5s 内（短动画 ✓）
5. 跳转链正确（未登录→登录页；已登录→主页）；双击/快速二次启动无重叠
6. `mov_bg` 换肤联动（换肤后 splash 背景同步变）
7. 低端机/Reduce Motion 兜底生效

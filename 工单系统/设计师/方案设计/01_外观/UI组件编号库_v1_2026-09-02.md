# UI 组件编号库 v1（Catalog 起点 · 部位-组件编号范式）

> 设计师 @2026-09-02 ｜ **范式（用户拍板）**：`UI-<部位>-<组件>`——看编号即知「哪里的什么」；部位隔离天然支持单部位安全打样。
> **分层定位**：component_id（身份）= 本编号；semantic_type（语义）/ variant（形态）/ impl（实现）= v2.1 四层其余层。

---

## 一、编号范式

```text
UI-<部位>-<组件>
部位（在哪用）：CHAT / SETTINGS / SIDE / WORKBENCH / MARKET / ASSETS / SHEET
组件（是什么）：INPUT / BUBBLE / ROW / HEADER / TOGGLE / CARD / ICON / BUTTON / LIST / EMPTY / SHEET
（统一大写连字符；后续部位/组件新增=追加，不重排）
```

## 三、建库规则

1. **编号唯一**；部位/组件词表统一（大写+连字符）
2. component_id 只管「身份+部位」——形态/实现/语义分列（四层不混）
3. 新增=追加（不重排/不复用）；删除=作废（编号永不复用）
4. 每条必填：component_id / semantic_type / 名称 / provider / 说明（= Presentation 最小集）

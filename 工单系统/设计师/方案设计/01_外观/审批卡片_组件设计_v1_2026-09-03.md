# 审批卡片 · 组件设计 v1（2026-09-03 用户拍板：形态定案，组件化）

> 定位：审批三形态（单工具卡 / only-once 卡 / 预审单卡）共用同一 **CardShell**；容器=居中悬浮卡，极简模式复用同一容器。
> 施工对照 demo：`设计师\设计预览\审批弹窗_重设计_demo_v2_2026-09-03.html`（结构/令牌/交互以此为准，程序员照抄不自由发挥）。
> 归属：总纲 R1（ApprovalSurface）视觉节 + UPG-76 派单 UI 口径；组件目录注册（candidate）按 UPG-70 规范另评。

## 1 壳结构（三形态共用）

```
┌──────────────────────────────┐
│ (环) 标题              [tag] │   环=倒计时(≤10s 变红)，环心=队列 i/N（1/1 留空）
│      副题（工具名·域）        │
│ ┌──────────────────────────┐ │
│ │ 参数卡（key-value 脱敏）  │ │
│ └──────────────────────────┘ │
│ ☐ 记住，同类操作不再问        │   only-once：此行换成 🔒 一行小字，无勾选
│ [拒绝]              [同意]   │   主操作在右
└──────────────────────────────┘
预审单卡：同容器，内容区=步骤清单（序号+人话+副作用 tag+勾选；读取灰显自动；支付行 danger-tint 锁定「到此步单独确认」）
```

- 容器：16px 圆角 / s4 面 / scrim 令牌 / 缩放淡入；点 scrim=取消=fail-closed
- 色：纯黑白 + 唯一功能红（--danger 只用于拒绝/支付/敏感关键词）——守拍板④
- 令牌：全部引用 tokens.css 变量（s0-s4/text1-3/line/danger/primary-tint），禁硬编码色值（现行原生 AlertDialog 的病）

## 2 槽位填充契约（关键：谁填什么）

| 槽位 | 内容 | 填充源 | LLM 可否填 |
|---|---|---|---|
| 标题 | 「AI 想帮你\<动作\>」 | **deterministic**：apprHumanPhrase 人话模板 / 能力声明 `semantics` | ❌ |
| 副题 | 工具名 · 域 | 注册表（PermissionRegistryData） | ❌ |
| 副作用 tag | 写入/敏感/读取/支付 | 注册表 `side_effect`（MONEY 自判支付行） | ❌ |
| 参数卡 | key-value（脱敏：key/secret/token 打码） | **canonical 参数 deterministic 摘要**（apprArgsSummary 类） | ❌ |
| 队列号 i/N | 环心 | ApprovalService 队列 | ❌ |
| 倒计时环 | 30s 消退 | 服务侧 fail-closed | ❌ |
| 豁免勾选/🔒行 | 静态文案 | 组件内置 | ❌ |
| 步骤行（预审单） | 步骤人话+参数摘要 | 从**结构化计划数据**（tool+canonical args）deterministic 渲染 | ❌（LLM 的计划文本不作展示源） |
| **AI 说明（可选槽）** | 「为什么建议这么做」 | **LLM 唯一可填区**——必须标注「AI 说明」，样式弱化（text3/斜体），**不进审批效力链**（执行引擎 §6.5：LLM 只能解释，不能是审批文本来源） | ✅ 仅此槽 |

**红线（G5 可信链）**：审批效力字段（标题/参数/tag/金额/步骤行）禁止 LLM 自由文本填充——用户批的是 deterministic 渲染的 canonical 内容，执行按同一 canonical 五元复验；「所见即所批、所批即所执」。违反=验收红。

## 3 交互与状态

- 倒计时：30s 环形消退（≤10s 变红），到点=自动拒绝（cancelled，fail-closed）+ toast「已自动拒绝」+ 足迹
- 豁免勾选：不勾=ALLOW_ONCE；勾上=remembered（设置页可改）；only-once 工具无勾选（UPG-61 语义：UI 承诺与 handler 行为一致）
- 「本轮豁免」不进单卡——只在批量面板「全部本轮允许」
- 按钮：[拒绝] 左（danger-tint）/ [同意|批准 N 项] 右（primary）；点击反馈 toast，拒绝不降级（只是这次不做）
- 预审单：勾选联动批准计数；MONEY 行不可勾；部分批准→下游阻断（不承诺「撤销」，已执行标「已执行」）

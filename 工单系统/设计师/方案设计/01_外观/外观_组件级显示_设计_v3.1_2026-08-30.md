## 一、覆盖清除语义 = A（P0-1 定死）
```
开启全局极简 → componentOverride 全部清空(componentAppearance=null) + 写入极简形态
关闭全局极简 → 用经典默认(componentOverride 已清空,回默认)
```
- **真删除**("清除逐项覆盖"= `componentAppearance=null`),不是"禁用但保留";
- 未来用户想自定义 → 重新在外观页设;干脆派到 底,状态机简单。

---

## 二、形态 ID 规范（P0-2 · 统一命名）
```
input.classic   → 类 appearance-input-classic
input.capsule   → appearance-input-capsule
input.underline → appearance-input-underline
button.classic  → appearance-button-classic
button.minimal  → appearance-button-minimal
```
- **形态 ID 定死后,UI/状态/持久化/Debug/埋点全统一**;
- 收敛**一张配置表**(APPEARANCE_MAP),不散落各组件:
```js
const APPEARANCE_MAP = {
  input:  { classic:'appearance-input-classic', capsule:'appearance-input-capsule', underline:'appearance-input-underline' },
  button: { classic:'appearance-button-classic', minimal:'appearance-button-minimal' }
}
```

---

## 三、用户配置数据结构（P0-3 · 存储契约）
```js
appearance = {
  globalMinimal: false,
  components: { input:'capsule', button:'classic' }
}
```
- `globalMinimal=true` → **忽略 components**(全局极简);
- `globalMinimal=false` → **读 components**(逐组件);
- `DisplayAppearanceResolver`(逻辑层)按此**算出最终形态类** → DOM;CSS 只认最终类(无 !important/权重战争):
```
appearance → Resolver → 最终形态 → CSS class → DOM
```

## 四、状态矩阵验收（大神补,不只默认态）

| 形态 | Default | Hover | Pressed | Focus | Error | Disabled |

| classic | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| capsule | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

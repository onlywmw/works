# UPG-55 我的资产 · 验收方案 v1（2026-09-01）

> 设计师 @2026-09-01 ｜ 依据：设计 v3 收敛版（唯一施工口径）+ 设计 v1 §九验收测点（框架级，本方案编号化并补齐 v3 新增判据）+ 合并版下篇形态（对照 A/B/C/D 系列判据结构）。**验收对象 = 67-A 框架批**（AssetKind Registry+资产首页+credential 迁入+迁移）；67-B/C 批验收随批补。
> 变异锚编号规则：M55-x；真机判据编号：R55-x。

---

## 一、L1 机器验收（JVM/契约，对照设计 v1 §九编号化）

| 编号 | 判据 | 验收方式 | 通过标准 |
|---|---|---|---|
| J-1 | 注册制不破坏既有 | 注册测试用新 AssetKind（如 test_kind）→ 断言已存在三类的列表/存储/行为零变化 | 变异：改通用模型影响他类 → 红 |
| J-2 | 每类规则独立 | 三类各自 schema 行为测试（凭据加密/照片元数据/衣柜字段） | 各类规则互不影响 |
| J-3 | 迁移**三等式**（v3 收敛新增） | 构造旧 vault 数据（含凭据/证件照/普通条目混合）→ 跑迁移器 → Migration Manifest 对账 | COUNT/ID_SET/密文 HASH 三等式全过；变异：迁移器丢 1 条 → Manifest 红 |
| J-4 | 迁移幂等+中断续跑 | 同一存储连跑迁移两次；中途 kill 重跑 | 结果一致（幂等）；续跑补完（不重复不丢失） |
| J-5 | MCP 写门控 | wardrobe 可写走 Gatekeeper；credential 拒写（AI/MCP 双路径） | credential 写=拒绝+审计；wardrobe 写=放行 |
| J-6 | 凭据明文不出 | 全路径扫描：明文只出现在审批放行后的返回体 | journal/日志/trace 零明文（grep 断言） |
| J-7 | 注册即用 | 注册新 kind → 资产首页卡片出现 | 无需改其他类代码 |
| J-8 | egress guard（v3 新增） | 构造资产数据外发路径（网络调用携带资产内容） | guard 拦截+审计（全部类目统一过） |
| J-9 | 兼容期老入口只读（v3 新增） | 老「我的信息」入口进入后尝试写入 | 只读快照+写操作引导至新入口（写=被拒+提示） |

## 二、变异锚（对照合并版下篇形态，≥5 条）

| 编号 | 变异 | 预期红 |
|---|---|---|
| M55-1 | 迁移器丢条目（跳过 1 条不迁） | J-3 三等式红 |
| M55-2 | 迁移器重复迁（同条迁两次） | J-4 幂等红 |
| M55-3 | Registry 治理失效（跳过 SecurityGate 校验允许注册） | 治理断言红（securityPolicy 未校验即注册） |
| M55-4 | egress guard 移除 | J-8 红（数据外发成功=泄漏） |
| M55-5 | 兼容期老入口可写 | J-9 红（只读快照被写入） |

## 三、L2 真机验收（平板 21770d7d / 模拟器 5554）

| 编号 | 判据 | 操作 | 预期 |
|---|---|---|---|
| R55-1 | 资产首页 | 侧边栏 →「我的资产」 | 类目卡片实时渲染（凭据/照片/衣柜+灰显未上线）；凭据卡固定首位 |
| R55-2 | 凭据类目页 | 进凭据类目 | 旧数据全在（迁移后）；按平台分组 toggle 生效；明文查看走 only-once 弹窗 |
| R55-3 | 迁移无感 | 升级包覆盖安装（老 vault 数据在） | 首启自动迁移、无感；全部数据在新入口可查（**用户数据零丢失真机实证**） |
| R55-4 | 证件照子页签 | 凭据页 → 证件照页签 | 子页签在+「同等安全等级」小字在；照片查看/重拍 |
| R55-5 | 到期提醒 | 构造含 expiresAt 临期条目 | 资产首页凭据卡标 ⏰（首页加载实时计算） |
| R55-6 | 老入口只读 | 兼容期老「我的信息」入口尝试写入 | 只读+引导提示 |
| R55-7 | 多轮对话回归（UPG-62） | 连续对话 3~5 轮 | 焦点保持不回退（62 修复不因本单回退） |

## 四、里程碑判据（用户感知）

| 判据 | 说明 |
|---|---|
| 「我的信息」里所有数据在「我的资产·凭据」里都能找到且能用 | R55-2/R55-3 达成即证 |
| AI 换装产出的衣物出现在衣柜类目 | 67-B 批验收（本批不含） |

## 五、验收流程

1. 程序员交付（67-A：Registry+首页+凭据迁入+迁移）→ 登记 → 验收员按 §一~§三 查账
2. 变异锚 M55-1~5 由验收员亲杀（对照合并版下篇惯例）
3. L2 真机（R55-1~7）平板+模拟器双端
4. 结论落 ACCEPTANCE_LOG + 证据落 `验收员\证据数据\`

## 六、67-B/C 批验收预告（随批补细则）

- 67-B：衣柜 MCP 接入（mcpWritable/Gatekeeper/入库校验三件）+ 换装产物入衣柜类目 + Asset Access Gateway 首版（如四轮评审 §十 范围恢复）——随 67-B 派单补
- 67-C：照片增强+分组/证件照/到期提醒细节（本批已含基础）——随批补

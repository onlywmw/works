## 一、点击行为 = 分派表（v3 定案,非"与内置一致"）

| pin 类型 | 点击 | 说明 |
|---|---|---|
| BUILTIN · page 类 | 打开页面 | 订单/信息/记忆 → 跳页 |
| MCP_TOOL · 有预设 | **回填预设** | 低风险/二次确认 |
| MCP_TOOL · 无预设 | **轻量输入面板** | 该工具参数输入,不直接执行 |

**预设来源(v3 补)**:内置预设=我方写;第三方 MCP 预设 = ①钉选时**用户可选填一句预设**(存 pin)或 ②从工具 `inputSchema` 生成默认模板;没填 → 无预设 → 点击进输入面板。这也给"长按直达"明确执行对象。

---

## 二、长按 = 上下文菜单（v3 定案,解决手势冲突+副作用）

- **长按胶囊** → 上下文菜单:`直达执行 / 详情 / 取消钉选`;
- **「直达执行」资格** = `有预设 ∧ MCP annotations readOnlyHint=true` 或 **无必填参数**(MCP 协议自带 readOnlyHint,正好用;无参直达才安全);
- **手势冲突安全阀**:钉选区横滑,长按与之共存 —— 快滚时**不触发**长按(移动端长按需长时按下,滚动优先),且直达是副作用动作,仅资格满足才可直达(与"回填为默认"的安全理由对称)。

---

## 三、工具第三态（v3 补,服务端下线/改名,常态）

| 状态 | dock | 点击 | pin |
|---|---|---|---|
| 正常 | 正常 | 按分派表 | — |
| 停用(本地) | 变淡 | toast 引导启用 | 保留(占名额) |
| 卸载(本地) | 移除 | — | 清理(**释放名额**) |
| **服务端下线** | 变淡+"不可用" | toast「该工具已下线」 | 标记 + **清理释额**(定死,防占名额) |

**pin 只存 `stableId`(v3 关键)**:`MCP_TOOL(id,name,tool)` 冗余 name → **只存 stableId**;name/icon/描述**渲染时从工具注册表实读**——服务端改名 → 胶囊自动正确;不带旧名残影。

## 四、管理弹层 = 三区交互（v3 定案,解决跨组排序）

```

【当前钉选 · 唯一排序面(跨类型混排)】
 ⠿ 订单   ⠿ 🚄12306   ⠿ Obsidian
```

- **上限可见**(当前几个 / 5);dock 预览=只读镜像。

## 六、验收测点（v3 增补,替换"300 条"）

- **L1**：①点击分派表逐格断言 ②聚合显隐三态(零工具/全钉/混合)③第 6 钉选禁用+toast ④**服务端下线/改名**后胶囊与 pin 行为(pin 无 name 冗余)⑤预设变更后回填用最新版 ⑥长按菜单 + **readOnlyHint 门控** ⑦跨组排序持久化 ⑧迁移幂等 ⑨pin 无冗余 name/icon(数据断言)。

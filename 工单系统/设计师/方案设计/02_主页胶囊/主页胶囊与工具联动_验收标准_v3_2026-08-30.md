> 设计师 @2026-08-30 ｜ 依据：主页胶囊系统 v3 + 输入↔工具联动机制 v3(冻结,9.3/10) ｜ 验收对象 = **能力快捷 + Tool Orchestration Runtime**。

## 〇、验收总原则（大神定,一句话）

> **AI 是否在正确的时候、调用正确的工具、以正确参数、在正确的安全等级下执行。**

验收**层级**:L1 代码/契约(六指标评测集) / L2 真机交互 / L3 安全·可观测。**每级配实物证据**(评测集结果/测试 XML/日志 Trace/截图),不信自报信实物。

## 一、L1 代码 · 契约 + 度量（六指标评测集）

### 1. 评测集（核心验收形态,非 UI 断言）
- 建评测集:典型输入 → 期望决策(含模糊输入/多工具候选/不该触发边界);
- 用例含 `NO_CALL`(讲铁路历史 → 不调工具)、`MULTI_CALL`(查票+备忘)、`CALL`;
- **desc 改动前后回归**——六指标不降。

### 2. 六指标（每条对应断言）
| 指标 | 含义 |
|---|---|
| Tool Selection Accuracy | 工具选没选对 |
| Argument Accuracy | 参数填没填对 |
| No-Call Precision | 该不调用时有没有乱调 |
| No-Call Recall | 该调用时有没有漏调 |
| Multi-Tool Accuracy | 多工具组合(Parallel/Sequential/Conditional)对不对 |
| Safety Gate Accuracy | 该拦(确认门)时有没有拦 |

### 3. 决策契约
- `Tool Decision = NO_CALL / CALL / MULTI_CALL`;**NO_CALL = 合法决策**(非"没找到工具")。

### 4. Argument Validation
- 缺参 / 歧义 / 非法 / 超权限 四类 → **阻断**(断言阻断,不执行);变异:漏阻断 → 必红。

### 5. Safety Policy（风险分级）
- `Tool Risk L0/L1/L2/L3` → Execution Policy → 是否确认;**L2/L3 必进确认门**;自有策略兜底(不依赖第三方 annotation 填标准)。

### 6. Trace 可观测
- 每次调用落 Trace:`traceId/conversationId/turnId/input/candidateTools/selectedDecision/selectedTool/arguments/validationResult/riskLevel/confirmationResult/executionResult/memoryCandidate/decisionReason`;
- **decisionReason 结构化**(非 CoT);断言字段齐 + 可回放"为什么调了这个工具"。

### 7. 数据契约（pin）
- `workbench_pins` **单写点**;**pin 只存 `stableId`,无冗余 name/icon**(渲染从注册表读,服务端改名自动);卸载/下线清理 + **名额释放**;迁移幂等(pin_type=BUILTIN)。

## 三、L3 安全 · 可观测
1. **副作用确认门**:L2/L3 工具执行前确认(readOnlyHint/destructiveHint + 自有风险分类器);
2. **Argument Validation 阻断**四类(缺/歧/非法/超权限);
3. **记忆回流**:工具结果=记忆候选(非记忆本身),经 Policy→Draft→确认→Store(防"订票≠偏好上海"污染);
4. **Trace 可追溯** + 自动 Bug 定位;
5. **三层互不污染**:胶囊(pin)/记忆/工具 desc 数据约束(断言,非口号);
6. **并发生命周期**:面板打开期间工具停用/卸载 → 观察者响应式更新。

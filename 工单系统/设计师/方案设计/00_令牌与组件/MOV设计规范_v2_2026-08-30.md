### 1.3 暗色推导规则（别只抄浅色变深）

暗色不是"浅色变深"，是**层级反转 + 明度翻转**。换肤/新主题必须按这套规则推导，禁止逐个手工赋值：

| 维度 | 浅色 | 暗色 | 规则 |
|---|---|---|---|
| Surface 层级 | s0 最浅(页面底) → s3 最深(分隔带) | **s0 最深(页面底) → s3 最浅(分隔带)** | 层级反转：越底层表面越深，卡片/浮层逐级变浅，"抬起来"用变浅表达 |
| 文本 | 主文本 `#191B21` 最深 | 主文本 `#F0F2F5` 最浅 | 明度翻转：暗色下文字亮度反转，text > text2 > text3 层级不变（由亮到暗） |
| 线/遮罩 | 黑系 alpha | **白系 alpha**（`rgba(255,255,255,.08)`） | 暗色下分隔线/描边改白半透明 |
| 主色（primary） | `#0E7C5B`（深绿） | `#34C79A`（亮绿） | 品牌色向亮侧翻转一档，保 4.5:1 对比 |
| 语义色（danger/ok/warn） | 深/中调 | **向亮侧提亮一档**（danger `#F97066`/ok `#47D39C`/warn `#F79009`） | 暗底上深色不可辨，必须提亮 |
| on-primary | 白字 | **深字**（`#0B0F14`） | 主色变亮后，其上的字改深才保对比 |
| shadow | `rgba(0,0,0,.08~.18)` | 淡化或去（暗色下阴影不可见） | 暗色下靠层级反转表"抬升"，不靠阴影 |

> **验收**：①暗色下 s0-s3 层级肉眼可分（卡片明显"抬"起）②主文本满足 4.5:1 ③danger/ok/warn 三色在暗底可区分（呼应 a11y 状态冗余编码）④on-primary 在 primary 上对比达标。违反任一条 = 不是合格暗色。

## 五、组件规格（定形态，逐项是验收点）

1. **按钮**：主按钮=primary 底+on-primary 字+圆角 12+高 44；次按钮=s1 底+line 边+text 字；文字按钮=primary-text 无框；危险按钮=danger（**退出登录用 danger 文字钮，不放页面底部孤立位**——进账号卡）。
2. **chip**（聊天页 chips 排）：高 30、全圆角、s1 底+line 边、12px 字；**文案不带 ▾ 三角**（用户拍板去除，UPG-25 ①；可点性由气泡交互承担，不靠指示符）；钉选小按钮=34×34 圆角 10（UPG-23 规格）。
   - **命名规则（v1 补，2026-08-30）**：chip 一律用**短显示名**——①模型 chip 显示短名（`DeepSeek`），完整名 `DeepSeek V4 Flash（快速对话）` 作悬浮/长按详情；②工具/功能 chip 短名 ≤4 字，超限按 §排版规则截断；③禁止完整长名占满 chip（防 `DeepSeek V4 Flash（快速对话）` 这类超长名）。
   - **排版规则（v1 补，2026-08-30）**：chip **宽度自适应内容**（不再固定 118dp，去掉硬截断）；长度超 `--chip-max-w`（容器 40%）→ 统一 `…` 收尾 + 悬浮显示完整名；**禁裸 CSS ellipsis 硬截到单字符**（防 `我的能力`→`我`、`DeepSeek V4 Flash…`→`DeepSeek V...` 残缺）；中文截断保证**语义前缀保留**（`我的能…` 而非孤字 `我`）。
   - **胶囊展开规范（v1 补，2026-08-30）**：
     - **形态**：点击胶囊 → **气泡浮层**（锚定胶囊，胶囊上方展开）——圆角 14、白/浅底、描边、阴影（对齐 §五.4 气泡弹层）；宽度锚内容、不超容器；
     - **层级**：一级气泡（列表行）→ 可选二级下钻（标题「‹」返回）；**最多两级**（不无限下钻）；
     - **行元素**：左=名称（+免 key 标 / 状态点）+ 可选副文字；右=chevron / 开关 / radio；**状态点三态**（同 §五.6 四色：绿正常=ok / 红不可达=danger / 灰停用=neutral）；
     - **交互**：点外部关闭；返回箭头；点项=执行（切换/打开/回填）；**空态=引导文案**（「去 XX」「暂无…」）；
     - **气泡字数规定（v1 补，2026-08-30）**——主行/副行各限字数，防 `DeepSeek V4 Flash Vision(多…` / `deepseek-v4-flash-vision-exp` 这类超长失控：
       - **主行（二级·名称）**：≤16 字（短显示名）；超长 → `…` 省略（保留语义前缀）+ 完整名放 profile/detail；模型主行 = 模型短名（`DeepSeek V4`），**模式后缀 `(快速对话)` 不入主行**（作右侧小标签/免 key）；
       - **副行（三级·详情）**：两段 ≤ 一行（如 `provider · 模型简称`）；**技术 id/model id 超长**（`deepseek-v4-flash-vision-exp`）→ **中段省略**（`deepseek-v4-flash-…`）或显示「厂商 · 版本」（`deepseek · V4 Flash`）；`当前`/`免key`/`✓` = **右尾缀小标签**（不占主副行字）；
       - **行数**：主行 1 行、副行 1 行（ellipsis）；**禁**技术 id 全量平铺副行、禁超行数。
     - **展开分类**：
       · 模型 chip / 「MCP 工具」/ MCP 独立胶囊 → **展开气泡**（层级/下钻按内容）;
       · 内置钉选（page 类：订单/信息/记忆）→ **跳页**（不展开）;
       · MCP 独立胶囊点击默认 → **预设指令回填**（低风险/二次确认）;
       · 「＋」管理 → 底部 sheet（另行规范，非胶囊展开）;
     - **禁**：胶囊展开不用全屏 popup/新建页；不无限下钻；跳页仅限 page 类钉选。
3. **卡片/分组**：van-cell-group inset，圆角 14，s1 底，line 分隔。
4. **弹层/sheet**：底部 sheet 顶圆角 16、底色 s0；气泡弹层圆角 14、阴影 0 8 28 rgba(0,0,0,.12)。
5. **开关**：van-switch 默认尺寸，on=primary。
6. **状态点**：7px 圆，ok绿/warn橙/danger红/灰=s3；全 App 同一套。
7. **tab**：下划线式（当前=2.5px primary 短杠），文字 13px。
8. **toast**：深色半透明底 `rgba(26,26,26,.88)`、圆角 8、11px 白字、底部居中。
9. **空态**：text3 文案 + primary 文字按钮引导（「暂无项目，去市场看看」范式）。
10. **时间戳**：10px、text3、等宽数字、**固定宽不换行**。

## 六、五态（loading / empty / error / disabled / submitting）

> 底线：**数据驱动的界面必须显式处理五态**，不许"空白即加载"或"默默失败"。empty/disabled 已有雏形（§五.9 / 01 外观 §四），本节主要补 loading/error/submitting 及其变体。

### 6.1 loading（加载态）
- **骨架屏**（首选，替代转圈）：形状/圆角=对应组件圆角阶梯（卡片 14 / 条目 8）；微光 `shimmer` 1.2s 循环；骨架块=s2 底。
  - 列表首屏 / 记忆页冷启动（300 条 <2s 目标）→ **骨架屏**（非 spinner）；
- **进度**：
  - 线性：顶部 3px primary；**不确定进度**（模型首载 30-60s、无明确总量）→ 线性不定 + 文案「正在加载…首次较慢」；
  - 环形：图标钮/按钮内 16px 环形。
- **按钮 submitting**：见 6.5。

### 6.2 empty（空态）
- §五.9 通用范式（text3 文案 + primary 文字按钮引导）；补变体：
  - 无数据空态：图标(24px + text3) + 一句主文案 + 一个动作按钮；
  - 收窄空态：仅一句说明（如「暂无工具」），无按钮。

### 6.3 error（错误态 · 三层）
| 层级 | 场景 | 形态 | 重试 |
|---|---|---|---|
| 行内校验 | 表单字段非法 | 字段下方 12px danger 文案 + 错误描边 | 改对即消 |
| 区块错误 | 某模块加载失败 | 卡片内：图标 + 一句可读原因 + [重试] 按钮 | 重试按钮 |
| 整页错误 | 断网/核心连不上 | 居中：大图标 + 一句原因 + [重试] | 重试 + 返回 |
- **文案范式**：不报技术黑话（`ERR/404/SocketTimeout`），说「网络开小差了 / 服务连不上，稍后再试」；必须给**重试或返回**，不许白屏。

### 6.4 disabled（禁用态）
- 通用：降低不透明度(0.4) + 不可点 + not-allowed 光标；**禁**只靠变灰（需连带语义，见 §七.3）。
- 输入框/按钮禁用可见于 01 外观 §四 与 §五.1。

### 6.5 submitting（提交中）
- 按钮文案保留 + 前置 16px loading 环形；**disabled**（禁重复点）+ 防抖；
- 例：设为重要(memoryPromote)、保存模型、审批同意 → 全程 submitting，**以底层返回为准**（Memory 契约：不乐观写死）。

## 七、无障碍（a11y）

> 原则：**不靠单一通道传信息**——颜色必须配形状/图标/文字；交互必须可用键盘/无障碍服务完成。

### 7.1 文本对比度（token 级合规）
- 正文/常规文本 ≥ **4.5:1**；大字(≥18sp/14pt bold)与图形/图标 ≥ **3:1**；
- 主文本(text) 浅色对 s0/s1 达标、暗色对 s1 达标；text3 仅作辅助/占位，**禁**承载核心正文。

### 7.2 触控目标 ≥ 44×44dp
- 图标钮/开关/chevron/钉选(34×34 现状)/badge 均**不足** → 用**不可见热区**扩到 44×44（视觉 34，点击区 44）；
- 相邻可点目标间距 ≥ 8dp；达标按钮 44 高（§五.1）视为合格。

### 7.3 状态冗余编码（颜色 + 形状/图标）
- **禁单靠颜色区分**（红绿色盲不可辨）：
  - 状态点（§五.6）：彩色圆点 **必配形状/图标**——ok=实心圆+勾、warn=实心圆+叹号、danger=实心圆+叉、停用=空心圆；或点旁加文字；
  - 危险操作（§五.1）：红色之外**必配图标/文案**（「删除」「退出」字样），不许只剩红色文字；
  - 表单校验（§六.3 行内）：danger 红 + 错误图标 + 文案（三信道）。

### 7.4 动态字号 / 系统缩放
- 随系统字体缩放：chip 截断、固定宽时间戳（§五.10）是**风险点**——
  - chip 用 max-width + `…` + 悬浮，不硬截单字符（§五.2 已有）；
  - 时间戳/行高固定宽在放大 1.3x 时**改尾随省略** + 允许行高自适应；
- 布局**纵向可扩展**（不依赖固定高度裁切）。

### 7.5 contentDescription
- 所有图标钮/纯图形要素**必带可读 label**（string / contentDescription）；
- 装饰性图标可空；语义图标（审批 9 类 / 状态 4 态）**必标**。

## 八、Motion（动效 · tokens）

> 现有文档点名需要动画但无参数：胶囊过渡、气泡展开、sheet 升起、toast、Snackbar 撤销、审批 30s 倒计时。本节定参数。

### 8.1 duration
| Token | 值 | 适用 |
|---|---|---|
| `--dur-fast` | 120ms | 微交互：按下反馈、状态点切换、toast 进出 |
| `--dur-base` | 200ms | 常规：气泡展开/收起、sheet 升起、chip 显隐 |
| `--dur-slow` | 320ms | 大位移：dock 胶囊增删引起的重排、整页切换 |

### 8.2 easing
| Token | 曲线 | 适用 |
|---|---|---|
| `--ease-standard` | `cubic-bezier(0.2,0,0.2,1)` | 默认（位移/缩放） |
| `--ease-decelerate` | `cubic-bezier(0.3,0,0,1)` | 进场（减速停止） |
| `--ease-accelerate` | `cubic-bezier(0.7,0,1,0.5)` | 离场（快速退出） |

### 8.3 减弱动效（prefers-reduced-motion）
- 系统开启减弱动效 → 所有 `--dur-*` 降为 **0ms**；微交互保留（反馈仍可见），位移/缩放/循环动画**禁运行**；
- shimmer（§六.1）在减弱动效下**改静态占位块**（不闪烁）。

## 九、层级栈（z-index / elevation）

> 八类浮层必须有层叠顺序，以免联调第一周互踩：弹层、sheet、胶囊气泡、审批弹窗、toast、Snackbar、长按菜单、scrim。

### 9.1 --z-* 阶梯
| Token | 值 | 层 |
|---|---|---|
| `--z-base` | 0 | 页面/列表内容 |
| `--z-scrim` | 100 | 遮罩(scrim) |
| `--z-sheet` | 200 | 底部 sheet |
| `--z-popover` | 300 | 胶囊气泡/长按菜单/下拉 |
| `--z-drawer` | 400 | 审批弹窗/对话框 |
| `--z-toast` | 500 | toast / snackbar（浮层最顶层） |

### 9.2 浮层互斥规则
- 同刻最多 **2 层**（1 个 scrim + 1 个内容浮层）；**新浮层关旧浮层**（如审批弹窗打开时其下 sheet 关闭）；
- toast/snackbar 可盖在 sheet/弹窗上（最高优先），但**不盖对话框**——对话框打开时 toast 队列化，关闭后逐条出。

### 9.3 elevation（阴影分级）
| 级 | 阴影 | 用途 |
|---|---|---|
| e1 | `0 1 2 rgba(0,0,0,.08)` | 列表行抬升、按下态 |
| e2 | `0 4 12 rgba(0,0,0,.12)` | 气泡、下拉、卡片悬浮 |
| e3 | `0 8 28 rgba(0,0,0,.12)` | 弹层、sheet、对话框（§五.4 已用此值） |
- 暗色下（§一.3）阴影**淡化**，靠层级反转表抬升。

## 十、安全区（inset · 刘海/手势条）

> 移动端必需，全库此前零提及。贴底组件直接受底部手势条影响。

### 10.1 inset 规则
| 元素 | 顶部(status bar) | 底部(gesture bar) | 横屏(左右 cutout) |
|---|---|---|---|
| 顶栏 | 状态栏高(46px 不占用) | — | 左右 inset + 顶栏 46px 保留 |
| 页面主区 | 状态栏以下 | 安全区以上 | 左右 inset |
| 底部 sheet / dock / snackbar | — | **底边距 = safe-bottom**（手势条高） | 左右 inset |

### 10.2 具体处理
- **底部 sheet**：顶圆角 16 不变，底部贴 safe-bottom（内容不被手势条压）；
- **dock（主页胶囊）**：胶囊行底边距 = safe-bottom，避免与手势条重叠；
- **snackbar（记忆撤销）**：底部居中，距底 safe-bottom；
- **横屏/折叠屏**：顶栏 46px 保留；左右内容避开 cutout；底部 sheet 高度受限时**转居中对话框**（不进死区）。

### 10.3 实现
- 原生：`WindowInsets` 读 safe-insets；web：CSS `env(safe-area-inset-*)`；
- 禁硬编码固定值，统一走 inset token（`--inset-safe-bottom` 等）。

## 十一、反馈组件决策树（Toast/Snackbar/Banner/Dialog）

> 现状有两种（toast §五.8、Snackbar 撤销），无择选规则，也无对话框规格。本节定「何时用哪个」+ Dialog 通用规格。

### 11.1 决策树
| 需求 | 用哪个 | 依据 |
|---|---|---|
| 瞬时结果、无需用户操作 | **Toast**（§五.8） | 轻提示、自动消失 |
| 可撤销/副作用（删除/移除） | **Snackbar**（带动作，5s 撤销） | 给反悔机会 |
| 需持续上下文提示（警告/确认） | **内联 Banner**（页面内） | 不浮层、常驻上下文 |
| 要用户做阻断决策、否则不能继续 | **Dialog**（§11.2） | 阻断式 |

### 11.2 Dialog 通用规格
- **结构**：标题(15px 600) + 正文(13px text2) + 动作区；
- **动作**：主动作(primary) + 次动作(次按钮) + 可选第三(危险/取消)；**主次缺一不可**（无主动作不用 Dialog）；
- **危险动作**：主动作=danger 底；配图标（§七.3）；需二次确认 → 勾选/输入确认；
- **不可点外部关闭**：审批授权、删除确认、支付、中断性操作（强迫显式决策）；
- **可点外部关闭**：信息型、可取消型（取消=中止）；
- 阻断决策，浮层优先级见 §九（`--z-drawer` 400）。

> 映射示例：模型「删除确认」、主页胶囊「取消钉选」、审批同意/拒绝 → **Dialog**（阻断式）；记忆移除 → **Snackbar**（可撤销）；设为重要成功 → **Toast**（瞬时）。

## 九、排版可调层（v2.1 新增 · 全局排版偏好）

**定位**：字号/字族/字重=全局排版 Token（不属于单个组件——与组件库形态[形状/线条/密度]正交）。

### 9.1 字号三档（语义档位偏移——不是像素值）

```text
档位：小（-1 档） / 标准（0 档） / 大（+1 档）
映射：每档=字阶（§二）整体 ±1 档（例：正文 M=14px→小 13 / 标准 14 / 大 16）
用户偏好=设置-外观「字号」三选（无障碍+个人偏好）
```

### 9.2 字族/字重

```text
字族：default（系统默认）/ brand（品牌黑体——可选）/ mono（等宽——工具名/版本号场景）
字重：regular（常规）/ medium（中粗——标题/强调）
```

### 9.3 Token 契约（消费侧只用语义名）

```text
--text-scale: small|normal|large      （字号档位）
--font-family: default|brand|mono     （字族）
--font-weight: regular|medium          （字重）
（具体 px 值=皮肤值段——UPG-40「皮肤=纯值段」同一套哲学：契约名固定、值可换）
```

### 9.4 实施边界

- **本层=Token 标准先行**（v2.1 契约）；设置-外观三档偏好 UI=**并行小单/UPG-50 阶段附项**（先标准后用——不阻塞组件库打样）
- 与组件形态正交：「UI-CHAT-INPUT（经典形态 × 大字号）」自由组合
- 禁止写死（§硬规延续）；三档只是档位选择，默认=标准

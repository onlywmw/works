**设计师** @2026-09-02 ｜ **依据**：`UI_Component_Registration_Contract_v2.1_2026-09-02.md`（大神 #47/#48 突破方向，9.7/10） + `UI_Component_Runtime_契约_v5.0` + STD `STD-UPG50_阶段2_增补_2026-09-02.md`（L2-11/12 + M-U50-10/11 冻结）

## 范围（P0 核心）

1. **UI Component Catalog**（合法清单）——20 条编号组件入目录（含 id/contract_version/provider_id；`UI-000001~000xxx`=公共/`UI-010001+`=第三方）
2. **UI Component Registry**（本机状态）——install/enable/version/implementation 四态；Resolver/Runtime 读注册态（未注册=不渲染/或标准降级——fail-closed 语义）
3. **上架绑定**——MCP 市场工具 install 时绑定 catalog ID（不可匿名创建 UI——**不可绕过注册制注册**）
4. **Contract Validation + Capability Check**——注册路径必须过（CI 门禁断言）
5. **ID 规则**——component_id 永不复用（删除即作废）；版本升级同 ID

## 判据（= STD 阶段 2 增补）
- **L2-11**：20 条 catalog 条目齐全（id/contract_version/provider_id——机器校验）
- **L2-12**：Registry 四态反映真实（install/enable 操作→状态变化→Resolver 读一致；未注册组件→不渲染）
- **M-U50-10**：绕行注册（不入 catalog 直接 install）→ 红（变异亲杀）
- **M-U50-11**：ID 复用（删除后重分配）→ 红
- 红线延引：Token 契约/单实例/UI 直调豁免/阶段 1 零回归（全量测试绿）

- 上架绑定=只读引用（catalog 是权威——MCP 不放行未经 catalog 的组件）
- 交付=分支 `feat/upg50-ph2` + 报告 + 变异亲杀（M-U50-10/11 ≥2）+ 登记

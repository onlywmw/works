## 一、一句话

把极简呈现从散装代码提升为引擎+契约：PresentationRegistry（呈现契约）+ core.js（呈现栈/动效/浅栈/Recall/Intent Router/Response Splitter 机制件）——LLM 零渲染决策，业务代码零即兴呈现。

## 二、范围

1. **PresentationRegistry**：九字段契约（content_type/presentation_intent/shell/skeleton/slots/components/voice_hint/owner/state）+ **style_tokens 壳级白名单 + style_vocabulary_version="1.2"**（v1.2 §二）+ 登记纪律（candidate 可用/≥2 独立消费者转 registered/未登记 fail-closed 纯文本回落）。
2. **core.js 引擎**（纯 HTML5/JS，无框架无新依赖）：Surface 四类抽象（Base/Content/Decision/Recall）+ Transient/Persistent 区分 + 呈现栈 z 序（决策永远置顶）+ docked 转场 + **动效=Motion Intent 五词（enter/exit/expand/docked/micro，组件层禁直接引 duration/easing 字面量——v1.2 §三.2）** + 浅栈与 Recall 小圆片（读 PresentationPolicy 分档，禁硬编码）+ **卡面 token 值（圆角 22/20、无描边、--card-shadow-lg、scrim 含 blur——v1.2 §一，照 demo v4）**。
3. **Intent Router**：Blocking Decision pending 时新输入四路仲裁（Cancel/Modify/NewTask/Defer）+ 全足迹——输入框随手可及，执行由 Runtime 裁决。
4. **Response Splitter**：LLM 主回复唯一解析点——结构化块→schema 校验→Validated PresentationData→引擎；散文→对话消息；**UI 禁止直接依赖主回复**。
5. **内容双通道**：工具 out schema 直映优先 + LLM 提取（双段输出零额外轮次）过校验。
6. **三骨架**：offerCard / timelineList / plain（对应 demo v3 三形态；纯文本回落含诚实小字）。
7. **测试**：Registry 治理/z 序置顶/Splitter 隔离/Router 四路/policy 分档/动效参数锚 + 5 变异锚亲杀（STD）。

## 三、红线（违反=打回）

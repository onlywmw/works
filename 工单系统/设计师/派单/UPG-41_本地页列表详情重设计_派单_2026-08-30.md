## 需求(照 §三 定稿施工)

### A. 一级「本地」列表(简约 + 分类管理)
- 分组标题(内置能力 / 市场已安装 / 系统基础能力)左靠(margin-left 12px)、灰色、小号；
- 工具行右缩(padding-left 20px)：**仅 名称 + 一句副题(12.5px 灰) + 右侧箭头 `›`**；
- **无图标 / 无 badge / 无「N 项」计数 / 无健康点 / 无任何行内按钮开关**；健康提示移二级；
- 分组标题与工具行错位成两级层次，均不贴左边框。

### B. 内置工具详情(用法/用途前置)
- 顺序固定：头卡(名称+tagline+健康+**右上角启停开关**) → **「这能干嘛」**(一句人话) → **「怎么用」**(例子：`💬"你一句" → 它回什么` + `[用它]` 回填输入框) → 工具一览(名/作用/权限 自由·询问·拦截) → 权限分布 → SAF 授权 / (市场包)卸载；
- 「用途/用法」必须在「工具清单/权限」**之前**(DOM 顺序，验收断言)。

### C. 市场包独立模板(商店式，与内置区分)
- 顺序：头卡(包名 + v版本·作者 + 「已安装」) → **装后普通/极简主页示意(segment 切换，核心)** → 怎么用(1-2 例子) → **信任区**(作者/来源/权限请求，**详情底部致密折叠、默认收起、低调灰字、不扎眼**) → 安装/更新/卸载；
- 无启停开关(市场包是「装不装」问题)。

1. **纯视图重建**：不动数据面/安装/启停/权限逻辑(LocalOverview / market.* 读面零改动)、零新增数据写路径；

## 一、一句话

官网 mov-ai.cn 走「手机=个人服务器」：用户**官网出码 → 手机 MOV App 扫码 → 配对建立** → 官网展示手机本地只读内容（记忆/资产/衣柜/会话摘要），**服务器零存储**。

## 二、范围（本单=阶段 1）

1. **二维码配对**：官网出码（sessionRef 一次性引用）→ App 扫码 → 手机确认 → 会话建立（sessionId+会话 token 手机生成）
2. **用户面代理端**（App 内新组件，**非 8389**）：配对期间绑 `0.0.0.0:8841`；**会话 token 鉴权**（无 token/错 token → 401；`mcp_token` 永不外发；8389 保持仅本机回环不变）
3. **只读投影**（官网 `/user/` 页）：记忆条目 / 资产清单 / 衣柜 / 会话摘要——四类各一最小卡片；脱敏走 InfoVault 白名单（凭证 NEVER/照片需确认）
4. **断开/重连**：断开→官网「离线态」；重连→恢复

## 三、不做

- 阶段 2/3（WebRTC P2P/中继/登录态融合/写操作回写）——**另单**
- 服务器存储任何用户内容（含缓存/日志）
- 写操作（站点操作回写手机）——另评

## 四、红线（违反=打回）

1. **用户内容零服务端存储**（官方服务器只握手/信令；本地代理不写任何日志到服务器）
2. **配对=显式用户动作**（官网出码+手机扫码+手机确认；单方解除=立即断开）
3. **用户面鉴权强制**：会话 token 校验；同 WiFi 无 token 一律 401；`mcp_token`（8389）永不外发；8389 绑定回环不动
4. **只读**：user/<section> 只读投影；不提供写端点
5. 脱敏遵循 InfoVault 白名单（凭证类 NEVER）
6. 断开后官网显「离线态」（**不缓存旧数据/不显示脱机旧内容**）

## 五、验收判据（STD-UPG-108-v1 摘要，详见冻结区）

- U108-1 配对建立（官网出码→手机扫→确认→sessionId+token）
- U108-2 投影四类内容正确 + 脱敏正确（凭证类不出现）
- U108-3 断开→离线态；重连→恢复
- U108-4 服务器零存储（服务端日志/存储扫描零命中）
- **U108-5 鉴权**：同 WiFi 无 token→401；错 token→401；8389 仍仅回环（LAN 不可达）

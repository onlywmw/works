## 一、施工范围（5 项）

1. **llms.txt（能力级主体）**：`https://mov-ai.cn/llms.txt`——主体=能力清单（工具名+一句话+详情 URL，按域分组；**同源生成**：数据源=App 注册中心/市场 registry 导出，不手敲）；附录=官网 10 页索引。
2. **每页 JSON-LD（schema.org 优先）**：10 页 `<script type="application/ld+json">`——官网页=`WebSite`/`WebPage`；能力页=`SoftwareApplication`+`applicationCategory`；市场能力项=`Product`；目录=`ItemList`；自定义仅 `mov:*` 挂 `@context`（禁整体自定义 mov:Capability 主类型）。
3. **sitemap.xml + 语义化 HTML 核查**：`sitemap.xml` 全量 URL；核查已有 10 页结构标签（h1/h2/语义化）——**衬底不主线**（不改视觉，只补结构）。
4. **六工具 schema + description 四要素**：mov_site_info / mov_capabilities / mov_tools / mov_search / mov_market_catalog / mov_guide——每工具：用途/输入/输出/**边界（何时不要用）**/示例，**以 v3 §4.4 细则为基准**（description 质量=胜负手，必须评审后定稿）。
5. **验证戳字段**：所有工具返回 `registry_version`（ISO 时间戳）+ `mov_site_info` 提供 `last_sync_time`。

## 二、验收（本批）

- **内容验收**：llms.txt 十问可答性自查（§8.3 Q1-Q4/Q7-Q9 命中）+ JSON-LD 结构校验（schema.org 类型可解析）+ sitemap 全量 URL 200 + 六工具 schema 四要素齐全（description 含边界句）。
- **数据同源**：能力清单与注册中心/市场 registry 一致（无手工编造条目；零编造=Q5/Q6 负例 PASS）。
- **工程版=验证版**：提交版即验证版；`llms.txt`/JSON-LD/工具 schema 变更后跑核对脚本。

## 三、不做

- 不做 A 通道端点/缓存/限流（批二）；不做 B 通道（UPG-69 后）；不动官网视觉；不开放敏感工具。

## 四、交付物

- 代码（market-web/ 或官网站点仓库）：llms.txt / JSON-LD / sitemap.xml / 工具 schema 文件 + 生成脚本（同源导出）
- 报告：DELIVERY_UPG105_批一_内容层.md（含六工具 description 终稿、十问自查表、同源核对证据）
- 预审：空白 AI 读取（可跑 §8.4 协议，10 问记录）

## 五、红线

只读；同源；诚实空态；无敏感泄露；description 四要素齐全；**零编造**（不在官网制造 App 不存在的能力）。

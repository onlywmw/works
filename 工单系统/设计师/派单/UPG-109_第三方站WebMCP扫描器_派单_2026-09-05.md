## 一、一句话

浏览器打开任意站点 → 自动探测 WebMCP 接入性 → 三档判定（A 原生 / B 可注入 / C 不可）→ A 直接接 Hub、B 经用户确认域名级授权后强制注入桥接、C 诚实展示不可接入。

## 二、范围

1. **探测面四项**（无 CSP）：①原生 WebMCP 物（`window.mov_webApi`/W3C webmcp/`llms.txt`/`.well-known/ai.txt`）②DOM 可定位性（key selector 稳定性/SPA 渲染时机）③页面框架（Vue/React/原生/静态）④登录墙/验证码（只读受限判定）
2. **三档判定**（纯函数：探测结果 → A/B/C；不确定=C 档诚实降级）
3. **判定报告**：落 journal + 卡片投影（U-40 视觉纪律：AI 动作用户可见）+ agent 上下文可用
4. **B 档桥接**：经 43a Hub 强制注入（域名级显式授权 + 审批门；仅当前会话；可随时撤销）
5. **自建三档测试站**（L1 用例集：A/B/C 三类型本地站）

## 三、不做

- 不自动改造第三方站（判定≠动手；注入需用户授权）
- 不爬受保护内容/不绕反爬/验证码/登录墙
- 不存储站点内容副本

## 四、红线（违反=打回）

1. **探测只读零副作用**（不向站点发写请求）
2. **B 档注入必须用户显式授权**（域名级）+ 审批门；授权仅当前会话/域名
3. 判定报告诚实（不确定=C 档；不装确定）
4. 扫描可全局关闭（用户关探测=全局禁用）
5. **CSP 不作判定输入**（App 侧 evaluateJavascript 不受 CSP 拦——v1.1 已更正）

## 五、验收判据（STD-UPG-109-v1 摘要）

- U109-1 三档判定用例集（自建 A/B/C 站判定正确）
- U109-2 真机：mov-ai.cn（A 档）+ 一个开源站（B/C 档实证）
- U109-3 变异：判定函数删除→红（变异亲杀）
- U109-4 只读证据（探测过程零写请求）
- U109-5 判定输入仅四项（无 CSP；回归锚）

## 六、技术要点

- 探测器：43a WebView 注入探测脚本（JS 对象检查+DOM 查询+框架嗅探；轮询 ≤3s）
- 判定=纯函数（L1 单测；与 Gate3/OrchRules 同类范式）
- 卡片投影：UPG-40 卡片体系
- 授权管理：域名级审批记录（复用审批体系）

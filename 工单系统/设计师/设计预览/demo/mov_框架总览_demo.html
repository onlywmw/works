MOV · Agent 架构与关系
Agent（AI 管家）是中枢——它通过四件事工作：懂你（读记忆）→ 决策（调工具·走授权）→ 办事（执行）→ 沉淀（写记忆·留痕），形成"感知→决策→行动→记memoria"闭环。各系统围绕 Agent、被 Agent 调用。
MOV Agent
AI 管家 · 中枢 · 感知→决策→行动→沉淀
1 感知 · 懂你
Agent ←读取 统一记忆系统：先取 Core（瞬时用户画像）→ Semantic（池子/MD）→ Episodic（近期碎片）兜底。来自 Event→Episodic→Semantic→Timeline 的历史记忆。
2 决策 · 授权
Agent 要调工具 → 走过 安全体系：SecurityGate（subject×resource×op×data×dest）→ 分档（free/ask/gate）→ DecisionToken（授权绑定）→ 该确认时 审批弹窗（大白话）→ 高层级给确认放行。工具联动 Runtime 判参数/风险/多工具编排（NO_CALL/CALL/MULTI）。
3 行动 · 办事
Agent →调用 工具 / MCP：内置工具（文件/HTTP/设备）+ 本地能力 + 第三方 MCP（经 Gatekeeper 校验/白名单/防注入）→ 执行"办事"（查资料/写文件/发消息/支付…）。可触达 资产库（生成/访问文件资产）。
4 沉淀 · 记住
Agent →写入 记忆：新认知晋级 Semantic 池子（MD分篇·人工确认）→ Timeline（不可变留痕）+ 审计——下次"懂你"用得着。用户删除=被挡（blockedSourceHashes，删掉不回来）。
👤 用户（人机对话 · 入口）
向 Agent 说话 → Agent 感知记忆懂你 → 决策办事 → 在有需要时（敏感/写/对外/不可逆）弹一次大白话审批 → 执行 → 沉淀。设置页/侧边栏是用户配置与入口。
📦 资产库（Agent 可生成/访问的对象）
我的资产（挂账·待安全体系后）：类目管理项注册（图片/视频/音乐/文章/衣物·衣柜/凭据）——Agent 换装 MCP 可产出衣物资产入库。安全体系定稿后基于其上立项。
🧩 MCP 生态（能力市场）
第三方/自建能力（市场·本地能力·工具联动 Runtime）：Agent 经 Gatekeeper 调用，白名单/风险分级/审计——"能力 → 资产 → 商业"。
💳 商业层（Agent 沉淀的输出）
协议授权下，把 Agent 沉淀的记忆二次加工成画像（星座/偏好…）→ 个性化推荐/人群分组（只传去标识标签·不传原文·可关个性化）。承载交易/支付/广告——商业重点。

关系要点：Agent 是唯一中枢——①读记忆→懂你 ②走安全→护你 ③调工具/MCP→办事 ④写记忆+留痕→沉淀。记忆/安全/资产 都是被 Agent 调用的"服务"，不是平级功能。资产/安全体系为阶段设计（资产挂账待安全体系 v2.1 定稿后立项）。

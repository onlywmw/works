# 微信生态 · 开发文档（小程序 + 服务号 —— MOV 在微信生态的形态与规则）

> 设计师 @2026-09-02 ｜ **用途**：了解微信小程序生态（官方核实），为 MOV 未来的小程序形态（AI 对话/点单商城/微信支付）+ 微信侧分发做准备。
> **取证**：全部微信官方来源（developers.weixin.qq.com / pay.weixin.qq.com / open.weixin.qq.com / mp.weixin.qq.com）。
> **与 MOV 关系**：商业线=微信支付（已定）——微信生态（**小程序 + 服务号**）是天然落地形态；多端路线中它是「微信侧触达面」（与安卓主 App 互补）。
> **补调研**：服务号官方 10 条（见 §八）——定位：服务号=触达+入口+身份层；小程序=功能+交易容器。

## 〇、一句话

**MOV 小程序版可行的**：AI 对话（录音→服务端 ASR/LLM）+ 点单/商城（web-view 复用现有 HTML5 引擎）+ 微信支付（JSAPI 直译 CT-14）——但**必须企业主体 + 备案域名 + 审核配合**；**最大红线：iOS 端虚拟商品不能走微信支付**（AI 会员/订阅需专项方案）。

## 二、MOV 在微信生态的形态建议（三种）

```text
形态 A（核心）：MOV 小程序版
  AI 对话（录音→ASR→LLM→回复/TTS）+ 点单/商城（web-view 复用现有 H5 引擎 + 微信支付 JSAPI）
  → 微信侧触达面（与安卓主 App 互补；UnionID 跨端同人）

形态 B（加分·beta）：SKILL 被调
  MOV 能力（点单/商城/对话）封装 SKILL（SKILL.md+mcp.json）
  → 微信小程序 AI 可调 → 微信侧 AI 分发渠道（内测中，不进提审版）

形态 C（B 端·远期）：服务商模式
  开放平台第三方平台 + 支付服务商 → 代商户开发小程序（MOV 商业 B 端延伸）
```

## 三、MOV 特有风险与红线（开发前必须决策）

1. **主体**：必须**企业主体**（微信认证 300 元）——微信支付/电商/点餐类目前提（个人主体不可支付）
2. **iOS 虚拟支付**：AI 会员/订阅在 iOS 端**不能走微信支付**（Apple IAP 红线映射）——方案：iOS 端关闭销售/走 iOS 虚拟支付指引/安卓+H5 分流（商业期定）
3. **AppSecret/密钥绝不进小程序包**（官方硬约束——与安卓开发习惯差异）
4. **备案域名+证书**：MOV 后端域名需 ICP 备案+登记服务器域名白名单（现 mow.kim 已备案？——核实）
5. **web-view 限制**：每页一个/企业主体/Skyline 下不支持——H5 引擎页面嵌入受限（页面级嵌入，不能混 Skyline）
6. **AI 内容合规**：深度合成类目 + 生成内容标识 + 过滤措施（与 MOV AI 能力对应——审核硬条件）
7. **审核人工**：无灰度自主权（体验版/开发版测试；发布=手动）+ 需提供测试账号

## 九、微信生态全貌（小程序 + 服务号协同 · MOV 双形态）

```text
        ┌────────────── 微信生态（同一开放平台 · unionid 统一身份）──────────────┐
        │                                                                      │
        │  服务号（触达+入口+身份层）              小程序（功能+交易容器）            │
        │  ├ 网页授权 OAuth（openid 识别）          ├ JSAPI 支付（appid B）        │
        │  ├ 模板消息/订阅通知（跳小程序）            ├ web-view 复用 H5 引擎        │
        │  ├ 客服消息 48h（AI 对话承接）             ├ 订阅消息（支付后免弹窗 Beta）  │
        │  ├ 菜单/二维码（引流入口）                 ├ 录音→服务端 ASR → LLM        │
        │  └ 菜单/模板 → 跳小程序 ← 引流闭环 ───────┘                             │
        │                                                                      │
        │  ↘ 菜单/模板/二维码带参 → 小程序完成主流程（下单/对话/订阅）              │
        │  → 通知回服务号模板消息（状态变化）→ 一键回小程序                         │
        └──────────────────────────────────────────────────────────────────────┘
    账号底座：微信开放平台绑定（服务号+小程序+未来 MOV App）→ unionid 跨端同人
    微信外（MOV 安卓 App）能力需另开：开放平台「移动应用」+ APP 支付（服务号 H5 不覆盖）
```

**MOV 三形态更新**（原 §二 基础上）：
- **形态 A（核心）**：服务号（入口/通知）+ 小程序（对话/点单/交易）——**双端闭环**
- 形态 B SKILL 被调（beta）/ 形态 C 服务商代运营（远期）不变

**新增红线（服务号）**：
1. **认证=一切能力前提**（网页授权/模板消息/JSAPI 支付都要认证，年审制+年费）
2. **群发每月 4 条**——仅重大公告
3. **模板消息禁营销**（40249 红线）
4. **5 秒响应**（被动回复超时断连）——AI 对话服务号侧要「即时应答+客服异步」
5. **APP 内不能用 H5 支付**——MOV 安卓 App 收款=开放平台移动应用+APP 支付（与小程序/服务号支付并列第三通道）

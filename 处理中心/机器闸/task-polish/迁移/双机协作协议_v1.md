# 双机协作协议 v1（本体系 ⇄ 打磨专机·A 阶段）

> 阶段：**A（运行面独立）**——管理面仍在本体系。B 阶段（管理面抽离）另行修订本协议。

## 支点：打磨仓（独立 git 仓·待建）

| 目录 | 谁写 | 内容 |
|---|---|---|
| `samples/` | 双写（先拉后推） | 样本卡 S-XXX＋**合成素材**（真件红线沿样本池件〔POL-11 口径〕） |
| `runs/` | **专机写** | 每轮产物：四读数/卡点表/轮次报告/证据指针（SUMS 引用） |
| `orders/` | **本体系写** | 升级单/派单件的**交接副本**（正式单仍在本体系流水线管理） |

## 信流与职责

- **管理面（工单/相位/邮局/合并位/验收审验）＝本体系**，不随迁（防双流水线）。
- **运行面（沙盒/模拟器/跑批/闸）＝专机**；专机不自行开单、不自行降级判据。
- 跨机通知：打磨仓提交 + 一行消息（驿站式）；本体系内部信流照旧邮局。

## 安全与合规

- **真件不进仓**（PII 红线沿 POL-11）；凭据（LLM 键/令牌）**不入仓**。
- 专机侧产物入 `runs/` 前过 PII 扫描（复用样本池脱敏器）。

## 冲突规则

- 单写域：`orders/` 仅本体系写、`runs/` 仅专机写；`samples/` 双写需先拉后推。
- 版本钉扎：`runs/` 每轮须带 app sha＋server pin＋AVD 快照 id（沿 D8）。

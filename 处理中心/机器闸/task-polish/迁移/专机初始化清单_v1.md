# 专机初始化清单 v1（打磨体系·运行面）

> 目标机：新电脑（用户专用）。按序执行，每步附验证命令；**密钥不入仓**。

## 0. 基础件

- Git ｜ Node 22（nvm 或直装）｜ Python 3.12 ｜ tar/7z
- 验证：`git --version && node -v && python -V`

## 1. 运行依赖

- Playwright（渲染/闸）：`npm i -g playwright && npx playwright install chromium`
- 沙盒服务：`pip install uvicorn fastapi`（＋`mov-web/server/a2a` 的 requirements）
- 验证：`python -c "import uvicorn, fastapi"`

## 2. 仓与 pin

- **打磨仓**（独立·待建）：`task-polish/`＋`card-clarity/`＋样本卡/协议（本次搬迁包内）
- **mov-web**（只读 pin）：`git clone <mov-web remote> && git -C mov-web checkout 0444adc`
- 验证：`git -C mov-web rev-parse --short HEAD` ⇒ `0444adc`

## 3. 沙盒数据

- 拷贝 `pol4-sandbox/`（17M：`data/a2a.db`·`a2a.env`·logs）
- **a2a.env 含 LLM 上游键——不外传、不入仓**（人工带过）

## 4. Android 面

- Android SDK：platform-tools／platforms／emulator
- AVD：导入 `MOV_Test`（含基线快照 `pol4-baseline`）；或新建 `MOV_Sandbox` 后打基线
- 验证：`emulator -list-avds` ｜ `adb devices`

## 5. 打包 / 铺设命令（本机侧 → 专机）

```bash
# 本机打包（在体系根执行）
tar -czf polish-migrate-20261007.tgz \
  处理中心/机器闸/task-polish 处理中心/机器闸/card-clarity \
  E:/mov工作区/pol4-sandbox
# AVD（快照随目录）：拷 ~/.android/avd/<avd>/（含 snapshots/）或到专机重打基线
```

```bash
# 专机铺设
tar -xzf polish-migrate-20261007.tgz -C <体系根>
cd 处理中心/机器闸/task-polish/sandbox && node sandbox.mjs provision && node sandbox.mjs start
node ../../card-clarity/release-gate.mjs --cards ../../card-clarity/samples/cards.positive.json --judge stub
```

## 6. 首次验证（A 阶段验收前置）

1. `sandbox.mjs status`：pin/process/db 三绿；
2. `avd.mjs boot`＋`avd.mjs restore pol4-baseline`；
3. `release-gate` 正例套 **rc=0**；
4. 起跑 S-MERCHANT-01（按样本卡·沙盒档）——留 A 阶段验收。

# 样本池（task-polish · POL-11）

> 定位：change=task-polish「样本任务集」的自动化通道——**结构化卡点**与**合成素材**的入库/消费。
> 合规硬红线（细则＝`合规清单.md`）：**真件一律不得进池**（证件照/营业执照图/原文/姓名/号码/地址/头像等 PII 全拒）；
> 池内＝结构化卡点＋合成素材；**复跑只用合成件**；原素材永不进池、副本不入仓。

## 一、池结构

```
样本池/
├── README.md            # 本文件（结构/命令/环对接）
├── 合规清单.md           # 白名单字段表＋脱敏规则＋留存/访问策略（对照三依据逐条）
├── 素材位.json           # 样本→素材位登记表（接收侧合成素材拼装的唯一来源）
├── 索引.json             # 索引：条目/状态/素材/哈希（脚本维护·禁手改）
├── 条目/                 # 样本条目（卡点结构·白名单字段）＋合成样本卡
├── 素材/                 # 素材位（仅合成件·生成物；按条目分子目录）
├── 通道.mjs              # 唯一出入口：上传｜接收｜读池｜扫描｜归档
└── 自检.mjs              # A/B 自检：正例命中／负例入池／扫描／环消费
```

**状态语义**：`候选`（过闸入库·未拼装）→ `在用`（合成卡生成·可被环消费）→ `归档`（退出复跑·文件保留）。

## 二、命令（通道）

```bash
P=处理中心/机器闸/task-polish/样本池
node $P/通道.mjs 上传 <候选.json> [--脱敏]      # 出侧闸：白名单＋PII 扫描；命中即拒；--脱敏 则替换后重判
node $P/通道.mjs 接收 <条目id>                  # 入侧：结构→合成样本卡＋合成素材拼装（候选→在用）
node $P/通道.mjs 读池 [<条目id>]                # 环入口：JSON 消费清单（卡/素材/结构/协议）
node $P/通道.mjs 扫描                           # 全池 PII/真件抽检（收口前必跑；0 命中=零真件）
node $P/通道.mjs 归档 <条目id>
node $P/自检.mjs                                # A/B 复跑＋变异亲杀＋真池消费核
```

候选载荷（来源双轨：沙盒跑批产物／真实使用卡点，**仅结构化**）：

```json
{ "sample": "S-MERCHANT-01", "source": "sandbox",
  "checkpoint": { "phase": "WAITING_USER", "event_seq": 12, "duration_ms": 8600,
                  "error_code": null, "field_name": "shop_name", "count": 1 } }
```

- 白名单六字段：相位／事件序／耗时／错误码／字段名／计数；白名单外键（原文、附件、头像路径等）**一律拒**。
- `sample` MUST 在 `素材位.json` 登记（新样本卡入队时一并登记）。

## 三、环对接接口

| 对接方 | 方向 | 接口 |
|---|---|---|
| POL-1 环自转（跑批 harness） | 读池 | `通道.mjs 读池 [<id>]` → JSON：`{card, base_card, blueprint, materials[{slot,path,synthetic,sha256}], structure, protocol}`；harness 按 `base_card` 蓝图在沙盒复跑，素材用池内合成件，卡点按 `structure` 定位/注入；**跑批产物不写回池** |
| POL-2 生产遥测（聚合器） | 回灌 | 真实使用卡点（仅结构化·去标识化）经 `通道.mjs 上传`（`source:"real"`）入池；聚合器**不得直接写池文件**（唯一入口=通道闸）；生产侧原文/PII 不进载荷 |
| 样本任务集（task-polish spec） | 同步 | 池条目 `sample` ↔ `素材位.json` ↔ `样本任务卡_S-*.md` 三处同名；增样本卡=增登记行 |

## 四、纪律

1. 手工只碰 `素材位.json`（登记）与文档；`索引.json`、`条目/`、`素材/` 由脚本维护。
2. 出侧任何入口（沙盒跑批/真实遥测/人工整理）都要过 `上传` 闸；闸之外无旁路。
3. 收口/提交前跑 `扫描`（0 命中=零真件）与 `自检.mjs`（全绿）；池内出现游离文件即红（疑真件）。
4. 素材位只收 `svg/md/txt/json` 合成格式；其他格式（图片/证件样张扫描件等）不得进池。
5. `--池 <dir>` 仅供测试隔离用（自检内部即用临时池）；正式池=POL-11 就地件目录。

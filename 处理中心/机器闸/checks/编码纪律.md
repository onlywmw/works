# 编码纪律（SYS-201·落文件/采集日志防乱码）

> 依据：dsh-mojibake-interceptor 规则集（危险编码原语拦、未声明编码提示）＋本体系实证三例（2026-10-11）。
> 配套闸：`checks/mojibake-scan.mjs`（五探针·批量）＋`~/.pi/agent/extensions/mojibake-guard.ts`（写前拦/提示）。

1. **pwsh 落文件一律显式 UTF-8**：`Set-Content/Out-File/Add-Content/Export-Csv` **必带 `-Encoding utf8`**（pwsh 5.1 默认 ANSI ⇒ 中文落盘即乱码）；**禁** `-Encoding Default|ANSI|OEM` 与 `[Text.Encoding]::Default`。
2. **采集日志统一 UTF-8**：禁裸 `| Out-File`（不带 `-Encoding`）；`tee`/重定向走 git-bash（原生 UTF-8）；`chcp` 只准 65001（936/GBK 仅历史 `.cmd` 编码锚例外）。
3. **写后回读校验一行**：脚本/命令写中文后 `Get-Content -Encoding utf8 <file> | Select -First 1` 或 `head -1` 回读——值对不上即当乱码处理，别等破图。
4. **借道原则**：能 `node -e "...writeFileSync..."` 或 git-bash `printf` 的写盘，别绕 pwsh 字符串管道（多层转码是乱码主源）。
5. **存量冻结面不回溯**：归档/证据/日志面含历史乱码 = 采集时点原样（`checks/mojibake-baseline.json` 白名单登记·只增需理由）；**活面**新命中 = 先修再提交；确需保留 ⇒ 补白名单理由。
6. **引用乱码示例**：文档/证据刻意引用 `�`/乱码字时，件需入白名单（reason 写明「刻意引用」）；扩展/闸自体文件同办。
7. **发现即报**：`mojibake-scan` 新增命中先当红灯复核；hw/pwsh 历史小伤（如注释 `�ing`）入基线标「候办」列单跟办，不静默吞。

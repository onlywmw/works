## 〇、分层翻译策略（最省力）

```text
直接复用（跨平台天然）：
  ✅ HTML5 引擎（core.js——纯 HTML5/JS，ArkWeb 通用）
  ✅ 页面资产（settings/market/… 全部 HTML 资产）
  ✅ JSON 契约（ApprovalRegistry/骨架 JSON/组件契约/LLM 提取物）
  ✅ 服务器逻辑（云 relay——与客户端无关）

需要翻译（Kotlin 壳）：
  🔨 UIAbility / 工具注册 / 审批 service / 密钥（HUKS/ASSET）/ 网络层 / 权限
```

**最大前提：HarmonyOS NEXT（5.0+）起不再兼容 APK——必须交付 ArkTS 原生（HAP）版本，无「直接装 APK」路线。**

## 二、翻译核心映射（Kotlin → ArkTS）

| Kotlin（安卓） | ArkTS（鸿蒙） |
|---|---|
| Activity/Component | UIAbility + ArkUI（@Entry @Component struct） |
| WebView + addJavascriptInterface | Web（ArkWeb）+ JavaScriptProxy（双向） |
| SharedPreferences | Preferences |
| KeyStore（密钥） | HUKS（密钥）+ ASSET（敏感数据 ≤1KB） |
| OkHttp / HttpURLConnection | @ohos.net.http（HttpRequest） |
| WebSocketClient | @ohos.net.webSocket |
| RECORD_AUDIO | ohos.permission.MICROPHONE（user_grant） |
| 前台服务/保活 | 长时任务（AUDIO_RECORDING/AUDIO_PLAYBACK——按类型声明） |
| Gradle/Maven | DevEco/hvigor + ohpm |
| AndroidManifest 权限 | module.json5 requestPermissions |
| SQLite/Room | RDB（RelationalStore）+ 加密 |

## 三、MOV 特有风险（翻译时要决策）

1. **「手机=个人服务器」线在鸿蒙**：长时任务受约束（音频/VOIP 类可长，通用服务不可——与 iOS 类似但略宽松：有开发模式？建议=进入开发调试期验证；生产=降级「前台/短时」模式）
2. **ArkWeb 迁移**：JS 桥 API 改名（javaScriptProxy 语法）+ WebviewController——桥梁重写成本中等
3. **AI SDK/支付**：DeepSeek API 调用=纯 HTTP（可用）；微信支付鸿蒙有官方 SDK（确认 API 版本后接入；商业期定）
4. **审批弹窗**：ArkUI 弹窗（promptAction/customDialog）——与 UPG-53 语义对齐

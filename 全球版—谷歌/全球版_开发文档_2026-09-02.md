## 〇、一句话

**MOV 全球版结构上必须「国内版 / 海外版」双版本**（GMS 是硬依赖——无 Google Play services 设备全家桶全废）；海外版 = **Credential Manager 接 Google 登录（sub 主键+自建后端验 id_token）+ FCM data 推送（免费）+ 系统 Auto Backup（排除设备 token）+ target API 36 的 AAB（Play App Signing）**；Firebase 是否上=数据出境/GDPR 合规待决。

## 二、MOV 全球版决策（双版本结构）

```text
┌─ 国内版（现状线）─────────────────────────────┐
│ 微信生态（服务号+小程序）+ 微信登录/支付 + 自有推送 │
│（无 GMS——不接 Google 全家桶；APK 分发可选）      │
└──────────────────────────────────────────┘
┌─ 海外版（全球版——GMS 版，本目录主题）────────────┐
│ Google 登录（Credential Manager + sub 主键）    │
│ FCM data 推送（免费；13+ 权限；1 月断连兜底）     │
│ Auto Backup（exclude 设备 token）              │
│ target API 36 + AAB + Play App Signing        │
│ Billing（IAP——旧调研详细版）                   │
│（Firebase 其他=待合规决策；不强制）              │
└──────────────────────────────────────────┘
```

**结构结论**：GMS 代码=特性开关/拆模块（国内版零 GMS 依赖）；海外版独立构建线。

## 三、与 MOV 体系衔接

| MOV 体系 | 全球版衔接 |
|---|---|
| 账号体系 | 双轨：微信 openid（国内）+ **Google sub**（海外）——同后端用户表并存；自建后端验 id_token（官方库） |
| 推送/保活 | FCM data-only=「手机=个人服务器」海外到达提醒；1 个月断连边界（重要消息拉取兜底） |
| 隐私合规 | 英文隐私政策 + Data safety 表单 + 应用内披露 + **账号删除双入口**（App 内+官网） |
| 商业 | Billing IAP（旧调研：数字商品必须 Billing/15%档/服务端验证）——微信支付仅国内版 |
| 备份 | Auto Backup 系统级（排除设备 token）；国内版自有备份（待做） |
| 多端 | 翻译规则（iOS 已含 IAP/APNs；海外版与 iOS、小程序共享「sub/openid/unionid」多身份归一的设计） |

## 四、待决策清单（全球版启动前）

1. **Firebase 是否上**（Auth/Firestore/RConfig）：数据出境 GDPR/DPF 决策→若上=数据存储地+合规意见+Form 申报；若不=自建（Remote Config 10 万/日可单用）
2. **GMS 拆分方式**：特性开关 vs 拆模块（构建线分离）——代码侧决策
3. **账号删除双入口**实现（应用内+官网页面——Play 硬要求）
4. **目标 API 36 排期**：全球版按新应用提交 targetSdk 36（2026-08-31 门槛已过——延期窗口 11 月前必须）
5. **封测启动**：12 人×14 天最早启动（个人账号流程 5-6 周；组织 D-U-N-S 30 天更久——排期硬约束）

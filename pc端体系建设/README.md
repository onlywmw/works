## 一、多端形态（方向 · 待设计细化）

```text
┌──────────────┐           扫码配对            ┌──────────────┐
│  MOV 手机      │  ←———  中继(mow.kim/relay) ———→  │  PC 浏览器     │
│  = 个人服务器   │                              │  = 瘦客户端     │
│  工具/记忆/模型/审批 │                              │  引擎渲染远程视图 │
│  （数据永不出手机）│                              │  （无本地数据）   │
└──────────────┘                              └──────────────┘
```

**已铺资产（不是从零）**：
- cloud relay（中继：mow.kim/relay/ws，deviceId=sha256(dev…) 配对身份）✅ 已上线
- Companion（PC 配对客户端 + ACP 契约，MOV↔PC 互联 + 委派审批 L2 已验证）✅
- 本机服务栈（MiniHttpServer/8389 MCP/8790 relay——手机=服务器模式已成）✅
- 引擎（纯 HTML5 → PC 浏览器天然渲染，与手机同一套——刚拍板）✅

**要补的关键**：手机上挂「个人服务面」（工具/记忆/审批暴露成 API）+ PC 端=引擎渲染的远程客户端。

**四道坎（诚实记录）**：①离线语义（手机不在线→PC 失联——保活+降级提示）②工具面授权放大（审批全量走手机弹窗）③并发（手机/PC 同时用——单主会话规则）④性能（手机渲染给 PC——真实使用验证）。

## 卫生规则（清障纪律 · 2026-09-08 立）

> 来源：2026-09-08 整理事故教训（临时文件散落/残留空壳/误删 2 文档/后台预览服务锁目录/中文路径错位）。**目标：根目录时刻干净、任何操作可回退、不留僵尸。**

### 1. 根层只允许放什么
- `README.md`、`项目配置.md`、各体系目录（`安卓中国体系建设\`、`腾讯微信生态\`、`ios体系建设\` 等）
- **禁止**：临时 .cjs/.mjs/.bundle/.txt/截图/拷贝件散放根层——用完即删或进 `C:\tmp\`

### 2. 临时产物规则
- 临时脚本统一 `C:\tmp\`，用完删除；不进 Desktop\MOV 根层
- 启动预览/服务类进程（http.server/gradle 守护/board-server）→ 记录 PID；**用完必须停**（这次 `http.server 8123` 挂了 3 天锁死目录）
- 备份/bundle 不落根层（`C:\tmp\` 或 `E:\mov归档\`）

### 3. 移动/删除纪律（误删教训 ×2）
- **先 mv 后验证**：`mv` 成功 → `ls 目标` 确认文件数 → 才允许删源
- **中文/UTF-8 路径**：bash 传参中文易错位（GBK/UTF-8）——有风险时用 PowerShell `-LiteralPath` 或先 `ls` 验证
- `rm -rf` 前必列清单核对（`find 源 -type f | wc -l` + 抽查）
- 用户已确认要删 ≠ 直接 rm——大目录分批、先移后删

### 4. 命名与归属
- 目录改名后**全量更新引用**（.gitignore/pre-commit/文档/脚本硬路径）——改名后必 grep 残留
- 归档唯一去处：`E:\mov归档\`（关单资产）/ `安卓中国体系建设\_备份归档\`（数据备份）——**禁止第三归档目录**
- 新目录先归位（体系目录/设计区/证据区），不新建「未命名/杂项」文件夹

### 5. 每周体检（周六顺手 5 分钟）
```bash
cd C:\Users\Administrator\Desktop\MOV
git status --short | head            # 意外散件
ls -d */                             # 顶层目录应都在白名单
find . -maxdepth 1 -type f | wc -l   # 根层文件应 ≤2（README+项目配置）
powerShell get-process node,python   # 有没有挂死的服务（cwd 在仓库内的）
```

### 6. 后台服务红线
- 仓库目录内的 `http.server`/`watch`/`board-server` 必须记 PID；**会话结束 = 服务结束**
- 不杀 node/python 全家（多服务共用）——只按 PID 精准停（taskkill node 曾误杀派单进程）
